📌 知识脉络

  • 前置知识：JavaScript 基础语法、VS Code 编辑器操作
  • 后续扩展：DOM 操作（DOM Manipulation）、项目实战中的页面结构理解

🎯 概述

本章是一个 HTML 与 CSS 速成课程（Crash Course），目的是帮助你掌握这两项前端基础技术的核心概念。在后续章节的项目实战中（尤其是 DOM 操作），你需要对 HTML 和 CSS 有基本的了解。如果你已经熟悉 HTML 和 CSS，可以跳过本章直接进入下一章。

💡 提示：本章内容仅涵盖 HTML 和 CSS 最基础的部分（大约不到 5%），目标是让你能够理解课程项目中的 HTML/CSS 代码，并掌握 CSS 选择器的用法——因为在 JavaScript 中进行 DOM 操作时，我们会使用完全相同的选择器语法来选取页面元素。

🎯 概述

if/else 语句是 JavaScript 中最核心的控制结构（Control Structure）之一。它允许我们根据条件的真假来决定执行哪段代码，从而打破了代码从上到下线性执行的模式，让程序拥有了"做决策"的能力。

1. 什么是 if/else 语句？

🧩 生活类比：if/else 就像十字路口的红绿灯——绿灯亮（条件为 true）就直行，红灯亮（条件为 false）就走另一条路。程序执行到这里时，不会两条路都走，只会选一条。

flowchart TD A["代码开始执行"] --> B{"条件为 true？"} B -- "✅ 是" --> C["执行 if 代码块"] B -- "❌ 否" --> D["执行 else 代码块（可选）"] C --> E["继续执行后续代码"] D --> E

基本语法：

// ① 声明条件判断
if (条件) {
  // ② 条件为 true 时执行这里
} else {
  // ③ 条件为 false 时执行这里（可选）
}
💡 记忆口诀："if 问真假，true 走上，false 走下，else 可不加"

❓ 理解检测

1. 以下代码的输出是什么？
let x = 10;
if (x > 20) {
    console.log("A");
} else {
    console.log("B");
}
A) 输出 "A"
B) 输出 "B"
C) 输出 "A" 和 "B"
D) 报错
正确！ 解析：10 > 20 的结果是 false，因此走了 else 分支，输出 "B"。

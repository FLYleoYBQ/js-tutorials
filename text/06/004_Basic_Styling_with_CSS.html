Basic Styling with CSS (使用 CSS 进行基础页面装潢)

📺 来源：004 Basic Styling with CSS.en.srt 📂 章节：第 06 章
📌 知识脉络
  • 前置知识：HTML 的 id 与 class 标识符
  • 后续扩展：JavaScript 中的 `document.querySelector()` (它与 CSS 选择器的语法完全一致！)

🎯 概述

单纯的 HTML 只是黑白简陋的骨架。这节课我们将学习如何把 CSS（层叠样式表）引入 HTML 中，并通过 选择器（Selectors） 选中特定的元素，继而为它们上色、调字号以及加边框。

1. 外挂分离：Link CSS 样式表

虽然这门课里我们可以直接使用 <style> 标签把 CSS 写在 HTML 中，但真实世界里，我们总是主张**“内容与表现相互分离”**。这意味着，HTML 应该单独放一个文件，而样式则放入独立的 style.css 中。

🧩 生活类比：HTML 文档就像是汽车的出厂骨架图（`index.html`）。CSS 就像是一份《喷漆与内饰改装手册》（`style.css`）。光有手册不够，你必须要用一根管线把手册和骨架连起来告诉工厂：“请按这本手册来给它喷漆”。

在你的 <head> 配置区，写入这根连接管线：

<head>
  <!-- 告诉浏览器去读取并执行 style.css 里的样式装潢指令 -->
  <link href="style.css" rel="stylesheet">
</head>

3. 继承性（Inheritance）

当你给 body 躯干设置诸如 font-family: Arial; 时，你会发现整个页面里面所有的标题 h1、段落 p 全部的字体都跟着变成了 Arial。这就叫**继承性（Inheritance）**。

CSS 中并非每个属性都会被传递给子孙。一般而言，**和字体、文本表现有关的都会继承**（如 font-size, color），而不相关的物理参数，比如本节提到的 border 边框就不会被继承下来。如果边框被继承，你会看到网页上每一个字外面都长满了密密麻麻的框子！

4. Shorthand（简写属性）

程序员都很爱偷懒。例如，画一个边框，它总是包含“粗细”、“款式”、“颜色”三大要素。如果你不想分别写三行代码：

/* 啰嗦写法 */
border-width: 5px;
border-style: solid;
border-color: #444;

你可以直接使用 border 作为简写属性（Shorthand），将它们在一行内搞定，空格隔开即可：

/* 优雅简写 */
border: 5px solid #444;

🧪 学习验证

❓ 理解检测

1. 在编写 CSS 时，由于你忘了写一个关键符号，导致 id="submit-btn" 这个按钮没有发生任何变化。以下正确的 ID 选择写法是？
A) .submit-btn { background: blue; }
B) #submit-btn { background: blue; }
C) submit-btn { background: blue; }
👍 正确！ 解析：在 CSS 中，选取 ID 必须在前面加上 `#` 号；选取类（Class）必须加 `.` (点号)；什么都不加代表选中普通的 HTML 元素（如 h1, img）。
2. 为什么在 `body` 闭合框中设置了 `color: red;`，所有段落和标题的字都红了？
A) 因为颜色属性在 CSS 中是可以传递给后代的（具备继承特性）。
B) 因为 `color` 属性是针对全局强制更改的命令。
👍 正确！ 解析：与字体相关的多半属于可继承属性，这意味着它们会一层一层传导到子元素身上，这极大节省了我们重复代码的工作量。

🔧 代码填空

补足这段 CSS 样式表的残缺部分，使其能精准把控下方给定的 HTML 元素：

【HTML 结构】
<button class="primary" id="btn-login">登录</button>

【CSS 样式】
/* 1. 使用类名把登录按钮变色 */
primary {
  backgroundcolor: blue;
}

/* 2. 使用 ID 专属设置一个 2px 实心粗黑框（利用简写） */
btn-login {
  border: 2px black;
}

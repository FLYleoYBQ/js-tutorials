🎯 概述

上节课我们创建了简单的标题和段落。这节课我们将探索让网页内容更丰富的组件（如链接 <a>、图片 <img> 和表单 <form>），并引入对网页样式及 JS 交互都至关重要的——属性（Attributes）概念和元素标识（ID与Class）。

1. 行内元素 vs 块级元素

HTML 元素按其霸占“水平空间”的性格划分，主要有两派：

🧩 生活类比：
📦 块级元素（Block-level）：像是个不合群的大沙发，即便只坐着一个人（内容短），也会独占客厅一整行的宽度。例如：<h1>、<p>、<div>。
🧵 行内元素（Inline）：像是一张张并排的小板凳，文本有多长，占位就有多宽，它们可以和文字愉快地肩并肩坐在同一句话里。例如超链接 <a>、图片 <img>。

正因如此，我们可以放心地将超链接标签 `<a>` 插在 `<p>` 段落包裹的整句话中，而不会导致超链接断行突起。

2. 属性（Attributes）之 src 与 href

光有标签是不够的，诸如图片或链接还需额外的设定参数来指定它们的跳转方向等，这些参数称为“属性”。

超链接 <a> 与 href 属性：使用 href="" 写进其实标签中，告知链接要跳去哪里。

图片元素 <img> 与 src 属性：由于图片不需要包裹内部文字内容，它是一个自闭合元素（没有配对的 </img>）。直接使用 src="..." 指定图片路径即可加载图像。

3. 身份标识：核心属性 Class 与 ID

所有元素身上其实都能佩戴两个“名牌”属性：class(类) 与 id(标识符)。这两个属性对于后续我们在 CSS 或 JavaScript 发号施令挑选目标来说有着绝对关键的地位。

属性名 特性 使用场景 / 比喻
class="..." 可重复使用。同一个网页里，很多个元素可以共用被指派为相同的 Class 名字。 像校服。全班几十个人都可以穿统一的“第一班（class="class-one"）”校服。这适合给一批元素定义一样的样式。
id="..." 网页内必须全局唯一。绝不允许多个元素霸占同一个 ID。 像身份证号。全网寻人查无重名！通常用于选中拥有“唯一使命”的绝对特殊元素（例如顶端领航横栏 id="main-nav"）。
⚠️ 命名规范提示：在 HTML/CSS 中，我们通常使用破折号（Kebab-case）来连接词汇，而不是驼峰命名。例如 class="course-image" 是标准写法，不要写成 class="courseImage"。

4. Semantic HTML与表单实战

在创建网页表单（输入框、按钮等）时，我们不仅要把它用一个框子包起来，还要给这框子赋予“意义（Semantics）”。

你永远可以使用 <div> (Division) 作为容器把东西抱团装进。Div 就像个没有任何特色、没有任何说明标签的通用纸皮箱。
但当里面装的是表单元素（输入框 `<input>`、按键 `<button>`）时，更好的做法是使用专业的打包箱—— <form> 元素。

这两者呈现的“外观视觉效果”可能没什么不同，但这也就是 语义化 HTML（Semantic HTML） 的核心：不为视觉，为功能。使用正确的含意标签，能极大方便搜索引擎（如 Google 或 百度 的爬虫蜘蛛）理解你的网页重点。

❓ 理解检测

1. 你正在设计一个网页，页面里有 5 段红色的特殊警告文字。要怎么给它们贴名牌最科学？
A) 都赋予相同的 class="warning-text"，然后在 CSS 统一将 warning-text 指向红色。
B) 把它们的 id 全都设成相同的 id="warning-text"。
👍 正确！ 解析：ID 在整个页面中必须保持唯一！不能出现同名的 ID。如果是用来共用的设定参数，永远选择 class（类）。

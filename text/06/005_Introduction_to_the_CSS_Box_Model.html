Introduction to the CSS Box Model (初识 CSS 盒子模型)

📺 来源：005 Introduction to the CSS Box Model.en.srt 📂 章节：第 06 章 (本章最后一课)
📌 知识脉络
  • 前置知识：基础的 HTML 结构及 CSS 基础挑选法则。
  • 后续扩展：未来当你通过 JavaScript 添加/删除元素，或做特效动画时，对于盒子的尺寸认知将是基础中的基础。

🎯 概述

你编写在 HTML 中的所有骨架级元素（无论是标题、段落还是装表单的容器），实际上在浏览器底层都被看作是一个个方形的“盒子”。这节速成课的最后，我们将学习影响盒子占地面貌的关键物理量：Padding（内边距） 和 Margin（外边距）。

1. 什么是 CSS 盒子模型？

当我们要去排版一个元素的位置和空白留余时，我们通过四个层次的领域来设定：内容本身、内容周围的安全空间、实体外层边框、以及边框外与其它元素的隔距。

🧩 生活类比：快递打包纸箱
📦 Content (内容)：箱子里的贵重商品（文字/图片）。
☁️ Padding (内边距)：塞在商品和纸箱壁之间的防撞泡沫垫。你给越厚的 Padding，不仅更舒适，纸箱也必须被同步撑大。
🚪 Border (边框)：纯粹是这纸箱本身的纸板厚度和颜色。
🚧 Margin (外边距)：快递摆放在货架上时，要求与其他邻居快递纸箱保持的物理安全距离（不属于你自己的体积）。

2. 属性 border-box 的魔法

历史遗留的一个大坑：如果你规定一个盒子的宽度 `width: 400px;` ，接着你又给它添加了左内衬 25px、右内衬 25px、和左右两边的 5px 边框... 浏览器就会默认向外膨胀！

最终实际呈现的盒子宽度将会是：
`400（指定内容宽度） + 25 + 25（Padding 叠加） + 5 + 5（Border 叠加） = 460px 宽度`

这造成了极大的心智负担。为了避免你的规划不断被意想不到的排版撑爆失效，我们要使用 box-sizing: border-box;：

/* 重置魔法：强迫所有元素的宽和高，直接锁死在【边框】之内的总长 */
* {
  /* 当你规定 width 400px 后，内衬和边框只好往内部挤压，永远维持总体外部宽度精准保留在 400px */
  box-sizing: border-box;
}

3. 重组与衍生选择器

在实际美化页面时，我们会组合使用一些方便的选择器小技巧：

  • 分组选择器 (Group)：一次性点名多个。如给所有的 input 和 button 同时扩充内边距。
    input, button { padding: 10px; }
  • 后代选择器 (Descendant)：仅打击隶属于特定祖宗的元素。中间用空格隔开。
    #your-name h2 { color: olive; }（解释：选中那些包裹在 ID 为 your-name 元素里面所有的 h2 标题变身橄榄色。）

🧪 学习验证

❓ 理解检测

1. 你希望一个段落文字的上边框之外能与顶端留出一点白色的呼吸距离。你应该更改盒子模型的哪个值？
A) 增加 Padding-top，因为它可以拉大距离。
B) 增加 Margin-top，因为它负责边框外的外部排斥距离。
👍 正确！ 解析：Padding 会导致自己的底色被拉长填冲，它负责内部缓冲空间；Margin 负责外部的安全距离，把邻居（或者是页面的边缘）推远。
2. 在没有设定 border-box 的默认状态下，一个 width: 100px; padding: 10px; border: 2px solid; 的盒子，它被浏览器算出来的物理显示总宽度是多少？
A) 124像素
B) 100像素
👍 正确！ 解析：默认计算方式会累加：100(本身宽) + 左padding 10 + 右padding 10 + 左border 2 + 右border 2 = 124像素。这也是为什么大家现在写 CSS 都在开头用通配符 `*` 套入 `box-sizing: border-box`。

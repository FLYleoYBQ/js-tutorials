配置代码编辑器 (Setting Up Our Code Editor)

📌 知识脉络
  • 前置知识：无

🎯 概述

每一位优秀的工匠都需要属于他们的专属画笔。对于 Web 开发者而言，最重要的就是代码编辑器。本章节我们将确保你拥有业界最主流的环境套装，从而与课程视频中呈现的样子保持百分百一致，这将极大避免你在视觉上产生的认知摩擦。

🛠️ 必备基础层工具

1. Visual Studio Code (VS Code)：当今业内绝对的第一、最流行、也最强大的免费代码编辑器。请确保在你的系统（Windows, Mac, Linux 皆可）上完成下载安装。

2. Google Chrome：我们将用最新版本的 Chrome 浏览器测试并预览所有的 JS 代码。

⚙️ 编辑器个性化配置 (Jonas 同款)

为了让它看起来和视频里的教学界面完全一致，我们建议修改以下扩展及配置。

  • 主题背景色 (Theme)：打开左侧 Extensions（扩展），搜索并安装 Monokai Pro。如果你不想安装收费扩展（即使它不付钱也能用），你可以切换到内置的 Monokai Classic，它是极具相近色彩分布的平替版。
  • 文件图标 (File Icons)：在主题里将 File Icons 切换到 Seti 以享受极简的设计。

🎯 核心设置项调整 (Settings) ：

  1. Auto Save → 设置为 on focus change（当你离开代码编辑框点击别的地方时，自动保存文件，告别手动保存的烦恼）
  2. Format on Save → 选择 勾选 (on)（保存时自动格式化整理代码，后续章节会接入 Prettier 一起用）

到这步为止，你的本地代码编辑器就已经做好了起飞的准备。在后续章节，所有的神奇魔法都将发生在这个舞台上！

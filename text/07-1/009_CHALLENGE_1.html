CHALLENGE #1: Game Reset

🏆 1. 挑战任务发布

目前我们的游戏虽然能玩，但玩完一次后必须 刷新浏览器页面 才能进行下一局。

刷新页面是一个不好的选择。因为一旦重载浏览器，所有的内存数据就会清空（这样我们就无法在后续加入“历史最高分”的记录了）。因此，你的挑战就是：

目标： 实现左上角 .again（再来一局）按钮的功能。点击它时，整个游戏界面和内部数据应恢复到刚打开网页时的初始状态，而不要重新加载整个浏览器。

💡 2. 攻克提示步骤

如果你感到无从下手，请跟随以下四个步骤完成代码编写：

  1. 选择带有 .again 类的按钮元素，并给它挂载一个 'click' 事件监听器。
  2. 在事件处理函数 (匿名函数) 中，恢复两个核心状态变量 (State Variables) 的初始值：
    • 将 score 重置回 20。
    • 重新生成一个新的 secretNumber 秘密数字。(注意：如果你之前用 const 声明了它，你需要去把原代码改为 let secretNumber = ... 才能重新赋值)
  3. 恢复在屏幕上展示的数据/内容为初始状态：
    • 提示词 .message 恢复为 'Start guessing...'
    • 分数面板 .score 显示重置后的 20 分。
    • 中间的神秘方块 .number 恢复成问号 '?'
    • 重要：用来输入的 .guess 框内值 value，应当设置为空字符串 '' (代表清空输入)。
  4. 恢复之前变动的 CSS 样式：
    • 将 body 的背景色 backgroundColor 改回原来的黑灰色：'#222'。
    • 将问号盒子的 width 缩窄回：'15rem'。

现在，去你的代码编辑器中尝试自己写出来吧！肌肉记忆是最好的老师。实在写不出或者写完后，再展开下方的标准答案比对。

🔑 3. 解决方案

document.querySelector('.again').addEventListener('click', function() {
  // 1. 重置内部状态 (State)
  score = 20;
  secretNumber = Math.trunc(Math.random() * 20) + 1;

  // 2. 刷新屏幕显示 (DOM Text)
  document.querySelector('.message').textContent = 'Start guessing...';
  document.querySelector('.score').textContent = score;
  document.querySelector('.number').textContent = '?';
  
  // 3. 清空输入框 (DOM Input Value)
  document.querySelector('.guess').value = '';

  // 4. 洗去胜利状态的样式 (CSS Styles)
  document.querySelector('body').style.backgroundColor = '#222';
  document.querySelector('.number').style.width = '15rem';
});

注意看代码的匿名函数 (Anonymous Function)：
我们没有把它赋给任何变量，而是直接包裹在 function() { ... } 里作为第二参数传给了监听器。这就是标准的“当某事发生时才唤醒我”的设计模式。有了这项能力，我们在下一节加入『最高分记录』时就不会因为页面刷新而把数据丢失了。

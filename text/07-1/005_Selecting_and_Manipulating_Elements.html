我们已经知道 DOM 是什么了，现在让我们的手弄脏，实际去体验修改页面元素的快感！

1. 覆盖普通元素的文本 (textContent)

在之前的尝试里，我们用了 .textContent 老老实实地去**读取**了 <p class="message"> 里面的文本。但是对属性来讲，它不仅能够被读取出来打印，你更可以通过等号 = 反向往里面**写字**！

让我们模拟一下游戏获胜时改变提示信息的场景：

script.js 与 HTML 视图渲染区
【提示栏】 Start guessing...
【分数栏】 20

如你所见，只要使用赋值等号 =，我们就做到了真正的 DOM 操作：强行覆盖了页面节点内本来刻板书写的文本数据。数字更新、多语言切换，底层全都是这套逻辑。

2. 操纵 Input 输入框的值 (value)

普通的呈现型元素（如 p标题, div盒子, span内联字）统统用 textContent 来提取内部文本。但对于诸如表单输入框 (Input / Textarea) 这样用来和用户交互的容器元件，它们有自己专属的属性词：value。

💡 核心区别：
普通展示框用：Element.textContent
用户填空题用：InputElement.value

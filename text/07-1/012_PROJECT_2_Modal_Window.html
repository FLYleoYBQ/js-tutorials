PROJECT #2: Modal Window (模态窗口项目)

📺 来源：012 PROJECT #2 Modal Window.en.srt 📂 章节：第 07 章

1. 全新真实组件：模态窗口

告别猜数字的纯数据游戏，我们将要实现的是前端开发中最实用、见得最多的 UI 组件 —— Modal Window (模态窗口 / 弹窗)。

当你点击某个按钮时，背景会暗下来变模糊 (通过遮罩层 Overlay 实现)，中间会弹出一个白色的内容控制面板，而它可以通过右上角或点击背景被关闭。这个项目的本质：不是用 JS 从凭空拉出 HTML 标签，所有的弹窗 HTML 代码本来就在页面里，我们只是用 JS 去控制它们的“显示”与“隐藏”。

2. 专业起手式：预存变量

上一个项目中，为了简单起见，我们每次修改 DOM 都满篇写着 document.querySelector(...)。在实际项目开发中，这种反复执行查找 DOM 的动作极度消耗性能且代码丑陋。

好的习惯是：在文件的顶部，把项目中需要操控的 DOM 元素一次性抓取完毕，并保存在常量中。 等后续需要的时候，直接召唤变量名即可！

// 专业工程化代码起手式：统一抓取
const modal = document.querySelector('.modal');
const overlay = document.querySelector('.overlay');
const btnCloseModal = document.querySelector('.close-modal');

3. 痛点遭遇：批量抓取与 querySelectorAll

在这个项目中，我们要实现“点击页面上的任意 3 个按钮，都能呼出弹窗”。这三个按钮身上带有同一个 Class 类名：.show-modal。

如果我们还是用老办法选人：

const btnsOpenModal = document.querySelector('.show-modal');
console.log(btnsOpenModal); 
// 运行后发现，尽管有3个按钮，但控制台只打印了第 1 个！

🚨 querySelector 的致命短板
document.querySelector 就像是一个只认死理狙击手。它只会从网页的最上面开始扫描，只要一碰到第一个符合条件的元素，它就立刻停止工作并交差。对于下面其他同名的元素，它直接视而不见。

为了把所有携带该类名的按钮一网打尽，我们必须请出它的终极强化形态：querySelectorAll (注意末尾的 All)。

// 注意这里的 All ！
const btnsOpenModal = document.querySelectorAll('.show-modal');
console.log(btnsOpenModal);
// 控制台打印出：NodeList(3) [button, button, button]

4. NodeList (节点列表) 与遍历循环

querySelectorAll 返回的数据类型并不是一个单纯的元素对象，而是一个叫做 NodeList (节点列表) 的包裹。

对于初学者而言：就把 NodeList 当作是我们在基础知识部分学过的 数组 (Array) 来看待！它同样拥有 length 属性，同样可以用中括号 [i] 通过索引值来提取里面的每一个小块。

既然它是数组结构，那么想要逐个处理里面的所有按钮元素，我们就又能祭出老伙计 —— for 循环了：

const btnsOpenModal = document.querySelectorAll('.show-modal');

// 使用 for 循环逐个摸排节点列表中的按钮
for (let i = 0; i < btnsOpenModal.length; i++) {
  // 把它们的内部文字依次打印出来~
  console.log(btnsOpenModal[i].textContent);
}

通过这套机制，我们便拥有了批量对元素发号施令的超能力。下一节，我们将利用这个循环为它们逐个绑定事件触发器！

🧪 学习验证

1. 你的页面中有 5 个 `<li class="list-item">`。当你执行 `const items = document.querySelector('.list-item');` 时，变量 items 里装的是什么？
A) 包含这 5 个 li 元素的 NodeList (节点列表)。
B) 仅仅只有排在网页最前面的第 1 个 li 元素。
C) 报错，因为由于是多个元素，却使用了针对单体的查找函数。
👍 正确！ 解析：记住 `querySelector` 的死规定：“只要一碰到第一个兄弟，管你后面还有没有同名的，老子不查了直接回城”。要想全部带走必须用 `querySelectorAll`！

Manipulating CSS Styles (动态修改 CSS 样式)

📺 来源：008 Manipulating CSS Styles.en.srt 📂 章节：第 07 章

除了文字内容，DOM 树同样包含了所有元素的样式排版信息。通过 JavaScript 来瞬间改变页面颜色或排版，是网页动效和游戏反馈的重要手段。

在猜数字游戏中，当玩家猜中数字（胜利）时，我们将做两件事：把背景变成代表胜利的亮绿色，并把页面中间的那个问号方块横向拉宽两倍以示庆祝！

1. 操纵 CSS 样式的基础写法

要想更改样式，我们仍需先用 document.querySelector 揪出那个元素，随后接上 .style 属性进入样式库，最后再跟上你想要更改的具体 CSS 属性名。

// 选中全网页身体，将其背景色改为绿色 (#60b347)
document.querySelector('body').style.backgroundColor = '#60b347';

💡 底层实质：当你在 JavaScript 中执行上述代码时，浏览器其实是在帮你在那个 HTML 元素的标签里，写了一个叫做 style="..." 的内联样式 (Inline Styles)。
这并不是去真正修改你的 .css 文件。内联样式的显示优先级很高，所以屏幕上立刻就能生效覆盖。

2. 骆驼拼写法 (CamelCase) 铁律

这可能是编写 DOM CSS 时最大的槽点与坑！

在原来的 CSS 文件中，背景色的写法是带有连字符减号的：background-color。
然而，在 JavaScript 里决不允许在变量名里出现减号 - (会被当成减法运算)。

因此，所有的两单词以上的 CSS 属性，到了 JavaScript 中，都必须无缝切换为 骆驼拼写法 (CamelCase)，即去掉减号，第二个单词首字母大写：

  • ❌ style.background-color (语法错误)
  • ✅ style.backgroundColor (正确)
  • ❌ style.border-radius
  • ✅ style.borderRadius

3. 赋值必须是字符串 (String)！

你在等号右边指派的 CSS 值，永远必须用引号包裹起来变成字符串，哪怕它看起来是由数字组成的也是如此。并且不可遗漏像 px, rem 这样的单位。

const numberBox = document.querySelector('.number');

// ❌ 错误：纯数字或未加引号的组合，浏览器将无法解析
numberBox.style.width = 30; 
numberBox.style.width = 30rem; 

// ✅ 正确：带引号的纯种文本字符串
numberBox.style.width = '30rem';

1. 若想利用 JavaScript 将元素的上下外边距（在 CSS 里叫 `margin-top`）设置为 25 像素，以下哪句代码不报错且最正确？
A) element.style.margin-top = 25px;
B) element.style.marginTop = 25;
C) element.style.marginTop = '25px';
👍 正确！ 解析：要闯过两道关卡：第一卡（去中划线改用 marginTop 骆驼式拼写）；第二卡（等号右侧的值必须套上引号变成字符串，并写上单位 px）。

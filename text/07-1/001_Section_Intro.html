🚀 欢迎来到 DOM 操控的世界

欢迎回来！是时候来搭建我们第一个拥有可视化用户界面 (Visual User Interface) 的项目了。

一直到现在的课程为止，我们都在幕后学习 JavaScript “语言本身”的核心逻辑与基本功。但是在这绝赞的一章中，我们要把开发水平拉升到一个全新的层次——学会如何让 JavaScript 与真实的网页产生动态交互，这在业界被称为 DOM Manipulation (DOM 操控)。

当你看着代码第一次在浏览器里“活过来”的那种兴奋感是无与伦比的。

🛠 本章预告：三大实战项目

在这一个章节里，为了让你把基础的 DOM 操作彻底肌肉记忆化，我们不仅仅只做一个项目，而是会连续制作三个漂亮且功能各异的小项目！

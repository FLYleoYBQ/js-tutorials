Resetting the Game & Scoping Preview (重置游戏与作用域启蒙)

📺 来源：019 Resetting the Game.en.srt 📂 章节：第 07 章 (终章)

游戏结束了，屏幕变成了黑金色，但玩家想要再来一盘！我们需要实现 “New Game” 按钮的功能。
很显然，按这个按钮时要做的操作，和网页第一次刚加载时做的“初始化操作”是一模一样的 (清理分数、重置玩家、卸下赢家状态)。为了满足 DRY（不要重复自己）原则，我们需要把这些代码装包进一个专属函数 init() 中。

1. 封装重置函数 (init)

我们把开局的所有赋值代码剪切放入 init 函数中，包括去除赢家的黑白背景（classList.remove('player--winner')），恢复左边玩家为活动状态（classList.add('player--active')）。

const init = function() {
    scores = [0, 0];
    currentScore = 0;
    activePlayer = 0;
    playing = true;

    // 清零页面文字
    score0El.textContent = 0;
    score1El.textContent = 0;
    current0El.textContent = 0;
    current1El.textContent = 0;

    diceEl.classList.add('hidden');
    // ...去除胜者类名，重置活动玩家等 CSS 代码
};

2. 致命坑点：揭秘作用域 (Scoping)

这里有一个极其容易踩雷的新手巨坑！如果你像下面左图一样，直接把之前的变量定义打包丢进了函数里，你会发现你的游戏立刻死机报错：playing is not defined！

❌ 错误：封闭在函数内的死水
const init = function() {
  // 注意前面的 let！
  let scores = [0, 0];
  let playing = true;
};

init();

// 在下方按钮的回调函数里调用
btnRoll.addEventListener('click', function(){
  // 💥 报错！找不到 playing！
  if(playing) { ... } 
});
✅ 正确：声明在外，赋值在内
// 1. 在最高级别的天地声明空箱子
let scores, currentScore, activePlayer, playing;

const init = function() {
  // 2. 函数内部只是给外面的箱子装填数据！
  scores = [0, 0];
  playing = true;
};

init(); // 脚本加载时先执行一次装箱

btnRoll.addEventListener(..., function(){
  // ✔️ 完美运行！大家都在用外面的全局箱子！
  if(playing) { ... }
});

💡 作用域 (Scoping) 初探：
当你在一个大括号 `{}` 内用 `let` 创造变量时，这个变量的生命和视野就被死死关在了这个大括号构成的“房间”里。外面的人看里面是隐身的！
解决办法：老老实实在外面大厅宣告 (Declare) 他们的存在（但不给值），然后在房间里再去给他们赋值 (Assign)。

3. 纯净回调：不带括号的调用

我们要在点击“New Game”的时候去跑 init 引擎去重置数据。这里请注意一个常考细节：

// ❌ 错误写法
btnNew.addEventListener('click', init()); // 加了括号，意味着你在绑定事件时立刻就执行了！

// ✅ 正确写法
btnNew.addEventListener('click', init);

就像我们之前把匿名函数 function(){} 当作参数传进去一样，我们把 init 当作一个“打死不发出的子弹包”交给了监听器。只有当用户真真切切地按下鼠标的那一刻，浏览器底层机制才会替你去扣下扳机执行它。

🧪 学习验证

1. 为什么在 `init` 函数内部直接写 `let currentScore = 0;` 会导致点击骰子按钮时报错找不到变量？
A) 因为 `init` 函数没有使用 `return currentScore` 把值弹出去。只要加上 Return 就修好了。
B) 因为使用 `let` 或 `const` 声明的变量具有“块级/函数级作用域”。如果在函数内生成，它对于外界代码就是隐身隔离的。因此只能将他们的外壳（声明）提升至全局空间。
👍 正确！ 解析：这就是经典的作用域隔离！声明（创造户口）和 初始化赋值（塞入存款）是两件独立的事。全局户口才能让所有函数都来取款。

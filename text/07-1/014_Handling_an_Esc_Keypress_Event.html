Handling an "Esc" Keypress Event (处理按键事件)

📺 来源：014 Handling an Esc Keypress Event.en.srt 📂 章节：第 07 章

现代网页体验中，当你打开一个弹窗时，通常习惯顺手敲一下键盘左上角的 Esc 键来将其关闭。为了实现这个高级特性，我们需要监听 全局键盘事件 (Keyboard Events)。

1. 监听全局事件：绑定于 document

不同于前面“绑定在某个具体的按钮上”的点击事件，键盘敲击是全局发生的：用户无论把鼠标放在页面的哪个角落按下键盘，系统都应该捕获到。因此，我们要把事件监听器绑定在最高指挥官 —— document 身上。

键盘事件通常有三种：keydown (按下时)、keypress (持续按住时) 和 keyup (松开时)。最常用的触发时机是刚按下去的那一瞬间：

document.addEventListener('keydown', function() {
  console.log('有键盘按键被按下了！');
});

现在，只要在这个网页里敲击任意按键，控制台都会冒出这句话。但这带来了一个巨大的问题：如果按什么键都会触发，JavaScript 到底怎么知道我刚刚按下的是不是 Esc？

2. Event (事件对象) 解密

其实，每当事件（点击、按键、滚动...）在网页上发生时，浏览器底层绝不只是干巴巴地喊一声“事件来了”。它还会非常贴心地 生成一个包含大量事件详情的数据包裹（一个对象）。

我们只需要在回调函数的括号里写上一个变量名（通常惯例叫做 e 或者是 event），浏览器在自动呼出这个函数时，就会顺手把这个包含了情报的“包裹”硬塞进这个变量里！

document.addEventListener('keydown', function(e) {
  // 把浏览器传进来的 e (事件对象) 拆开看看
  console.log(e);
});

去控制台敲击几下，你会发现每次敲击都会打印出一个 KeyboardEvent 对象，点开它，里面挂满了无数属性。而在这万千属性中，最耀眼的那一个叫 key。
如果你按弹射起步键，e.key 的值就是 "Enter"；如果按空格，就是 " "；按下逃生键，就是我们在寻找的 "Escape"！

💡 再次强化这套魔法机制：
你并没有在任何地方手动调用 function(e)。你只是写好了它。是当你的手指接触到键盘那一瞬间，浏览器底层的 JavaScript 引擎察觉到了，它主动召唤了你的函数，并作为跑腿小哥，将打包好的 e 对象“递”到了你的参数里。

3. 组合逻辑：仅当弹窗存在时按下 Esc 才关闭

既然拿到情报了，剩下的就是手到擒来了。只要判定按键名是 Escape 并且弹窗目前没穿隐身衣，就调用我们在上一节封装好的 closeModal() 关门大吉！

这里有另一个极其好用的 classList 方法：classList.contains('类名')。它负责侦查元素身上是否存在某一层衣服，返回布尔值（true/false）。

document.addEventListener('keydown', function(e) {
  // 1. 判断是否按了 Esc 键
  if (e.key === 'Escape') {
    
    // 2. 侦查弹窗目前有没有隐身衣
    // 逻辑：如果它身上 不包含 (!) hidden 类名，说明它现在正裸露在外（可见状态）
    if (!modal.classList.contains('hidden')) {
      
      // 满足条件：开干！关门！
      // 👉 注意这里是“主动执行”函数，必须带括号，因为它要立刻发生！
      closeModal(); 
    }
  }
});

还可以利用逻辑与 && 让代码更优雅（合二为一）：

document.addEventListener('keydown', function (e) {
  // 当“按了Esc” 与 “弹窗未被隐藏” 同时成立时，执行关闭
  if (e.key === 'Escape' && !modal.classList.contains('hidden')) {
    closeModal();
  }
});

1. 下面哪一句描述关于 `document.addEventListener('keydown', function(event) {...})` 中 `event` 参数的真相是最准确的？
A) 它是 JavaScript 提供的一个全局魔法关键字，由于它的名字长得像 event 所以带有特殊功能。
B) 它只是一个形参的名字（叫 x 或 e 都可以）。之所以里面有数据，是因为浏览器在调用这个回调函数时，**主动传入**了一个由它生成的包含被触发事件详情的对象实例。
👍 正确！ 解析：这就是回调函数与 JavaScript 事件循环交互的底层哲学！浏览器：“你只管留个收件人的名字(形参)，出事了我自然会把档案袋抱好塞给你”。

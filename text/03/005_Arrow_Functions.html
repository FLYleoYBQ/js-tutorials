🎯 概述

上节课我们学习了传统的函数声明与表达式。ES6 为 JavaScript 带来了一种极简主义：箭头函数（Arrow Functions）。它本质上是函数表达式的“瘦身版”，非常适合写那种小巧单行的方法。

2. 多参数与多行逻辑

随着业务逻辑的叠加，简写模式不得不“退化”出部分的括号，以包容更多信息：

  • 如果要执行多行代码：必须加回 {} 块，并且必须手动写 return（因为它不知道你要返回哪一行了）。
  • 如果有多个参数：必须加回 () 将参数包裹。
complex-arrow.js

⚠️ 底层隐患提醒：
虽然箭头函数看起来酷炫、简短，但不要完全舍弃传统的 function 写法。为什么？因为箭头函数天生失去了属于自己的 this 关键字（在对象方法那一节我们会详细解剖这个大坑）。目前为止，我们将主要使用正规的函数声明或表达式，以确保你扎实地理解作用域。

🧪 学习验证

❓ 理解检测

1. 下图哪个箭头函数语法是完全正确的？
A) const sum = x, y => x + y;
B) const double = x => { x * 2 };
C) const sayHi = () => console.log('Hi');
解析： C 是正确的。
A 错：多个参数必须带括号 (x, y)
B 错：如果用了 {} 大括号包住，那就失去了隐式返回特效，必须显式加 return x * 2 才会有值丢出来。
C 虽无参数，但通过空括号 () 是完全合法的简写。

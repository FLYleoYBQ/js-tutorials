🎯 循环遍历数组的核心绝技

上节课学会的 For 循环最致命的使用场景，绝对非遍历数组 (Looping Arrays)莫属。因为数组里面堆叠了大量的同类数据，而人力的复制粘贴是有限的。

如果你有一个装满 5 个人生元素的数组 jonasArray，如何全自动读取它？

For 循环要素 数组专属配置方案 原理解析
1. 初始变量 let i = 0; 零号起跑线！ 数组永远是 `Zero-based` （从0索引开始）。因此循环计数器 i (传统的 index 代称) 必须从 0 启动，而不是 1。
2. 极限条件 i < jonasArray.length; 绝世杀招！绝不写死 i < 5。通过 .length 动态抓取长度，即便数组未来变长，这里永远精确防爆。如果是 5 长度，那么索引是 0~4，恰好 < 5。
3. 递增齿轮 i++ 老规矩，一步一步稳步读取。

🏭 动态创建新数组 (Push模式)

我们不仅仅可以读取旧数组，我们还能同时在这条“传送带”旁边，组装一条全新的数组。例如，把出身年份阵列 years，批量转换成 ages 年龄阵列！

🛑 控制流中断指令：Continue 与 Break

有时候在这条履带传输带上，我们碰到了不想要的零件，甚至想要立刻终结这条产线。这就需要两颗物理按钮：

  • continue：跳过指令！立刻终止当前这一圈代码的执行，跳回到 ++ 齿轮步入下一圈！
  • break：终结毁灭指令！不仅终止当前圈，并且彻底撕碎整个 Loop 机器，立刻宣告停工！
const jonas = ['Jonas', 46, 'teacher', ['Michael']];

console.log("--- 只要字串，其他免谈 (CONTINUE) ---");
for (let i = 0; i < jonas.length; i++) {
    // 如果碰到了非字符串的东西，立刻跳过！
    if (typeof jonas[i] !== 'string') continue;
    
    // 数字和数组会被跳过，完全轮不到下面这行打印
    console.log(jonas[i], typeof jonas[i]); 
}

console.log("--- 发现数字，立刻关停机器 (BREAK) ---");
for (let i = 0; i < jonas.length; i++) {
    if (typeof jonas[i] === 'number') break; // 彻底毁灭停机
    console.log(jonas[i], typeof jonas[i]);
}

💡 总结：
For 循环与数组的结合，是 JavaScript 这套工业革命系统里最大的产能引擎。掌握 `i = 0` 和 `i < array.length` 这个固定肌肉记忆手势，你将会战无不胜！

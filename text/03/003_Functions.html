🎯 概述

如果说变量是存储数据的“盒子”，那函数就是处理数据的“加工厂”。本节课我们将深入了解在 JavaScript 中最为重要的构件——函数（Functions）。学完后，你的代码将从此拥抱极致的复用性（DRY 原则）。

1. 什么是函数？

简单来说，函数就是一段可以在代码中重复使用的代码块。当你需要完成某项特定任务时，只需把这段代码“打包”成一个函数。日后就可以随时随地调用它，避免一遍又一遍地复制粘贴（DRY 原则：Don't Repeat Yourself）。

2. 函数的核心机制：参数与返回值

仅仅能执行固定代码的函数虽然有用，但略显死板。通常我们需要给函数传递一些数据（顺手比作原料），让函数帮我们加工，最后把成品还给我们。

🧩 生活类比：榨汁机（Food Processor）
想象一台榨汁机：你投入几颗苹果和几颗橙子（参数 Parameters），机器开启加工运转（函数体体内的代码），最终顺着出口流出了一杯混合果汁（返回值 Return Value）。

🔁 数据传递流向图 (Data Flow) 追踪：

  1. 我们调用 fruitProcessor(5, 2)，数字 5 赋予了变量 apples，数字 2 赋予了 oranges。（实际传入的具体数值称为实参 Argument）。
  2. 函数执行时，内部拼装出 juice 字符串变量。
  3. 关键词 return 将 juice 抛出函数外部。一旦代码执行到 return，函数运行立即结束并交出数据。
  4. 在外部，我们将抛出来的结果捕获，并赋值给常量 appleJuice。

📝 动手练习

练习 1：算账机
写一个名叫 calcTotal 的函数。它接收两个参数：price（单价）和 quantity（数量）。函数内部计算总价并返回（return）。然后调用它计算 单价 50，数量 3 的总价，并打印到控制台。

💡 参考答案 
function calcTotal(price, quantity) {
    return price * quantity;
}
const total = calcTotal(50, 3);
console.log(total); // 150

❓ 理解检测

1. 关于 console.log() 和 return 的区别，以下哪项最贴切？
A) 它们是同一个东西，都用于输出结果。
B) console.log 只是在开发者面板打印文字用于查看；return 则是将真正的值从函数内部交出来，以便赋值给新的变量继续使用。
C) return 会在网页屏幕上弹出一个内容框反馈。
解析： B 是正确的。console.log 不会交出任何数据，如果尝试用变量接收它只会得到 undefined；而只有用 return 才能拿到真真实实的数据用于下一次运算。

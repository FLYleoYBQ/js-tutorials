Iteration: The for Loop (For 循环迭代)

🏋️ 健身房的重复灾难 (DRY)

我们曾学过 if/else 是 JavaScript 中的控制流结构 (Control Structures)。那么现在，欢迎认识同属于控制流的终极利器：循环 (Loops)。

所有编程语言的底层基因都带有自动化的血液，而循环正是我们解决**反复做同一件事**的关键设施。想象一下去健身房举铁，你需要做 10 组：

❌ 人工肉体级代码
console.log('Lifting weights rep 1 🏋️');
console.log('Lifting weights rep 2 🏋️');
console.log('Lifting weights rep 3 🏋️');
// ... 难道让你复制粘贴 10 遍甚至是 30 遍吗？
// 如果有一天，我们想修改后面的 Emoji 这将是末日级工作量！
✅ 全自动工业级循环
for (let rep = 1; rep <= 10; rep++) {
    console.log(`Lifting weights rep ${rep} 🏋️`);
}
// 搞定。不管是 10 遍还是 10 万遍，都只需两行代码。

🔬 解剖 For 循环的三要素

for 语句极其规整地由三个组件构成，它们被塞入小括号 () 内，组件之间**必须用分号 ; 严格隔开**：

组件阶段 代码写法 意义与职责
1. 起点指令 (Initial Value) let rep = 1; 在起跑线创造一个计数器变量。必须用 let，因为循环跑起来这数字在翻滚，不能用定死的 const。
2. 生死结界 (Logical Condition) rep <= 10; 只要这句条件计算是 True，循环体代码就会轰鸣地运转。只要它胆敢被判定为 False 时，整个机器瞬间熄火停机。 这是循环安全阀。
3. 齿轮推杆 (Counter Update) rep++ 在每一圈(iteration)代码行走到末尾时，我们该拿计步器 rep 怎么办？++ 是自增的优雅语法糖，代表 rep = rep + 1。强迫推着循环往前走。

💡 Jonas 黄金笔记本：
“For loop keeps running, while condition is true.” —— 只要中间那个条件的真理还没被打破，For 循环就绝不会停止工作。

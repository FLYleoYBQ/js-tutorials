🔥 Bonus: 通用平均数计算器 (calcAverage)

现在我们要更进一步，写一个极度通用的函数 calcAverage(arr)，它可以计算任何数组的均值（不论里面传来的是 bills, tips 还是各种鬼东西！）。这也是数组循环操作中绝对常见的一个模式，叫作“累加器模式”(Accumulator Pattern)。

const calcAverage = function(arr) {
    let sum = 0; // 必须是 let，因为我们要不停地在它上面叠罗汉

    // 疯狂叠罗汉累加环节
    for (let i = 0; i < arr.length; i++) {
        // sum = sum + arr[i]; 
        sum += arr[i]; // 更简洁的写法
    }

    // 出了循环以后，求均值
    return sum / arr.length;
}

// 现在我们计算一下那些生成的 totals 数组的均值有多大
// (确保先执行楼上的代码获取 totals 结果)
console.log(calcAverage([2, 3, 6])); // 测试预演：(2+3+6)/3 = 3.666..

Functions Calling Other Functions

📺 来源：006 Functions Calling Other Functions.en.srt 📂 章节：第 03 章

🎯 概述

真实世界中的机器往往需要互相配合，代码也一样。我们将探索在一个函数内部如何调用另一个函数。为了演示数据流向与组件拆分，我们搬出上一课的“榨汁机”，给它配一台新增的“水果切块机”。

1. 切小块机器：函数调用函数

假设我们现在的榨汁机无法直接榨整颗水果了，它需要提前将水果切成 4 小块。于是我们专门打造了一个新的机器 cutFruitPieces 函数，专门用来切算术乘法。

仔细体会刚才数据的游走过程：你从外界只传了 2 个苹果和 3 个橙子。但在这 fruitProcessor 的内部，这 2 和 3 自发成为了 cutFruitPieces 的实参。

2. 彻底贯彻 DRY 原则

有同学可能会问：“搞这么复杂干嘛？我直接在榨汁机里写 apples * 4 不就行了吗？”这就牵扯到我们一再强调的重构了：

🚨 初版冗余写法 (The Naive Way)
function processor(apples, oranges) {
    const applePieces = apples * 4;
    const orangePieces = oranges * 4;
    // ...
}
✨ DRY 重构写法 (The Refactored Way)
function processor(apples, oranges) {
    const applePieces = cut(apples);
    const orangePieces = cut(oranges);
    // ...
}

使用独立的切块机，是极具**维护性**的。想象一下，如果日后的需求突然要求把所有的水果切成 5 块，乃至切成10块，在冗余写法下你可能要满代码库地去找散落的乘号进行魔改，那将是 Bug 滋生的温床。而在重构写法下，我们只需要去那个独立的 cutFruitPieces 函数里**修改唯一的一处**即可。这就是 DRY 原则的魔力归途。

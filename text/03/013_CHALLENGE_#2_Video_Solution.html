🏆 Coding Challenge：智能小费计算器 2.0版

💰

背景介绍：
又到了该死的小费环节！上次你帮 Steven 用 if/else 写了一次小费计算器，现在你学会了超酷的数组和函数技术，是时候把它升级成可以批量处理多个账单的究极版本了！

📋 任务清单（Tasks）

  1. 写一个函数 calcTip。该函数仅接收任意一笔账单金额 bill。
  2. 在函数内必须使用你学过的三元运算符 (Ternary Operator)，返回该账单应付的小费：
    规则：如果账单金额在 50 到 300 之间（含两端），则小费为 15%；其他金额的小费则一律为 20%。
  3. 建立一个名为 bills 的数组对象，里面含有这三次大餐的花费测试数据。
  4. 建立第二个数组叫做 tips。要求：在里面调用 calcTip 计算出 bills 对应位置每一个账单的小费！
  5. 🏅 Bonus: 建立第三个名为 totals 的数组对象，计算每一顿饭总共花出去的最终打款数字 (老规矩：Bill + Tip)

🧪 测试数据集（Test Data）

  • 三天晚上的饭钱分别是：125, 555, 和 44。

💻 实战沙盒

你已经学会向 Array 丢入带有返回值的 Function 表达式了，所以 tips 数组里你该怎么堆叠它？切记：数组和数组绝不可直接相加减！

💡 Jonas 官方解法揭秘 (Spoilers! 先自己试哦)

如果在 totals 的计算里，你试图使出 bills + tips 这种骚操作，还记得上一节课你看到了什么下场吗？（它们会被强行黏合成没意义的字符串！）正确的做法始终是精确制导到数组里的某个“槽位”。

1️⃣ 核心引擎 calcTip：由于三元运算符太完美了，只需一行即可。你可以写成标准表达式或者箭头函数，这里我们保留老手最爱的普通函数写法增加可读性：

const calcTip = function(bill) {
    return bill >= 50 && bill <= 300 ? bill * 0.15 : bill * 0.20;
}
/* 激进极简党的箭头函数版本：
const calcTip = bill => bill >= 50 && bill <= 300 ? bill * 0.15 : bill * 0.20;
*/

2️⃣ 基础账单阵列：一定要用复数名称养成好习惯！

const bills = [125, 555, 44];

3️⃣ 动态核算阵列 tips：这是本节课的王牌杀招。我们在构建一个新数组时，塞进去的并不是定值的死数字，而是实时的函数调用指令！JavaScript 会贴心帮你把值算出来再排进数组的新坑位：

const tips = [
   calcTip(bills[0]), 
   calcTip(bills[1]), 
   calcTip(bills[2])
];

4️⃣ 最终加总汇总阵列：

const totals = [
    bills[0] + tips[0],
    bills[1] + tips[1],
    bills[2] + tips[2]
];

console.log(bills, tips, totals);
// Output: 
// [125, 555, 44]
// [18.75, 111, 8.8]
// [143.75, 666, 52.8]

大功告成！通过巧妙利用数组元素的解包重组，我们把干瘪的代码变成了极具威力的数据处理车间。

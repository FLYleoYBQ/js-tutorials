🧐 方法到底是什么？

JavaScript 本身为数组挂载了无数好用且强大的原厂内置功能模块，我们不用自己造轮子可以随便调用它们。这些寄生在数组身上的独占“功能函数”，就被称为 Methods(方法)。

调用方法只需通过在数组变量后面加个点 . 就能拉出它的技能列表，今天我们精讲绝对绕不开的最基础四大系列方法。

➕➖ 第一系列：增与删的操作法门

往数组里加人、和把人踢出数组，都有针对于“尾部”和“头部”的操作方法。有趣的是，这些“函数命令”不仅仅只是埋头苦干，它们还会抛出非常有用的 返回值 (Return Value)！

➕ 增加元素 (Add Elements)

  • push(): 在数组末尾推入新元素。改变原数组，并返回增加完后的新长度。
  • unshift(): 在数组队首强插新元素。改变原数组，返回新长度。

➖ 移除元素 (Remove Elements)

  • pop(): 将处于数组末尾的一个元素给“弹出（剥除）”掉。不需要传参数，并它返回的是被删掉的那一颗可怜的元素尸首。
  • shift(): 删除处于首位的元素，同样返回被删除的元凶。

📝 词汇速记表 (Cheat Sheet)

方法名 操作位置 产生的变异 方法抛出的返回值是什么 (Return Value)?
push(x) 末尾 (End) 追加 变异完成后的全新长度(Length)数字
unshift(x) 队头 (Beginning) 前插 变异完成后的全新长度(Length)数字
pop() 末尾 (End) 删除 那个被砍出列的可怜元素内容本身
shift() 队头 (Beginning) 删除 那个被踢出长队的第一号元素内容本身
indexOf(x) 全范围 无 精准的数字索引位置（没找到就丢出 -1 牌子）
includes(x) 全范围 无 非黑即白的布尔值 (true / false)。包含此人则真！

🏆 Coding Challenge：体重指数对决 (对象版)

⚖️

背景介绍：
Mark 和 John 这两兄弟还在比拼他们的 BMI（体重指数）！但这次，我们不再写干瘪的变量。我们要运用刚刚掌握的**对象 (Objects)** 和 **方法 (Methods)** 技能，将他们的数据彻底武装重构！

📋 任务清单（Tasks）

  1. 为他们两人分别各建立一个对象（mark 和 john）。
  2. 对象中必须包含他们的个人属性：全名 (fullName)、体重 (mass) 和 身高 (height)。
  3. 分别为两个对象添加一个名为 calcBMI 的方法，作用是计算当前人员的 BMI。
  4. 关键要求： 在方法中，要求直接将算出的 BMI 值新建为对应对象的新属性 (叫作 bmi)，并同时将此结果 `return`。
  5. 最后拼装出一句话打印："John Smith's BMI (28.3) is higher than Mark Miller's (23.9)!" （当然，根据实际数据情况输出胜者）。

🧪 测试数据集（Test Data）

  • Mark Miller： 体重 78 kg，身高 1.69 m。
  • John Smith： 体重 92 kg，身高 1.95 m。

💻 实战沙盒

牢记：任何在对象方法内部访问自身其他属性的尝试，都必须依靠神圣的 this 统帅。

challenge3.js
💡 Jonas 官方解法揭秘 (Spoilers!)

1️⃣ 定义与方法固化：

const mark = {
    fullName: 'Mark Miller',
    mass: 78,
    height: 1.69,
    calcBMI: function() {
        // 计算时即创建 'bmi' 属性
        this.bmi = this.mass / this.height ** 2;
        return this.bmi;
    }
};

// 后期你将会学到 面向对象(OOP)，届时无需强行粘贴两份一样的方法代码！
const john = {
    fullName: 'John Smith',
    mass: 92,
    height: 1.95,
    calcBMI: function() {
        this.bmi = this.mass / this.height ** 2;
        return this.bmi;
    }
};

2️⃣ 点火启动！：如果你只是在这边写 `if(mark.bmi > john.bmi)`，你会拿到巨大的 `undefined`。因为只有先触发了 `calcBMI` 这两个方法开关，内部的 `this.bmi` 才会顺理成章地诞生。方法不靠自己调用。

mark.calcBMI();
john.calcBMI();
console.log(mark.bmi, john.bmi); // 终于有数字了！

3️⃣ 播报决胜：

if (mark.bmi > john.bmi) {
    console.log(`${mark.fullName}'s BMI (${mark.bmi}) is higher than ${john.fullName}'s (${john.bmi})!`);
} else if (john.bmi > mark.bmi) {
    console.log(`${john.fullName}'s BMI (${john.bmi}) is higher than ${mark.fullName}'s (${mark.bmi})!`);
}

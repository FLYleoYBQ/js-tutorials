Looping Backwards and Loops in Loops

📺 来源：021 Looping Backwards and Loops in Loops.en.srt 📂 章节：第 03 章

⏪ 逆流而上：倒序循环

很多时候我们需要以倒序的方式读取数组。比如数组元素长度如果是 5，那么起跑线（索引值）就不再是 0，而是 4、3、2、1、0！

这意味着我们的 For 循环三要素需要全体大换血：

  • 起点：不再是 0，而是 array.length - 1。
  • 限界：不再是小于长度，而是只要 i >= 0 就要继续跑！
  • 齿轮：不再是累加向上 i++，而是递减退档的 i--！
const jonas = [
    'Jonas',
    'Schmedtmann',
    2037 - 1991,
    'teacher',
    ['Michael', 'Peter', 'Steven']
];

// 向后递减打印 4, 3, 2, 1, 0
for (let i = jonas.length - 1; i >= 0; i--) {
    console.log(i, jonas[i]);
}

🌌 宇宙套娃：嵌套循环 (Nested Loops)

你以为一个循环就完事了吗？如果有3组不同的肌肉训练，每1组动作要做5次呢？那意味着一共要做 15 次！这就是循环嵌套循环的世界。

底层规律：外层循环(Outer) 每前进一步，内层循环(Inner) 的机器必须完整地从头轰鸣到尾！

nested-loops.js

🔥 解析机器节奏：
当 exercise = 1 时，内部的 rep 会完整执行 1~5。等全部打碎完毕执行结束后，外部机器才跳表到 exercise = 2，内部 rep 重置为 1，进行新一轮从头计算。在嵌套渲染网格、处理二维数组时这将发挥核爆级威力！

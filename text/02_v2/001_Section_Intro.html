🚀 第 02 章：JavaScript 基础

📺 来源：001 Section Intro.en.srt 📂 章节：第 02 章

🎯 概述

欢迎来到课程的第一个核心编程章节。从这一章开始，你将正式踏入 JavaScript 语言的世界，学习构成所有程序的最底层基础构件。

在这一阶段，我们暂时不会触碰网页界面的构建（如 DOM 操作或事件监听）。相反，我们将全神贯注于语言本身的逻辑表达能力——如何声明数据、做出判断、进行运算。这些概念是未来一切高级主题（函数、对象、异步编程）的地基。

🗺️ 本章知识地图

以下是你将在本章中逐步解锁的核心知识点：

📦
值与变量
理解数据的最小单位——值，以及如何用变量这个"标签箱子"来存储和复用它们。
🏷️
数据类型
JavaScript 的 7 种原始数据类型：Number、String、Boolean、Undefined、Null、Symbol、BigInt。
🔒
let / const / var
三种声明变量的关键字及其作用域、可变性差异。
➕
运算符
算术、赋值、比较、逻辑运算符，以及运算符优先级规则。
🔀
条件判断
if/else 语句、switch 语句和三元运算符——让程序能够"做决定"。
📝
字符串与模板字面量
文本处理的利器：模板字面量让字符串拼接不再痛苦。
🔄
类型转换与强制转换
显式 vs 隐式类型转换，以及 JavaScript 令人困惑的 Truthy/Falsy 值。
⚖️
相等运算符与布尔逻辑
== vs === 的致命差别，AND / OR / NOT 逻辑运算。

🏆 学习目标

完成本章后，你将能够：
  • ✅ 在浏览器控制台和外部 JS 文件中编写并运行 JavaScript 代码
  • ✅ 使用 let、const 声明变量，并理解它们的核心区别
  • ✅ 区分 JavaScript 的各种数据类型并进行类型转换
  • ✅ 使用算术、比较、逻辑运算符进行数据运算
  • ✅ 编写 if/else、switch 和三元表达式实现条件逻辑
  • ✅ 使用模板字面量（Template Literals）优雅地构建动态字符串
  • ✅ 理解布尔逻辑（AND、OR、NOT）并应用于实际判断
  • ✅ 完成 4 个 Coding Challenge，巩固所学知识

💡 学习心态

🧠 重要提醒：本章的内容看似简单，但它们是一切的地基。后续章节中的函数、数组、对象、DOM 操作、异步编程……全都建立在这些基础概念之上。

不要着急去做酷炫的网页效果——先把语言本身的"说话方式"学透。地基不牢，高楼必塌。

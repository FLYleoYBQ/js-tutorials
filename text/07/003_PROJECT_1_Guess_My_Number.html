PROJECT #1: Guess My Number!

🎯 概述与游戏规则

欢迎来到我们的第一个项目：猜数字游戏 (Guess My Number!)。这款游戏采用了带有趣味的复古 80 年代街机风格设计。游戏的主要规则如下：

  • 程序会在 1 到 20 之间随机生成一个秘密数字。
  • 你在输入框中填入你猜测的数字，点击“Check (检查)”按钮。
  • 如果猜错了，右侧的信息栏会提示你是“太高了 (Too high!)”还是“太低了 (Too low!)”。同时你的初始分 (Score, 默认为 20) 会扣减 1 分。
  • 如果猜对了，信息栏显示“正确 (Correct number!)”，整个页面的背景将变成绿色，神秘数字会被揭晓。
  • 如果你的分时比历史最高分 (Highscore) 还要高，它将被记录为新的最高分。点击 "Again!" 可以重置游戏再玩一次。

1. HTML/CSS 结构初探

我们所有的视觉界面都是由 HTML 实现的。HTML 文档由一系列的元素 (Elements) 嵌套组成。

比如，网页右上角显示游戏提示信息的那段文字，在我们的 `index.html` 文件里长这样：


<p class="message">Start guessing...</p>

在 CSS 开发中，我们通过这个类名 .message 为它添加颜色和字体样式。而在 JavaScript 中，我们同样可以根据这个类名来“选中”它，从而在代码里操控它！

2. 我们的第一个 DOM 操作：querySelector

现在，我们要学习如何在 JavaScript 中抓取上面那个段落元素。我们将使用 document 对象上提供的一个极其强大的方法：querySelector。


// 选中类名为 message 的元素 (注意传入的字符串跟 CSS 选择器语法完全一致，前面有个点)
const messageEl = document.querySelector('.message');

console.log(messageEl); // 在控制台打印出来，你可以看到整个 <p> 标签

// 真正实用的是读取它内部的文本数据：
console.log(messageEl.textContent); // 输出: "Start guessing..."

💡 点操作符是从左到右执行的：
当你写 `document.querySelector('.message').textContent` 时：
1️⃣ 首先执行 `document.querySelector('.message')`，它返回一个真实的 DOM 元素对象。
2️⃣ 然后接着通过第二个点操作符 `.textContent` 读取刚才返回的那个 DOM 元素身上的文本属性。

🧪 学习验证

1. 当我们想在 JavaScript 中通过类名选择一个 HTML 元素时，使用的方法名称及语法格式是什么？
A) document.querySelector('.类名')
B) document.selectClass('类名')
正确答案：A。`querySelector` 方法之所以叫这个名字，是因为你可以把任何合法的 CSS 选择器作为查询条件传给它（比如类选择器 `.class`，ID 选其起 `#id`）。

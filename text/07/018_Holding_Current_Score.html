Holding Current Score

📺 来源：018 Holding Current Score.en.srt 📂 章节：第 07 章

🎯 概述

游戏机制的最后一大块拼图：保存分数 (Hold Score)。如果玩家在没掷出 1 之前胆怯了，他可以点击 "Hold" 按钮，把当前这波临时得分存进自己的“总金库”，然后主动把回合让给对手。而且，只要谁的总金库先达到 100 分，谁就赢了！

1. 使用数组存储双方总分

我们现在有两位玩家，他们各自需要一个总分。之前我们可以用 let score0 = 0; let score1 = 0;，但那样写代码就无法动态复用了。更聪明的做法是：用一个数组来存两人的分数！


// 在文件顶部的全局作用域声明：
// 下标 0 代表 Player 1 的分数，下标 1 代表 Player 2 的分数
const scores = [0, 0]; 

btnHold.addEventListener('click', function() {
    // 1. 把当前临时分加到当前活跃玩家的主管账户里
    // 恰好我们的 activePlayer 要么是 0 要么是 1，可以直接用来做数组的索引！
    scores[activePlayer] += currentScore;

    // 2. 更新 UI
    document.getElementById(`score--${activePlayer}`).textContent = scores[activePlayer];
    
    // 省略：判断是否获胜的代码...
    
    // 省略：切换玩家的代码 (之前写过了)
});

💡 设计模式： 将业务状态 (如 activePlayer 是 0 还是 1) 映射为数据结构（数组 scores）的索引，是极其优雅且常见的编程技巧。这就是为什么一开始坚持用 0 和 1 而不是 1 和 2 命名玩家的原因。

加完分立刻检查，如果达到或超过指定点数（为方便测试暂定为 20 分），该玩家就赢了。我们需要给他的 HTML 节点加上属于赢家的专属黑色背景 player--winner。


    // ...接上文 btnHold 的内部逻辑

3. 终极奥义：状态锁 (playing)

代码写到这里，表面上看似完美。但如果你继续点击 "Roll Dice" 按钮，你会发现：哪怕有人赢了，骰子依然能掷，分数依然能加，甚至触发连胜 Bug！

这就引出了游戏开发（以及复杂网页交互）中最核心的概念之一：全局状态流控 (State Variables as Locks)。我们需要一个开关，告诉整个程序“游戏是不是正在进行中”。


// 在文件顶部声明：默认游戏一打开就是开玩状态
let playing = true;

btnRoll.addEventListener('click', function() {
    // ⭐️ 封锁网关：只有在 playing 是 true 的时候，才允许执行大括号里的逻辑
    if (playing) {
        // ... 生成随机数、抛骰子、加分的逻辑 ...
    }
});

btnHold.addEventListener('click', function() {
    if (playing) {
        // ... 保存分数、检查是否及格 ...
        
        if (scores[activePlayer] >= 20) {
            // ⭐️ 有人赢了！立刻按下结束开关！
            playing = false;
            // 添加胜利 CSS...
        } else {
            switchPlayer();
        }
    }
});

利用这个布尔值变量 playing，当它变成 false 时，所有的事件监听器里的大块逻辑都会被 if (playing) 拒之门外，从而完美实现了“冰冻”整个游戏棋盘的效果！

🧪 学习验证

1. 我们引入 `playing = true/false` 的本质目的是什么？
A) 它是用来控制 CSS 动画播放和暂停的内置属性。
B) 它充当一个守门员/锁。通过它可以让我们写的事件处理函数知道当前系统处于什么阶段，从而决定是否应该忽略用户的点击操作。
正确答案：B。这就是非常典型的“状态驱动”。程序的行为什么时候该放行、什么时候该拦截，不由写死了的代码决定，而是由这些抽象的 State Variables 来控制。

📖 词汇速查表 (Cheat Sheet)

中文术语 代码 / 英文术语 简明释义
状态变量 State Variable 记录系统当前状况（如分数、是否结束、谁的回合）的变量。它们是应用的核心血液。
布尔型锁 Boolean Lock (e.g., let playing) 用 true/false 控制代码块是否应该被执行的一种常见编程模式。

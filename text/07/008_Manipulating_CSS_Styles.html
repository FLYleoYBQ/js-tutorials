Manipulating CSS Styles

📺 来源：008 Manipulating CSS Styles.en.srt 📂 章节：第 07 章

🎯 概述

在获胜的那一刻，我们希望游戏背景变成满屏的代表胜利的绿色，并且把揭晓的数字变宽拉长，营造出强烈的视觉反馈！这意味着我们不仅要操作文本或数字，现在我们还要用 JavaScript 去篡改网页的外观（CSS）。

1. 使用 style 属性更改 CSS

要通过 JavaScript 操作 DOM 元素的样式，我们需要魔法入口：.style 属性。当我们选中元素后，在此基础上加上 .style.属性名 就可以进行修改了。

下面这行代码，能将整个页面的背景颜色瞬间变为清爽的胜利绿：


// 当玩家猜对时执行：
document.querySelector('body').style.backgroundColor = '#60b347';

2. JavaScript 操作 CSS 的两大数据法则

如果你仔细看上面代码，会发现它跟平时写 CSS 似乎有点不一样。没错，有两条你必须死记硬背的法则，违背任何一个，页面都不会有任何反应：

① 驼峰命名法 (Camel Case) 替代横杠连写

在原生的 CSS 中，我们习惯使用连字符（横杠）来写属性名，如 background-color、font-size。但是，在 JavaScript 中，横杠 - 意味着“减法运算”！为了解决冲突，所有带横杠的属性名，到了 JS 这里必须全部改为小驼峰式命名。

  • ❌ document.querySelector('body').style.background-color (SyntaxError: 引擎以为你在做减法)
  • ✅ document.querySelector('body').style.backgroundColor

② 值必须是字符串 (String)，且必须带单位

当你设置高度、宽度或任何值的时候，你传给右边的值必须是被引号包裹的纯字符串 (String)！ 哪怕是数字也必须套进字符串里，并且如果它需要单位，也必须一并带上。


// 把包含数字框的宽度增加一倍 (原来的 CSS 设定是 15rem)

// ❌ 错误：给了个光秃秃的 Number 数字
document.querySelector('.number').style.width = 30;

// ✅ 正确：给的是包含了单位的完整字符串
document.querySelector('.number').style.width = '30rem';

3. 本质探秘：这修改的是什么 CSS？

你可能会好奇，用这种方式修改，我的 style.css 文件会被强行重写吗？

答案是：绝无可能！

你在 JS 里执行的这些代码，会在浏览器实时渲染的 HTML 标签上，贴贴纸一样加上一个 内联样式 (Inline Style) 属性。



<body>


<body style="background-color: rgb(96, 179, 71);">

💡 科普提示： 在 CSS 权重 (Specificity) 原则中，内联样式的权重极高，会瞬间盖过你写在 `style.css` 文件里的正常样式。这就是为什么 JS 修改外观总是立竿见影的原理。

🧪 学习验证

1. 我们想用 JS 把 `#title` 的外边距 (margin-top) 设为 50 像素。正确的代码是？
A) `document.querySelector('#title').style.marginTop = 50;`
B) `document.querySelector('#title').style.marginTop = '50px';`
正确答案：B。必须同时满足两大准则：属性名用小驼峰 (`marginTop`)，且赋予的值必须是一个带着有效 CSS 单位的字符串 (`'50px'`)。

CHALLENGE #1: Implement Game Reset

📺 来源：009 CHALLENGE #1.en.srt 📂 章节：第 07 章

🎯 概述

这是本课程的第一个代码实战挑战！目前我们的游戏玩完一局后就“死”了，除非刷新整个网页。但如果每次都刷新网页，我们不仅会丢失体验连贯性，更致命的是后面章节里我们要做的 Highscore (最高分) 数据也会一并灰飞烟灭！因此，我们需要利用 JavaScript 给左上角的 Again! 按钮编写重置功能。

🏆 挑战任务

📝 你的任务清单：

不要复制粘贴！尝试脱离教程独立手敲完成以下步骤：

  • 步骤 1： 选择 HTML 中 class 为 again 的按钮元素。
  • 步骤 2： 用 addEventListener 给它绑定一个 'click' 事件，并在回调函数中执行接下来的所有步骤。
  • 步骤 3（核心）： 在代码中，将控制命数的 score 变量恢复杂复为 20。并且一定要重新生成一个新的 secretNumber（秘密数字）。
  • 步骤 4（恢复文本）： 将那些通过 DOM 修改过的文本全部变回默认状态。
    • 提示语应该变回: 'Start guessing...'
    • 生命值分数应该变回 score 变量对应的 20。
    • 中央显示的神秘数字应该变回 '?'。
  • 步骤 5（清空输入）： 将输入框的 value 赋值为一个空字符串 ''。
  • 步骤 6（恢复 CSS）： 将 body 的 backgroundColor 恢复至黑灰色的 '#222'；将 .number 的 width 恢复到正常的 '15rem'。

💡 官方题解 (Solution)

👉 点击这里展开查看 Jonas 的标准答案逻辑 👈

如果你已经尝试过了，请对照下方代码检查你的思路。特别注意状态变量 (State Variables) 的更新和 let 的重要性。


// 最顶部的全局变量，由于重置游戏时我们需要重新计算并赋值，
// 所以当初声明 secretNumber 时，它必须是 let 类型，不能是 const！
let secretNumber = Math.trunc(Math.random() * 20) + 1;
let score = 20;

document.querySelector('.again').addEventListener('click', function () {
    // 1. 恢复核心状态变量 (重定义生命和再选一次随机数)
    score = 20;
    secretNumber = Math.trunc(Math.random() * 20) + 1;

    // 2. 恢复最初始状态的提示信息 (DOM Text)
    document.querySelector('.message').textContent = 'Start guessing...';
    document.querySelector('.score').textContent = score;
    document.querySelector('.number').textContent = '?';
    
    // 3. 将输入框输入的内容强行清空 (DOM Value)
    document.querySelector('.guess').value = '';

    // 4. 重置页面获胜留下来的 CSS 内联样式 (DOM Style)
    document.querySelector('body').style.backgroundColor = '#222';
    document.querySelector('.number').style.width = '15rem';
});

💡 易错点解析：匿名函数 (Anonymous Function)

注意在这个 addEventListener 里，作为第二个参数传进去打工的函数，它是没有名字的，我们称之为 匿名函数。由于它只为这个按钮点击服务一次，我们不需要给它起名或是用变量单独存起来。

通过这套连招组合拳，我们的应用现在就能在不刷新浏览器的情况下“涅槃重生”了！为接下来的“永久保存最高分”做好了完美的铺垫。

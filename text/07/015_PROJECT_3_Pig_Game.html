PROJECT #3: Pig Game

📺 来源：015 PROJECT #3 Pig Game.en.srt 📂 章节：第 07 章

🎯 概述

系好安全带，我们将进入本章的最后一个（也是最令人兴奋的一个）实战项目：Pig Game (双人掷骰子游戏)！
这个游戏将综合运用这几章学到的所有 DOM 操作知识，并且业务逻辑更加复杂，涉及到玩家轮换、临时积分叠加、总分记录等概念。

不过万丈高楼平地起。在处理复杂的转圈逻辑之前，我们第一步永远是相同的：理清需要操作哪些 DOM 元素，并设置好游戏刚启动时的初始状态。

1. 按 ID 取件的专车：getElementById

在这个项目中，两位玩家的总分数字面板在 HTML 里分别有各自的 ID，如 id="score--0" 和 id="score--1"。

虽然我们继续用之前学过的万能公式 querySelector('#score--0') 也没错，但这其实是大炮打蚊子。既然我们已经确切知道了该元素的身份证号 (ID)，浏览器专门为我们提供了一个性能稍快一点的“专车接口”：getElementById。


// 万能用法：需要传 CSS 选择器（带 # 号）
const score0El = document.querySelector('#score--0');

// 专精用法：不需要传 # 号，直接传 ID 名字就行！
const score1El = document.getElementById('score--1');

💡 性能差异提醒： getElementById 在底层运行速度确实比 querySelector 略快。但是在绝大多数普通的前端项目中（抓取几个元素而已），这种快慢是人类无法感知的。所以出于代码风格的统一，很多现代开发者甚至全部统一使用 querySelector。你只需要知道它存在，并记住传参时不加 # 即可。

2. 游戏开始前的代码初始化 (Init)

由于 HTML 原文件在写的时候可能带有占位符（比如积分显示 43，中间还挂着一张很大的骰子图片）。当 JavaScript 文件被加载时，我们必须通过 DOM 立即将它们“清场打回原形”，这个过程叫做 初始化 (Initialization)。

这包括两个动作：

  • 将分数的数字强行改写为 `0`
  • 给中间的骰子图片挂上我们上节课学过的 `hidden` 隐藏类

// 1. 元素抓取 (带上 El 后缀，以区别于后续纯数字状态的 score)
const score0El = document.querySelector('#score--0');
const score1El = document.getElementById('score--1');
const diceEl = document.querySelector('.dice');

// 2. 初始化初始状态
score0El.textContent = 0; // JS 会自动把数字 0 转换为字符串 '0' 以适应 DOM 文本！
score1El.textContent = 0;
diceEl.classList.add('hidden'); // 玩游戏前没掷骰子，画面保持干净

🧪 学习验证

1. 关于使用 `document.getElementById('title')`，下面哪种写法是正确的？
A) `document.getElementById('#title')`
B) `document.getElementById('title')`
正确答案：B。因为函数名已经明确写了自己是个「ID 选择器」了，所以参数不需要再画蛇添足地加上代表 ID 的 Hash `#` 符号了，直接给名字就行。这是跟 `querySelector` 最容易搞混的地方！

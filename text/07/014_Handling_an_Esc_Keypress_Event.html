Handling an Esc Keypress Event

📺 来源：014 Handling an Esc Keypress Event.en.srt 📂 章节：第 07 章

🎯 概述

我们的 Modal Window (模态窗口) 已经可以通过鼠标点击关闭了。但在体验优秀的网站上，按键盘左上角的 `Esc` 键 也能随时关闭弹窗。要实现这个功能，我们需要监听全局的键盘事件，并学会如何读取事件对象 (Event Object) 中的关键信息。

1. 监听全局键盘事件

键盘事件大多不特定于某一个具体的按钮或拉框，因此，我们通常把键盘监听器直接挂在整个文档 (document) 上。

与键盘相关的事件主要有三种：keydown、keypress 和 keyup。最常用的是 keydown，因为只要手指按下键盘，它就会立即触发。


document.addEventListener('keydown', function () {
    console.log('有按键被按下了！');
});

2. 事件对象 (Event Object) 揭秘

当我们按下键盘时，上面代码里的函数确实会被调用。但问题来了：JavaScript 怎么知道我按的是 Esc 还是回车？

每当一个事件发生时（无论是点击还是按键），浏览器都会在后台生成一个装满事件信息的对象 (Object)。如果我们想读取这些信息，只需要给事件处理函数留一个形参 (通常命名为 e 也就是 event 的缩写)，浏览器在调用函数时，就会自动把这个对象塞进去。


// 在圆括号中传入形参 e 接收事件对象
document.addEventListener('keydown', function (e) {
    // e 就是包含按键细节的大字典
    console.log(e.key); // 如果你按了 Esc，这里会输出 'Escape'
});

💡 大一统思维： 回想一下我们上一节说的，在这个函数里不要加圆括号去“主动调用”它，而是交给 JavaScript 根据事件发生来“被动调度”。正因为如此，JS 引擎在调度它的时候，才能够像发快递一样，把包含着按下什么键的包裹（Event Object）传给你的 e 变量！

3. 判断包含类名：classList.contains

仅仅知道按下了 Esc 还不够。如果模态窗口根本没打开，此时按 Esc 就不应该执行任何关窗逻辑（虽然目前代码只是再加一次 hidden 类，不会报错，但做无用功不是好习惯 ）。

我们可以使用 classList.contains('类名') 来询问元素：“你身上现在有这个类吗？”。它会返回 true 或 false。


document.addEventListener('keydown', function (e) {
    // 逻辑：如果按下的键是 'Escape'，并且模态框此时并没有被隐藏（说明它是打开状态的）
    // 注意这里 ! (NOT) 运算符的运用
    if (e.key === 'Escape' && !modal.classList.contains('hidden')) {
        // 由于我们上一节已经写好了 closeModal 函数，这里直接“手动调用”它！
        closeModal(); 
    }
});

🧪 学习验证

1. 在处理键盘事件的函数中：`document.addEventListener('keydown', function(e) { ... })`，这个小写字母 `e` 到底是由谁赋值传进来的？
A) 由我们开发者自己使用 document.passEvent(e) 传进去的。
B) 由浏览器的 JS 引擎自动传进去的。当事件触发时，引擎打包好一个记录着该事件（哪种按键、鼠标坐标等）的对象，并把它作为实参传给了我们留好的形参 `e` 坑位。
正确答案：B。这就是事件回调函数的核心工作流。JS 引擎充当了调度员。只要你在参数列表里声明了一个变量（常用 `e` 或 `event`），引擎就会贴心地把事件现场的所有情报送到你手上。

中文术语 代码 简明释义
键盘按下事件 keydown 当物理键盘上的任意按键被往下按压时触发（最常用的键盘事件）
事件对象 e (Event Object) 一个包含了当前所发生事件所有细节状态（如鼠标 XYZ 坐标、按了哪个 Key 等）的 JS 对象
检查类名是否存在 .classList.contains('名') 询问元素的 class 列表中是否包含指定的类名，返回布尔值

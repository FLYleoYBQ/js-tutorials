PROJECT #2: Modal Window

📺 来源：012 PROJECT #2 Modal Window.en.srt 📂 章节：第 07 章

🎯 概述

欢迎来到本章的第二个实战项目 —— 模态窗口 (Modal Window)。模态窗口是现代网页设计中极为常见的 UI 组件，通常用于显示重要信息、登录框或警告提示，它会在当前页面之上弹出一个浮层，并强制用户与之交互。

在这个项目中，我们不再像之前那样通过 JavaScript 创建 HTML 结构或者写繁琐的内联样式。相反，模态窗口的 HTML 和 CSS 早就写好了，只是被 display: none; 隐藏了起来。我们将学习如何通过 JavaScript 操控 CSS 类 (Classes) 来实现元素的显示与隐藏。

1. 项目准备：变量集中管理

为了避免像上个项目那样到处书写重复的 document.querySelector，这次我们要养成良好的工程习惯：在文件顶部，把所有需要操作的 DOM 元素一次性选中，并妥善存放到变量中。


// 使用与类名相近的变量名，增强代码可读性
const modal = document.querySelector('.modal');
const overlay = document.querySelector('.overlay');
const btnCloseModal = document.querySelector('.close-modal');

// 重点：触发弹窗的按钮有三个！
const btnsOpenModal = document.querySelector('.show-modal');
console.log(btnsOpenModal); // ⚠️ 结果：只选中了页面里的第一个按钮！

2. 批量选取的利器：querySelectorAll

上面的代码中，我们遇到了第一个坑。页面上有三个 class="show-modal" 的按钮，但 querySelector 只会返回它在文档里找到的第一个匹配元素，然后就收工了。

如果要一次性把所有符合条件的元素都抓出来，我们必须请出它的终极形态：querySelectorAll。


// 正确做法：加上 'All'
const btnsOpenModal = document.querySelectorAll('.show-modal');

// 打印出来看看是什么？
console.log(btnsOpenModal); 
// 输出: NodeList(3) [button.show-modal, button.show-modal, button.show-modal]

💡 什么是 NodeList？
querySelectorAll 返回的并不是一个真正的数组 (Array)，而是一个叫做 NodeList（节点列表） 的结构。虽然它不是纯血统的数组，但它长得像数组，有下标 [0]，也有 .length 属性，最重要的是，我们可以用 for 循环来遍历它！

3. 遍历 NodeList

既然拿到了包含 3 个按钮的集合，接下来我们就可以用传统的 for 循环，逐一为它们挂载事件或者读取属性了。


// 遍历 NodeList，打印每个按钮上的文字
for (let i = 0; i < btnsOpenModal.length; i++) {
    console.log(btnsOpenModal[i].textContent);
}

// 注意：如果 for 循环体只有一行代码，你可以省略大括号 {}
// for (let i = 0; i < btnsOpenModal.length; i++) console.log(btnsOpenModal[i].textContent);

🧪 学习验证

1. 关于 `querySelector` 和 `querySelectorAll`，下面哪种说法是正确的？
A) `querySelector` 性能很差，所以我们应该总是使用 `querySelectorAll`。
B) `querySelector` 只返回第一个查找到的元素，而 `querySelectorAll` 会返回包含所有符合条件元素的 NodeList 集合。
正确答案：B。根据你的需求精准用药。如果你确定页面上只有唯一的一个 ID 或 Class 需要操作（如前一个项目），使用 `querySelector` 会更快捷简便。

Selecting and Manipulating Elements

📺 来源：005 Selecting and Manipulating Elements.en.srt 📂 章节：第 07 章

🎯 概述

上节课我们懂得了 DOM 是什么，这节课我们终于要动手施展魔法了！我们将通过 JavaScript 来“选中”网页里的元素，然后随心所欲地去“篡改”它们显示的内容。掌握这套擒拿手，你就是网页的主宰！

1. 读取和写入文本内容 (textContent)

如果你想修改普通 HTML 元素里夹着的文字（比如 <p>、<h1>、<div>），最核心的属性叫做 textContent。

下面这行代码分为非常清晰的两部分：先用选择器抓取，再操作属性。


// 步骤一：抓取 HTML 里 class 名为 'message' 的元素
// 步骤二：篡改它的 textContent 属性

document.querySelector('.message').textContent = '🎉 Correct Number!';

你可以用这个属性读取网页现有的字，也可以给它塞新字进去。这就像变量的读和写一样自然：


// 读操作 (Read)
console.log(document.querySelector('.message').textContent); 
// 输出: "Start guessing..." (假设这是原来的字)

// 写操作 (Write/Mutate)
document.querySelector('.score').textContent = 10;
document.querySelector('.number').textContent = 13;

💡 小提示： querySelector 里的字符串用法和你在 CSS 里写选择器一模一样：点号 . 代表 class，井号 # 代表 id。如果你想选某个标签（比如 body），直接写 'body' 即可。

2. 操作输入框 (Input Fields) 的特殊之处

我们要在 "Guess My Number" 游戏里让玩家输入数字，所以我们需要用到 <input> 元素。但是请注意！Input 标签是个奇葩，它不能用 textContent 操作！

为什么？因为 <input> 是一个自闭合标签（没有结束标签，中间夹不了东西），用户的输入都存在了一个叫做 value 的内部属性里。


// ❌ 错误做法：企图用 textContent 操作输入框
document.querySelector('.guess').textContent = 23; // 这毫无反应！

// ✅ 正确做法：读取和设置输入框的 value 属性
document.querySelector('.guess').value = 23; // 代码自动在页面输入框填入 23
console.log(document.querySelector('.guess').value); // 读取当前输入框里的内容

现在我们已经能用意念（代码）控制页面元素了，接下来的终极挑战是：我们希望当玩家真正去用鼠标点击按钮时，代码才开始运行！这就要涉及“事件监听”了。

1. 我们需要将页面上一个带有 class 名为 "btn-submit" 的按钮上的文字修改为 "提交"，正确的代码是？
A) `document.querySelector('btn-submit').textContent = '提交';`
B) `document.querySelector('.btn-submit').textContent = '提交';`

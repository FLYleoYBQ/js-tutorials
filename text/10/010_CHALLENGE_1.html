CHALLENGE #1: Let's Build a Poll App

📺 来源：010 CHALLENGE #1.en.srt 📂 章节：第 10 章 · 函数深入
🥊 挑战任务要求

我们要构建一个非常轻量的在线投票 (Poll) 应用的底层逻辑。我们提供了一个基础的 poll 对象，你需要在这个对象上实现业务方法，并将它绑定到页面按钮上。

任务 1： 为 poll 对象编写一个方法 registerNewAnswer。它需要做以下几件事：
  • 通过 prompt() 弹窗提问（问题文案拼接 question 和 options）。
  • 获取用户的输入并转换为数字 (Number)。
  • 验证输入：确认用户的输入是一个有效的选项下标（比如不能输入 5）。如果有效，利用短路求值 (Short-circuiting) 让对应的 answers 数组元素 +1。
  • 在记录完答案后，顺手调用任务 3 写的 displayResults 方法展示最新结果。
任务 2： 将上述的 registerNewAnswer 绑定到一个类名为 .poll 的按钮的 'click' 事件上。
⚠️ 陷阱警告：作为复习刚刚学的知识，想一想如果直接写进 addEventListener 会发生什么？如何利用 bind() 修复 this 上下文？
任务 3： 为 poll 对象编写方法 displayResults。
  • 接收一个 type 字符串参数。如果 type 为 'array'（设为默认参数），仅打印出数组；如果 type 为 'string'，打印出如 "Poll results are 13, 2, 4, 1" （结合 join() 方法使用）。
🌟 额外加分任务 (Bonus) 🌟： 使用 displayResults 方法分别打印出外来的测试数据 [5, 2, 3] 和 [1, 5, 3, 9, 6, 1]（使用 'string' 类型打印）。
提示：由于函数内写死了 `this.answers`，你该如何临时修改、借用 (borrow) 这个方法欺骗它访问新的测试数据？

✅ Jonas 参考解答解析

来看看我们这节课里关于 bind(), 短路逻辑 以及 call() 的应用教科书级答卷。

const poll = {
  question: "What is your favourite programming language?",
  options: ["0: JavaScript", "1: Python", "2: Rust", "3: C++"],
  answers: new Array(4).fill(0),
  
  // 任务 1 
  registerNewAnswer() {
    // 接结合并使用 join 拼接换行符
    const answer = Number(
      prompt(`${this.question}\n${this.options.join('\n')}\n(Write option number)`)
    );

    // 验证：typeof 必须是 Number，且必须小于 options 长度
    // 灵活运用逻辑与 && 的短路求值特性，只要前面成立，后面就会执行。省去 if 的繁杂！
    typeof answer === 'number' && answer < this.answers.length && this.answers[answer]++;

    this.displayResults();
    this.displayResults('string');
  },

  // 任务 3
  displayResults(type = 'array') { // ES6 默认参数
    if (type === 'array') {
      console.log(this.answers);
    } else if (type === 'string') {
      // 灵活使用数组的 join
      console.log(`Poll results are ${this.answers.join(', ')}`);
    }
  }
};

// 任务 2: DOM 绑定陷阱
// 【关键点】如果不使用 bind，在点击时 this keyword 将指向 button 对象，导致获取不到 question 报错！
document.querySelector('.poll').addEventListener('click', poll.registerNewAnswer.bind(poll));


// 任务 4 (Bonus): 借用方法欺骗 this
// 利用 call 手动改变展示函数内部寻找 this.answers 时的落脚点对象！
poll.displayResults.call({ answers: [5, 2, 3] }, 'string');
poll.displayResults.call({ answers: [1, 5, 3, 9, 6, 1] }, 'string');
poll.displayResults.call({ answers: [1, 5, 3, 9, 6, 1] }); // 走 array 默认模式
> **💡 Jonas 的大师级点评：**
> “注意我是如何使用短路操作符 `&&` 替代 `if` 语句的（任务1），这种写法在 React 源码及高级前端写法中随处可见，它让代码变成了简练的单行。而在做最后的 Bonus 修改时，我们构建了一个只有 `answers` 属性的一个小对象包裹器传入 `call()`，因为 `displayResults` 只在乎 `this.answers` 存在与否，这是鸭子类型思维的最好体现。”

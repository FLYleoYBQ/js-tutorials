Looping Arrays: The for-of Loop

📺 来源：012 Looping Arrays The for-of Loop.en.srt 📂 章节：第 09 章
📌 知识脉络
  • 前置基础：老派的传统 for (let i = 0; i < arr.length; i++) 循环。
  • 进化变革：ES6 引入的 for-of 循环结构。极大幅度剥离底层的计数器管理。

🎯 概述

在古典 JavaScript 时代，遍历数组意味着我们需要手写三段长长的初始化、边界判定、自增仪式。而全新的 ES6 for-of 让数组遍历变得极速优雅，宛如阅读一篇人类能够直观理解的英文小说。

1. for-of 取代繁琐的老式 for 循环

让我们看看它在实际业务流里有多直白。相比别的现代循环方式，for-of 有一个碾压级的巨大优势：它允许被 continue 或 break 强行打断！

2. 痛点：如何通过 for-of 获取索引？

for-of 最初被设计时纯粹是为了丢给你“具体的元素内容” (Element) 而非数字索引 (Index)。但如果你同时恰恰需要索引号（例如展示菜单：1. 披萨，2. 意面），你需要一个内置工具：.entries() 迭代器。

💣 第一步：带泥沙的原生捞出法
for (const item of menu.entries()) {
    // 此时 item 变成了一个包含了 [索引, 值] 的小数组包裹
    console.log(`${item[0] + 1}: ${item[1]}`);
}
🛡️ 第二步：结合解构大法的终极版
// 我们根本不再需要忍受 item[0] 和 item[1]
// 直接在接待形参的部位使用解构 [i, el] 把包裹撕开
for (const [i, el] of menu.entries()) {
    // i 就是 index, el 就是 item 值
    console.log(`${i + 1}: ${el}`);
}

通过使用 menu.entries()，你把原本的一维 ['Pizza', 'Pasta'] 变成了二维小方块阵型装车发送给了遍历机：[ [0, 'Pizza'], [1, 'Pasta'] ]。再配合最时髦的解构签收，完美无痛获取了 index 和 element。

❓ 理解检测

1. 关于 ES6 的 `for-of` 语法，下述说法哪项正确？
A) 它只能用来获取值，如果想在循环里既获取索引又获取值，只能乖乖换回老的 let i = 0... 循环。
B) `for-of` 支持中途使用 break 截断停止，或者使用 continue 跳过单次。这和传统的 for 一样刚健，比后来学到的 forEach 更加自由。
C) 它完全废弃了老版循环，我们不再需要写 const [index, it] of...
B 是正确的选项。这也是它的立足之本。在后面我们要学的数组高阶函数 forEach 里面，是完全不理会并且不吃你 break / continue 这一套强行终止操作的。

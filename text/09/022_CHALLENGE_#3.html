CHALLENGE #3 (足球博彩大挑战)

📺 来源：022 CHALLENGE #3.en.srt 📂 章节：第 09 章

⚔️ 任务总览

欢迎回到我们的足球博彩数据解析系统！这次的数据库源头不再是对阵对象，而是一张囊括了整场比赛 90 分钟内发生所有事件的极密 Map 表。其中「键 (Key)」代表发生时间的分钟数，「值 (Value)」代表发生的动作（进球、换人、红黄牌等）。

📋 你的 4 项核心指控任务：
  1. 建立一个名为 events 的数组，要求提取出本场比赛中出现过的所有不重复动作种类 (例如只允许存在一个提取词 '进球')。
  2. 经VAR录像仲裁：第 64 分钟的黄牌纯属黑哨误判。你的任务是直接从总事件 Map 表里永久销毁该时间点的事件记录。
  3. 计算平均事件爆发间隔，并在控制台无情打出这句宣告："An event happened, on average, every X minutes" (假设常规比赛总时间刚好是 90 分钟，算出其中的 X)。
  4. 将整个 Map 表全部打印出来，但要求在每条事件前标注它是发生在哪个半场：
    [FIRST HALF] 17: ⚽ GOAL
    [SECOND HALF] 69: 🔴 RED CARD

🧠 导师拆解思路

  • 任务1「剔除提取」：Map 长有能够直接掏出右侧资料肉体的方法 .values()。你拿出一堆有很多重复进球的肉堆后，毫不犹豫地把它扔进拥有绞碎去重能力的 new Set() 中洗涤。最后别忘了要拿散装 Spread ... 把洗干净的东西给它披上数组的 [] 外套。
  • 任务2「销毁指控」：Map 自带斩杀指令 .delete(key)。传参要消灭的回合（64）即可。
  • 任务3「频率算法」：Map 长有能直接显示里面藏了多少条目大关的 .size 属性。拿总时间（90）一除便可得出答案。
  • 任务4「巡检遍历」：上节课讲了 Map 如何完美的丝滑融入 for-of。解构出 [min, event]，拿分钟数跟 45 判断，大于 45 那肯定只能是属于下半场。

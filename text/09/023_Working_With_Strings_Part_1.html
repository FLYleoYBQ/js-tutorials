✈️ 启航：如同数组般提取刻度

跟数组完全一样，就算我们挂在这里的是一段单薄无辜的字符串实体，我们依然可以无视法则直接对文字套弄 [] 下拉数字提取某单体字母！以及测量整体的尺寸长度 .length。

const airline = 'TAP Air Portugal';

console.log(airline[0]); // 'T' （严格从零刻度数起）
console.log('B737'[0]); // 甚至可以直接徒手凭空对着野生字符串猛锤出 'B' !
console.log(airline.length); // 探针报出尺长 16

1. 基础索敌探测仪 (indexOf 与 lastIndexOf)

这是我们要拆解字符串前必备的声呐装备，用于锁定待砍单词首字母精准所在坑位。它们只会返回一个数字标号，探测查无此人时弹出负面绝望的 -1。

// 永远只在遇到第一个小写r的瞬间锁定标号就断网报点：
console.log(airline.indexOf('r')); // 出现在 6 坑位 (注意，严格区分大小写敏感)

// 哪怕这条大船上长了一万个r，我也只提取坠在船尾巴倒数最后一个的r：
console.log(airline.lastIndexOf('r')); // 10

// 轰炸精准整个词根
console.log(airline.indexOf('Portugal')); // 8

2. 夺心切割刀 (slice)

我们锁定坐标，到底是为了什么？为了发动手术级的 .slice(起针点, 拔针点) 彻底切割并抽离出血肉核心！

注意：任何 String 方法的劈砍改造返回的都永远是一份克隆复制体，字符串这种基础源矿原生体，是绝对坚冰不可变质的！(Immutable Primitive)。它们不能被当场弄残缺，必须把切割后的变异接住赋值。

const airline = 'TAP Air Portugal';

// 砍第一刀：只输入起刀点。
// 它会从坑位 4 'A'字头一路杀到结尾。
console.log(airline.slice(4)); // 结果：'Air Portugal'

// 砍第二刀：精确控制拔针停靠点。
// 从4开始，斩击到7(空格)停手，它不会包裹第7个字的肉。
console.log(airline.slice(4, 7)); // 结果：'Air' 
// 💡长轴密探：切割出的实体块长宽度，绝对 = (尾巴 7 减去 头部 4)。

// --- 【高阶盲砍盲切手段】 ---
// 在大型业务中系统是绝对不知道用户传的哪个公司的名字。如何抽取任意首个名字？
// 以查出的第一个带空格的索引点位，充当强行拔针点停手！
console.log(airline.slice(0, airline.indexOf(' '))); // 'TAP'

// 抽取大长条后缀名：从最后探知到的末尾那个倒数空格，往后顺到死砍完。
console.log(airline.slice(airline.lastIndexOf(' ') + 1)); // 'Portugal'

// --- 【负数暗黑切割法】 ---
// 从屁股末端开始倒扯起。
console.log(airline.slice(-2)); // 'al'
// 头部正攻法从位移1开始，并且刀法砍到屁股尾巴倒扯1单位就强行遏止。
console.log(airline.slice(1, -1)); // 'AP Air Portuga'  (头尾切掉两端各一坨肉)

💎 究极装箱解析 (Boxing: 引擎到底怎么作弊的？)

很多学得深的人内心这时候会爆炸：不对啊！前面讲过，String 是绝对的最基层原始类型 (Primitives) 原矿，不是高级 Object（对象），那它怎么配拥有 slice / indexOf 等等这么一长串的 Methods 方法？只有 Object 才长有那些狗爪子附带法术体呢？

🎩 揭秘 JavaScript 底层光速诡术：暗影装箱 (Boxing)

其实当我们对一条朴素的字符串疯狂按压下那个 . (点) 的瞬息，JS 底层马达极为疯狂地进行了一次替身重塑！它把这段小小的野生命根词组套上包裹，强制转化并生掰出了一个具有同等词文的替身使者对象体 new String('TAP')！

这个对象上自然附带好了方法链群。等大招放完一刹那，返回新修改完成的字符串结果给外界。然后底层又把那个强行生成的假面具壳子打烂毁尸粉碎！变回普通形态退居幕后。
这就叫极其神速智能的“幕布装箱”操作。你表面上仿佛在操作最弱的个体，而实际上内部调用了极度豪华的对象装甲工厂。这就解释了 typeof new String('ha').slice(1) 的最终回卷反馈为何还是一个弱者 'string'。

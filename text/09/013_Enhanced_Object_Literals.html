🎯 概述 (Object Literal 终极净化)

其实这节课非常简单，仅仅是关于帮你少按几次键盘按键语法糖的教学。所谓的“对象字面量（Object Literals）”正是我们手敲花括号 {} 像流水账一样定义出来的结构体。

ES6 引入了三大重磅改进招式，它通过自动识别同名以及自动省略多余修饰符号，大幅度降低了编写对象的代码行数和精神污染风险。

强化招式 2：对象方法的函数申明简写脱衣法

在你的主对象里面定义成员挂载的功能函数时，在古代你不得不用 : function() 的胶布结构把它缝死在字典里。在现代，你可以拔掉胶布，让它长得跟外部普通函数结构或者类方法一致了。

💣 古典函数包袱
const restaurant = {
    // 你必须用 key: function() 给它穿衣
    orderPizza: function(main, ...other) {
        console.log(main);
    }
};
🛡️ 现代版脱去 function
const restaurant = {
    // 干净且直接！丢弃了 : 和 function 关键词
    orderPizza(main, ...other) {
        console.log(main);
    }
};

强化招式 3：计算属性名 (Computed Property Names) 动态拼装

以前我们无法在包裹花括号的对象体内部去进行运算并凭空生成出 Key 字符串。你只能写好壳子后再通过 obj['day-' + index] = ... 在体外逐个注射补充。如今，你可以使用 [] 中括号在体内直接开展动态魔法了！

const weekdays = ['mon', 'tue', 'wed', 'thu', 'fri', 'sat', 'sun'];

const openingHours = {
    // 直接在声明结构体里内嵌方括号 [] 运算逻辑。这里指向 'thu'
    [weekdays[3]]: {
        open: 12,
        close: 22
    },
    // 支持极其反人类的模板拼接加算数推导命名。最终名字变成了 'day-6'。
    [`day-${2 + 4}`]: { 
        open: 0,
        close: 24
    }
};

console.log(openingHours); 
// 最终渲染出的属性真实名为 { thu: {...}, "day-6": {...} }

❓ 理解检测

1. 关于 对象内数组的计算属性名（Computed Property Names），它打破了什么边界？
A) 它允许在对象里写入无法命名的属性。
B) 它只允许将内部数字相加为键名。
C) 它让我们不必逃脱出 `{}` 花括号闭合区域，在声明配置项定义的最开始，就可以依据数组或计算公式动态推导编排属性的硬名（Key）。极大增强了代码凝聚与生成力。
C 是正确的选项。这改变了在定义常量结构体数据地图时的死板手感，我们可以在声明它的一瞬间引用函数，模板字符串拼接和数组下标来灵活组装它身上的字典条目了。

解构数组 (Destructuring Arrays)

🎯 概述

解构赋值 (Destructuring) 是 ES6 引入的一项极其强大的特性。它可以帮助我们将数组中的元素或对象中的属性，"拆包" 并打包赋值给独立的变量。

1. 基础解构与跳过元素

> 🧩 **生活类比**：就像你收到了一个包含三种零食（薯片、可乐、巧克力）的快递盲盒。以前，你需要把它们一个个手动拿出来单独贴上名字标签；而使用解构，你可以一次把它们全倒出来，并瞬间赋予它们独立的变量名。

假设我们有一家意大利餐厅，它的菜单分类是一个数组。你可以直接用方括号 [] 放在等号左侧来接收数组元素：

2. 变量值交换 (Swapping Variables)

解构赋值最酷的一个实战技巧就是交换两个变量的值。假设由于业务需求，餐厅老板决定将上面的 main 和 secondary 分类互换。

🚨 初版冗余写法 (The Naive Way)
let main = 'Italian';
let secondary = 'Vegetarian';

// 必须引入第三方临时变量 temp
const temp = main;
main = secondary;
secondary = temp;

console.log(main, secondary);
✨ DRY 重构写法 (The Destructuring Way)
let main = 'Italian';
let secondary = 'Vegetarian';

// 一行代码搞定！创建一个新数组并立即解构赋值
[main, secondary] = [secondary, main];

console.log(main, secondary);

💡 痛点解决： 彻底避免了声明多余的 temp 变量，代码变得如丝般顺滑！

4. 嵌套解构与默认值 (Nested & Default Values)

当我们要面对的是数组中包含数组的情况（嵌套数组），只需将等号左侧的解构模式对应嵌套起来（解构中的解构）。

不仅如此，当我们从 API 拉取数据时，常常不知道数组到底有多长。如果试图提取一个不存在的位置，变量会变成 undefined。为防止报错，我们可以设置默认值 (Default Values)。

进阶解构.js

💡 关键要点

  • ✅ 解构数组并不破坏原数组，它只是从数组中提取并复制值。
  • ✅ 使用 [a, b] = [b, a] 是经典的变量反转魔法。
  • ✅ 用逗号留空 [a, , b] 可跳过不需要的中间元素。
  • ✅ 善用 = 符号设置默认值，在处理未知长度的 API 返回数据时能够增加代码鲁棒性。

❓ 理解检测

1. 下面这段代码的输出结果会是什么？
const arr = [10, 20, 30];
const [x, , z = 100, j = 200] = arr;
console.log(x, z, j);
A) 10 20 100
B) 10 30 undefined
C) 10 30 200
✅ 解析：正确答案是 C。 x 对应第1个元素 10。
空出了第2个位置（跳过 20）。
z 对应第3个元素 30，由于它在原数组中存在且不为 undefined，它的默认值 100 不会生效。
j 对应第4个位置，由于数组只有3个元素，j 拿到 undefined 从而触发了它的默认值 200。

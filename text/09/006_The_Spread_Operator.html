展开操作符 (The Spread Operator ...)

📺 来源：006 The Spread Operator (...).en.srt 📂 章节：第 09 章
📌 知识脉络
  • 前置知识：解构赋值（区别：解构是提取部分元素分配给变量，展开是提取全部元素逗号分隔输出）
  • 后续扩展：与下节课将要学习的剩余参数 (Rest Pattern) 符号相同但作用完全相反！

🎯 概述

展开操作符 (Spread Operator, ...) 是将数组的所有元素“解包 (Unpack)”出来的快捷方式。当我们需要将数组元素用逗号隔开写在一个新大数组里，或者在传递函数参数时，它绝对是最佳选择。

1. Unpacking: 数组提取术

> 🧩 **生活类比**：你可以把数组想象成一个整齐装箱的包裹 `[1,2,3]`。如果你直接把箱子放进新包裹，那里面就是一个箱子。但如果你在箱子前写一个 `...`（相当于用小刀划开胶带），里面的物品就会散落出来互相混在一起！
🚨 初版冗余写法 (The Naive Way)
const arr = [7, 8, 9];

// 手动一个一个往新数组里塞
const badNewArr = [1, 2, arr[0], arr[1], arr[2]];
console.log(badNewArr); // [1, 2, 7, 8, 9]
✨ DRY 重构写法 (Spread Operator)
const arr = [7, 8, 9];

// 用刀划开！元素散落出来
const newArr = [1, 2, ...arr]; 
console.log(newArr); // [1, 2, 7, 8, 9]

3. 🚨 作用域限制陷阱

千万记住：展开操作符 ... 不能单独使用在除了“构建数组”或“传参”以外的任何地方。它不等于字符串拼接！

🐛 报错实验室 
const str = "Jonas";
// ✅ 在数组内解包：
console.log([...str]); // ['J', 'o', 'n', 'a', 's']

// ❌ 错误：期望单值的地方不能用逗号分隔（语法错误）
// const errorMessage = `${...str} is awesome`; // SyntaxError

4. 可迭代对象与 ES2018 对象扩展

JavaScript 中有许多可迭代对象 (Iterables)：数组、字符串、Map、Set。但对象 (Object) 不是可迭代对象。

然而自 ES2018 以来，规范允许我们在对象内部使用展开操作符，非常适合用于创建对象的浅拷贝或新增属性合并：

对象浅拷贝.js

💡 关键要点

  • ✅ ... 可以将数组拆解成逗号分隔的值，它最常被用来合并数组或克隆数组。
  • ✅ 它可以用于函数参数的优雅传递，极大减少下标调用的冗余。
  • ✅ 只有可迭代对象（如 Array, String）能被 `...` 拆解（除了字面量构建的对象外）。
  • ✅ ES2018 让对象字面量中也能使用 `...`，从而彻底淘汰了曾经笨重的 Object.assign()。

❓ 理解检测

1. 关于展开操作符 ... 和解构赋值，以下描述最准确的是？
A) 解构赋值是将部分元素赋值给变量名；展开操作符是从集合中把全部元素一口气掏出来散开。
B) 展开操作符会改变原始数组的值（Mutating）。
C) JavaScript 的根基对象（Object `{}`）就是 Iterables，可以用在所有适用展开操作符的地方。
✅ 解析：正确答案是 A。它们的方向完全背道而驰。另外 B 是错的，展开不仅不改变原数组，还常用于创建浅拷贝。C 是错的，对象的展开只有在对象字面量（{}）内部构建新对象时受现代 ES2018 规范支持，对象本身不是 Iterables 协议。

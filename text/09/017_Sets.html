Sets (集合)

📺 来源：017 Sets.en.srt 📂 章节：第 09 章
📌 知识脉络
  • 前置基础：过去你只知道数组 (Array) 作为排队容器。它允许元素重复、依赖索引拿取。
  • ES6 新增核武：Set 集合天生自带“高度洁癖”。它里面绝对不存在任何互相重复的克隆体元素，并且打碎了有序数字首尾排列。

🎯 概述

很多语言里早就存在 Set 这种数据结构（例如 Python）。在 JS ES6 之前我们一直用残缺的笨重方法去数组里比对去重。Set 的使命只有两条：
1. 它的数据元素永远必须独一无二 (Unique)。
2. 它没有下标索引机制（你无法像 set[0] 这样掏东西）。

1. Set 的基础魔法操作与本质

如果你真的需要有顺序提取东西，请滚回去用数组。 Set 仅仅被用来询问 “这个玩意儿在不在你的地盘内？” (has) 以及 清洗掉重复病毒。

2. 核心工业实战：结合 Spread 给普通数组去杂

我们在工程里其实很少把 Set 独自挂在那里常驻。最经典的史诗级一行流操作：我们把一个感染了重复数据的数组转化成 Set 后，再利用 Spread 炸弹 ... 把洁净的数据炸回一个崭新数组壳子里！

const staff = ['Waiter', 'Chef', 'Waiter', 'Manager', 'Chef', 'Waiter'];

// 连招拆解：
// 1. new Set(staff) 变成洁净 Set { 'Waiter', 'Chef', 'Manager' }
// 2. ... 把它外壳炸碎成散落个体
// 3. [] 在外围把它重新接住封装回数组
const staffUnique = [...new Set(staff)];

console.log(staffUnique);
// 完美得到没有任何挂职复数闲人的职业名单：[ 'Waiter', 'Chef', 'Manager' ]

// 如果仅仅是要算有多少种职业而不需要数组？直接：
console.log(new Set(staff).size); // 3
console.log(new Set('jonasschmedtmann').size); // 算出一个长串单词里有多少个毫无重复的英文字母

❓ 理解检测

1. 关于 Set（集合）这种数据结构的定性，哪句总结最为狠辣准确？
A) 它是去重过滤洗碗机和存在性雷达（用 has）。它彻底剥去了数组那套下标排队提取系统，并且计算容量使用 `.size` 代替 `.length`。
B) 它意图在未来两年内彻底封杀数组（Array），因为去重后的世界才是纯净安全的。以后不再使用由方括号 [] 定义的数组。
C) 它是一种能包含键值对的对象升级版，跟 Object 差不多，靠 Key 查找。
A 是正确的选项。Set 的业务场景极其收敛专一：就是洗掉重复数据和最高速检索 has() 。当我们需要按顺序排序展示花名册乃至重度运用 .map() 和 .filter() 加工数据时，大统领依然是永不没落的 Array。

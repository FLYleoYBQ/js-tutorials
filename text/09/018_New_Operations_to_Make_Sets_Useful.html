🎯 概述：开启数学里的维恩图(Venn Diagram)世界

如果你在高中学过集合论 (交集、并集、差集)，那么接下来 JS 中的原生高级运算如同白开水一样直白。如果没有学过，不用怕，接跟着我一起玩转意大利菜和墨西哥菜互相勾结的故事。

1. Intersection（交集）：同时扎两只脚的通吃货

想要挖出那些既存在于义大利披萨里，又混在墨西哥肉卷里的公共内奸辅料食材？

index.js

2. Union（并集）：无脑吞噬拼合全家桶

把两张桌子上的菜扫到同一个大麻袋里，还能智能滤除在意大利盘子和墨西哥盘子里重复出现的西红柿（tomatoes）和蒜头（garlic）。

const fusionMenu = italianFoods.union(mexicanFoods);
console.log(fusionMenu); 
// 包含了所有 8 款意大利菜与墨西哥菜（去重了西红柿和蒜子各一份多余重量）。

复古黑客搭桥打法回忆：过去若没有这个 union 大法，你不得不用解构核武生拼硬造再清洗： new Set([...italianFoods, ...mexicanFoods])。

3. Difference（差集）：只有我有，对家没有的特权

它的翻译叫绝对扣除！这是一种带砍杀方向性的单推运算：以站在前面的第一主体（意呆利）为正规，去狠狠砍断削去第二客体里重叠公共的那部分手牌，只留下意大利原生的孤傲特产食材！

// 站在意大利的角度拔高（砍去番茄与蒜头公共区）：
const uniqueItalian = italianFoods.difference(mexicanFoods);
console.log('独属意大利：', uniqueItalian); // 只剩下 ['pasta', 'gnocchi', 'basil']

// 反转身份，站在墨西哥角度砍杀对岸重影：
const uniqueMexican = mexicanFoods.difference(italianFoods);
console.log('独属墨西哥：', uniqueMexican); // 只剩下 ['tortillas', 'beans', 'rice']

4. Symmetric Difference（对称差集）：互不相见的异乡客联盟

这玩意就是大写的排斥叛变。把两拨人凑一起组合，并极其血腥的将左右脚两边同时都有涉足的跨界两面派内保给抽离处死剔除，仅剩只懂一国菜系原味孤芳自赏的特有配料合成终极特产拼盘：

const allUniques = italianFoods.symmetricDifference(mexicanFoods);

// 等价于【独属意大利集合】 + 【独属墨西哥集合】无缝焊死拼接
console.log(allUniques); 
// 含有 ['pasta', 'gnocchi', 'basil'] 和 ['tortillas', 'beans', 'rice']
// 西红柿和蒜子因其跨国两面派作风，阵亡。
⚠️ 极短侦测布尔值雷达: isDisjointFrom

还有一个经常会塞进 if 开关去测雷的小探针：italianFoods.isDisjointFrom(mexicanFoods) —— 它会快速返回这俩国度是否老死不相往来，完全毫无瓜葛？由于我们刚发现它俩有着浓艳的番茄蒜子公共恋情纠葛，所以肯定会弹出一个 false（它们并非不交叉互相割裂的冰川）。

❓ 理解检测

1. 对于两极碰撞的新型 API，请问 A.difference(B) 和 A.intersection(B) 最本质的心态区别是？
A) 没区别，它们就是名字变写了而已。
B) `intersection` （交集）像粘合剂寻宝，只有我和你都有的东西才装出来成活；而 `difference`（差集）像霸道清理门户，我身上一切受沾染了有你的印记的东西要被全部连根斩杀消除掉，剩下的全都是只有我有的绝活特权身段。
C) `difference` 会把两个阵营的特色全部合并再统一进行随机抛弃。
B 是正确的选项。这极其严苛的遵照了高级数理集合推演，在诸如用户标签大类并集、或者从一大堆数据权限菜单里反向“扣除”已挂职权限时常常神乎其技地发光发热。

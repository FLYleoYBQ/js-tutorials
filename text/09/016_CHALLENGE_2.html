本次竞赛将考核你的武器库是否装载完毕我们此前修行的所有遍历手段：包含数组直接切阵的 for-of，配合数组天梯阶层定位仪 .entries()；以及徒手粉碎无常形对象的破壁机法决：Object.values() 用以汲取水潭数据取核心，Object.entries() 强迫剥壳展翅。不用顾及是否烧脑卡死，一切困难皆是长肌肉的台阶。

📝 需求描述

延续我们火爆运转着的体育大博彩平台系统。对这盘球赛：

  1. 遍历战败记功碑：在游戏统计字典下翻查名叫 game.scored 这块阵亡录队列并施加 for-of 光环扫描大循环。终端需精准无误报单播放格式战报：打印 "Goal 1: Lewandowski"...直冲念到大满贯 Goal 4！必须用到能带小下标返回包数组的那个函数。
  2. 测算下注大盘的赔率平均值浮点数：在浩如烟海的内部风暴眼 game.odds （一个对象块并不是数组）里面抽吸其隐藏内层全部 3 枚数值核心碎片，循环把值聚合运算除以块头长短并输出均算值结果。别再企图偷懒像前几回那样强迫硬提取分拆到常数写死算术。
  3. 以极佳排版列席宣判台并播送宣誓：优雅遍历游走穿梭过整个隐形的 odds 对象大森林。播报必须严格按格式装裱框架文字：“Odd of victory Bayern Munich: 1.33”。

    🚨铁规红线：不能将战队真容在模板字符串写死打在模具上！请在遍历游走抓到队伍的假名标识符比如 'team1' 时作为指针，折返回上方到高居顶点位置的顶级上帝字典：母星光主盘 game 头身里面借位调用它相对应记录真名的实际属相实体去替代拼接。
    ※ （唯一的网外放生漏斗）：由于"平局"(名为 'x' 这个符号位)它是一个虚体不在字典上报名单。如果是它就可以动用三元逻辑强制打印文字 'draw'。

// 1. 挂钩 entries 把普通队列转化成送上下标的列套阵。
// [i, player] 犹如一柄手术刀直接撕解开外包快递获取数据：
for (const [i, player] of game.scored.entries()) {
  console.log(`Goal ${i + 1}: ${player}`);
}

// 2. 先强行呼叫高阶对象神明施法融化对象！只要 values 内芯！
const odds = Object.values(game.odds);
let average = 0;
// 再拿化解出装满了数字干果的实则队列的容器丢进循环。
for (const odd of odds) average += odd;
average /= odds.length;
console.log(`博彩开挂计算之中心赔率平均刻度落在: ${average}`);

// 3. 全抓法阵神明化解对象！连血肉并内脏一把揽获取。
// 撕剥获得队伍名牌暗号 [team] 和其附属大头头衔数字 [odd]
for (const [team, odd] of Object.entries(game.odds)) {
  // 这句神级替身！若游走位处于 x 暗号，抛出特赐称号 'draw'。
  // 若是 team1 或者 team2 则强行倒流回头去攀高爬取母体对象那实报的战队头衔宏名！
  const teamStr = team === 'x' ? 'draw' : `victory ${game[team]}`;
  console.log(`Odd of ${teamStr}: ${odd}`);
}

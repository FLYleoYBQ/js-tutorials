Short Circuiting (&& and ||)

📺 来源：008 Short Circuiting (&& and ).en.srt 📂 章节：第 09 章
📌 知识脉络
  • 前置基础：逻辑运算符入门，什么是 Truthy 和 Falsy 值。
  • 突破认知：逻辑运算符 || 和 && 不只用于返回布尔值的 true/false，更有跨越类型返回各种奇怪数据类型的魔法隐藏属性——短路计算机制。

🎯 概述

一直以来我们被骗了，以为 || (OR) 和 && (AND) 必须要跟一堆 if/else 捆绑在一起使用，只能输出布尔值。今天，要教你黑客级的三大新隐藏特性：
1. 它们可以吃进任意类型的值。
2. 它们可以吐出/返回任意类型的值。
3. 它们具有极速断电的 短路计算机制 (Short-circuit Evaluation) ！

1. OR (||) 短路操作：寻找第一个真理光束并保底

OR 短路逻辑的心智模型：引擎像探照灯一样顺藤摸瓜，谁在这个链路里第一个呈现 Truthy（闪光真理），我就立即逮捕它并带着它停跳下车返回，此后排队的任何人我都闭上眼不检查了！

🛠️ 经典重构场景应用：默认值设防

假设我们正在开发一个订餐系统，需要访问餐厅当今晚上的客座数 restaurant.numGuests。如果是初学小猿，我们可能会使用三元表达式费劲撰写兜底方案，但现在有了一刀斩的手段：

const restaurant = {}; // 空餐厅无客人数数据定义

// 菜鸟时代（复杂且带有陈腐感）：
const guests1 = restaurant.numGuests ? restaurant.numGuests : 10;

// 短路宗师级手段（优雅地提供 Default 备胎 10 给前端界面防撞）：
const guests2 = restaurant.numGuests || 10;
console.log(guests2); // 10

⚠️ 警告暗礁：如果我们今晚有客人数数据，但是数据偏巧是极端的 0 呢？此时 0 触发 falsy 降级导致误送人头保底到了 10。别急，下一节课的高科技符号会完美根治它。

2. AND (&&) 短路操作：寻找第一块绊脚石并阻断

AND 短路逻辑永远与 OR 背道而驰：谁若是队伍里的第一个 Falsy 败类，就立刻封杀执行并返回这块老鼠屎！只有大家都品学兼优 (全是 truthy) 才会通过走廊直达最后一人（然后返回最后那个成员）。

console.log(0 && 'Jonas'); // 迅速阻断，输出 0 
console.log(7 && 'Jonas'); // 放行通过第一关，输出 'Jonas'

console.log('Hello' && 23 && null && 'Jonas'); // 输出 null，在第三关被无情截获阻断

🛠️ 经典重构场景应用：替代防爆 if 语句检查器
很多时候你需要确认挂在对象上的这个组件模块存在不存在（毕竟不存在的东西乱跑函数会招致惨烈的红屏报错崩溃），这属于防崩溃兜底的常见手段。

💣 常规冗长核查式
if (restaurant.orderPizza) {
    restaurant.orderPizza('mushrooms', 'spinach');
}
🛡️ AND 极速护栏式断链
// 前置守卫。
// 只要前面存在，就拉闸放开电闸执行后面开路的杀招
restaurant.orderPizza && restaurant.orderPizza('mushrooms', 'spinach');

❓ 理解检测

1. 关于短路现象（Short Circuiting），正确的说法是？
A) 在包含不同类型值得 AND（&&）运算链条中，引擎会扫描计算所有的对象的值直到句子末尾并返回真假。
B) OR（||）会敏捷抓取第一束出现的 Truthy 光，拦截剩余判定；而 AND（&&）则是残酷找寻第一颗绊死树杈的 Falsy。两者都能跨类型返回真实的本体目标值而非强制布尔。
C) 要使用默认值保底技巧时，应该统一使用 && 号。
B 是正确的选项。不仅不用死磕 boolean 值，还能巧妙提炼为执行栅栏和默认备份变量。这也是现代框架和底层库极爱到处使用的浓缩语法糖。

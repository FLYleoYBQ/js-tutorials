1. 基础洗盘 (Lowercase) 与 修复失控大小写

几乎全系统代码世界的第一法则：所有进来的野生比较输入串，请无脑先上强力洗衣机给它褪色碾碎成小写！

console.log('jOnAS'.toLowerCase()); // 'jonas'
console.log('jonas'.toUpperCase()); // 'JONAS'

实战：把瞎子打的 'jOnAS' 洗回标准的 'Jonas'。

const passenger = 'jOnAS';
const passengerLower = passenger.toLowerCase();

// 拼积木：抽出第 0 位字母强行升级成霸道大号 + 将后面被切过洗成弱极小的长串重新用 + 凝固封胶补上去
const passengerCorrect = passengerLower[0].toUpperCase() + passengerLower.slice(1);
console.log(passengerCorrect); // 大功告成 'Jonas'

3. 重大黑工：一键换皮 (replace / replaceAll)

比如把腐国的英镑账单转成老美的计价法汇率格式：

const priceGB = '288,97£';

// 继续利用链鞭：第一手把英镑号干掉顶上老美的美元符，紧接着对那老外习惯的逗号小数点发动点杀干回大圆点。
const priceUS = priceGB.replace('£', '$').replace(',', '.');
console.log(priceUS); // '288.97$'
⚠️ replace() 的先天胆怯

当用在一个漫长的文书长句里："前往 23号大门！再通知一遍这是最后 23号大门！" 。假如你使用了 announcement.replace('大门', '登机闸口')，原版的它就跟一个打卡下班不负责的工人一样，仅仅改完第一个找到的大门两字，就立马闪电消失，剩下后边成百上千个“大门”错字它会漠不关心留置不管！

✅ 拯救方案 1 (新纪元 ES2021)：直接用最新的硬核清缴法 announcement.replaceAll('大门', '登机闸口')！

✅ 拯救方案 2 (老黑客正则暴改)：在正则表达式区用斜杠把字符圈起，并挂接全球无尽剿杀标识 G (Global) 炸弹： announcement.replace(/大门/g, '登机闸口')。

4. 高级断言 Boolean 检测器

有三个轻量但超级重要的特工雷达函数，它们啥新字符串也干造不出来，干干脆脆的只吐 true / false 的布尔宣判。经常作为 if() 内部最香甜的润滑剂使用：

const plane = 'Airbus A320neo';
console.log(plane.includes('A320')); // true 有这个字眼埋在肚子里吗？
console.log(plane.startsWith('Airb')); // true 你开头四个门神是不是这几位？
console.log(plane.endsWith('neo')); // true 如果你屁股落点坐着新世代家族后缀，那算你是豪车版。

🔥 小练习：机场过机安检雷达机拦截器

const checkBaggage = function (items) {
  // ① 不管顾客瞎嚷嚷啥乱七八糟的大小写混合报备词，先把他们全部洗成同归一档。
  const baggage = items.toLowerCase();
  // ② 开启高危词根刺杀探雷针
  if (baggage.includes('knife') || baggage.includes('gun')) {
    console.log('🚨 按着，直接击毙不准登机！');
  } else {
    console.log('✅ 感谢配合，一路顺畅登机。');
  }
};

checkBaggage('I have a laptop, some Food and a pocket Knife'); // 大写的刀依然在安检第一层去归一化中原形毕露暴露马脚并遭到截杀
checkBaggage('Socks and camera'); // 放行

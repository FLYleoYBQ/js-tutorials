📚 第 02 章：JavaScript 基础

📺 来源：001 Section Intro.en.srt 📂 章节：第 02 章

🎯 概述

欢迎来到课程的第一个实质性章节！从这里开始，你将正式踏入 JavaScript 语言的核心世界。本章聚焦于语言基础（Language Fundamentals）——我们不会急于构建用户界面，而是先让你稳扎稳打地掌握 JavaScript 表达逻辑和处理数据的底层能力。

💡 Jonas 寄语

这些课程的设计目标是：在深入 DOM 操作与页面交互之前，先为你搭建一座坚固的语言逻辑骨架。后续所有高级特性都是建立在这一层之上的。

🗺️ 本章路线图

本章将覆盖以下核心知识模块：

📦
变量 (Variables)
学习如何用 let、const、var 声明变量并存储数据
🏷️
数据类型 (Data Types)
认识 Number、String、Boolean、Undefined、Null 等原始类型
⚙️
运算符 (Operators)
算术、赋值、比较、逻辑运算符及优先级
🔀
条件判断 (if/else)
掌握程序分支决策和控制流
📝
模板字面量 (Template Literals)
现代化的字符串拼接方式
🔄
类型转换与强制转换
理解 JavaScript 如何在类型之间自动/手动切换
⚖️
相等性运算符 (== vs ===)
严格相等与宽松相等的本质区别
🎛️
switch 与三元运算符
更多的条件控制流工具

🏆 学习目标

完成本章后，你应该能够：

  • ✅ 使用 let 和 const 声明变量并理解它们的差异
  • ✅ 识别并区分 JavaScript 的 7 种原始数据类型
  • ✅ 编写包含算术、比较和逻辑运算的表达式
  • ✅ 用 if/else、switch 和三元运算符控制程序分支
  • ✅ 理解类型转换（Type Conversion）与类型强制转换（Type Coercion）的机制
  • ✅ 独立完成 4 道代码挑战（Coding Challenge）

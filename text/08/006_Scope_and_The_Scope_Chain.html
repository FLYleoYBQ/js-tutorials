Scope and The Scope Chain (作用域与作用域链)

📺 来源：006 Scope and The Scope Chain.en.srt 📂 章节：第 08 章

🎯 概述

上节课我们探讨了引擎是如何通过调用栈记住“运行到哪了”。这节课我们要解决另一个核心问题：引擎是如何记住“变量去哪找”的？ 为什么内部函数能用外部变量，外部却不能用内部的？答案就在大名鼎鼎的词法作用域 (Lexical Scoping) 和 作用域链 (Scope Chain) 中。

1. 什么是作用域 (Scoping)？

简单来说，作用域回答的问题是：“我的变量住在哪里？”或者“我在这个位置能访问到哪些变量？”

JavaScript 采用的是 词法作用域 (Lexical Scoping)。这意味着：一个变量能不能被访问到，完全取决于当初这行代码**“写在了哪个物理位置”**（比如有没有被包裹在大括号里）。

JS 中的三种作用域

  • 全局作用域 (Global Scope)：写在所有函数外面的顶级代码。全世界都能访问这里的变量。
  • 函数作用域 (Function Scope)：写在函数内部的变量，只有在这函数内部（包括它的子函数里）才能用。
    注意：有些老教程管它叫“局部作用域 (Local Scope)”。
  • 块级作用域 (Block Scope / ES6 新增)：写在 if、for 等大括号 {} 内部的代码块。
    🚨 极其重要的例外！核心考点！
    只有 let 和 const 声明的变量，才会被块级大括号锁住！ 如果你在 `if {}` 里用老旧的 var 声明了一个变量，它会像鬼一样穿透大括号，直接依附到最近的外层**函数作用域**去！这也是如今为什么要彻底封杀 `var` 的原因。

2. 作用域链 (The Scope Chain) 的探照灯法则

现在到了见证奇迹的时刻。假设我们在最深处的一个孙子函数里，想要访问一个全局变量，它是怎么做到的？


const myName = 'Jonas';

function first() {
    const age = 30;

    if (age >= 30) {
        // 这是 if 的块级作用域
        const decade = 3;
        var millenial = true; // ⚠️ var 不受块级限制！
    }

    function second() {
        // 这是 second 的函数作用域
        const job = 'teacher';
        console.log(`${myName} is a ${age}-old ${job}`);
    }
    second();
}
first();

单向街探照灯法则：

这就是作用域链的核心机密：

  1. 变量查找 (Variable Lookup)：如果在当前层找不到变量，JS 就会顺着“作用域链”向上看一眼父级有没有。找到了就停止。
  2. 永远单向向上，绝不向下/向侧：子作用域可以肆无忌惮地偷窥父级、爷爷级的变量；但父级绝对不能向下索取子级内部的变量！ 同理，兄弟作用域（比如并排写的两个函数）互相绝对看不见彼此内部的东西。

3. 作用域链 vs 调用栈（请死死刻在脑子里）

还记得上节课学的“调用栈 (Call Stack)”吗？它们之间有什么关系？

💡 真理：作用域链的攀爬路径，和代码执行的“调用顺序（调用栈）”半毛钱关系都没有！

作用域链的结构，在代码被写成文本的那个物理瞬间，就已经被“谁包裹在谁里面”的物理书写结构钉死了（这就叫“词法作用域”）。哪怕函数 A 在天涯海角被远隔千山万水地调用了，它的作用域链依然只能顺着代码写死的原始父级向外寻找变量，绝不会顺着调用栈去借别人的锅做饭！

🧪 学习验证

1. 在 `if (true) { var test = "hello"; }` 之后，在 `if` 块的外面能否 `console.log(test)`？
A) 报错 ReferenceError，因为 `test` 被困在 if 的块级作用域里了。
B) 会成功打印 "hello"。因为 var 声明的变量**不具备**块级作用域约束，穿透了 if 块。
正确答案：B。let 和 const 才是正经的 ES6 块级公民。var 就像个幽灵，只有函数大括号能关得住它，if、for 等代码块的大括号对它无效。

2. 假设 函数A() 内部声明了一个变量 x，然后 函数A() 在内部调用了 函数B()。请问 函数B() 里面能访问这个变量 x 吗？
A) 能访问，因为 B 是被 A 调用的，都在同一个调用栈脉络里。
B) 除非 函数B 的代码物理上就写死在 函数A 的花括号内部，否则绝对访问不到！这就是词法作用域。
正确答案：B。必须分清“在哪里被调用”和“代码写在哪里”。作用域链只在乎代码是被包裹在谁的花括号里写的。调用栈的顺序不能借变量。

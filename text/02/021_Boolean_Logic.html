布尔逻辑 (Boolean Logic)

📺 来源：021 Boolean Logic.en.srt 📂 章节：第 02 章

布尔逻辑并非 JavaScript 的专利！它是所有计算机科学的基石，用来结合多个「真相」和「假相」以解决复杂的综合条件判断问题。想象一个场景：Sarah 必须拥有驾照并且视力达标才能开车，这两个条件怎么交织在一起？

1. 严酷审判：AND (与)

AND 是极其严厉苛刻的验证官。当你宣告 条件A AND 条件B 时，它要求所有涉及在内的参与者必须清一色全是 True！ 如果你在队伍中哪怕混进了一个 False，整个联合行动即刻判毁报销 (整体返回 False)。

条件 A 条件 B A AND B 结局
TRUE TRUE TRUE
TRUE FALSE FALSE
FALSE TRUE FALSE
FALSE FALSE FALSE

2. 留有余地：OR (或)

相较之下，OR 操作符就像一位老好人。当你提议 条件A OR 条件B 时，它的字典里只要抓获任何一个 True，整体使命便宣告达阵成功 (返回 True)！ 唯独当所有的选项全部都腐烂殆尽为 False，它才会悲痛宣判 False。

条件 A 条件 B A OR B 结局
TRUE TRUE TRUE
TRUE FALSE TRUE
FALSE TRUE TRUE
FALSE FALSE FALSE

3. 叛逆颠倒：NOT (非)

NOT 与前两者拉帮结派干架的风格截然不同：它是孤狼！它只对单一部位的身躯产生作用，其唯一的信条就是颠倒乾坤。

你给它塞进 True，它给你吐出 False。你输入 False，它归还一发 True。并且它的优先级天生高于 AND 和 OR，往往在复合运算中会最先对变量执行颠倒！

💡 烧脑小训练：推演环节

假如已知：A = False，B = True。来求证以下复杂逻辑的生死：

  • A OR B = 老好人发现了 B 是 True。整体为 True。
  • (NOT A) AND B = 先颠倒孤狼 (NOT False 变成了 True)。紧接着两个 True 通过了严厉审查官 AND，整体存活为 True。
  • A OR (NOT B) = B 被颠倒成了 False。两个死透的 False 来老好人摊位，老好人连个 True 都抽不到，无力回天，整体暴毙 False。

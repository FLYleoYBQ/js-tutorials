JavaScript 简明入门

📺 来源：A Brief Introduction to JavaScript 📂 章节：第 02 章

🎯 概述

什么是 JavaScript？它是一门高级（High-level）、面向对象（Object-oriented）以及支持多范式（Multi-paradigm）的编程语言。本节课我们将用大白话和生活类比来解析它的角色定位以及它可以为你带来哪些不可思议的魔法。

1. Web 的三驾马车

🧩 生活类比：名词、形容词与动词

构建一个网页就像是在写一句话，这三门核心技术分别起到了不同的语法作用：

  • HTML (名词)： 负责写出页面上的“实体”。比如 `<p>` 代表一个段落，按钮就是一个按钮。
  • CSS (形容词)： 负责“修饰”实体。比如：把段落文本变成红色。
  • JavaScript (动词)： 赋予页面真正的交互动作与生命力。比如告诉按钮：隐藏这个段落！

2. JavaScript 能做什么

JavaScript 是互联网的唯一官方编程语言。在现代前端开发中，它可以实现：

  • ✨ 动态效果： 用户悬停、点击时的微交互，弹出对话框。
  • 📡 数据请求： 在后台悄悄拉取远程服务器的数据更新页面，而无需刷新整个网页。
  • ⚛️ 构建大型 Web 应用： 它是 React、Vue、Angular 等现代前端底层框架的基石。在深入学习它们前，必须深植原生的 JavaScript 基本功。
  • 🌐 突破前端边界： 通过 Node.js，它可以跑在后端控制数据库；通过 React Native，它可以写 iOS/Android 原生手机应用；通过 Electron，它甚至能写电脑桌面软件。

3. 版本的演进 (ES5 vs ES6+)

JavaScript 的正式名称叫 ECMAScript (缩写为 ES)。

在 2015 年，语言迎来了一次翻天覆地的大更新，史称 ES2015，我们通常称之为 ES6（因为它是在 ES5 之后发布的第六个大版本）。从那以后，JavaScript 变成了每年都会有一次小更新。本课程将直接教导你最现代的 ES6+ 标准写法，但也会让你接触必要的 ES5 知识，这样你也能看懂世界上存量巨大的老代码。

🧪 学习验证

❓ 理解检测

1. 在 Web 开发的三驾马车“名词-形容词-动词”类比中，CSS 扮演的是哪个角色？
A) 动词，负责交互
B) 名词，负责展示内容
C) 形容词，负责样貌和排版
👍 正确！ 解析：CSS 就像形容词，它修饰页面上的 HTML (名词)，决定它是什么颜色、放在哪里。
2. 关于 JavaScript，以下哪项描述是**错误**的？
A) 它是构建在 React 框架的基础之上的底层语言。
B) 它只能在浏览器里运行，且无法和服务器后端产生联系。
C) ES2015 和 ES6 实际上是指的同一次非常重大的历史更新。
👍 正确！ 解析：B 是错误的，因为早在多年前，通过 Node.js，JavaScript 就彻底走出了浏览器，可以直接架设 Web 服务器并且操作数据库了！

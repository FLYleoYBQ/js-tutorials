真实与虚无：Truthy 和 Falsy Values

📺 来源：019 Truthy and Falsy Values.en.srt 📂 章节：第 02 章

上节课我们讨论了数字和字符串的互相转换。那么布尔值（Boolean）呢？在 JavaScript 中，世界并不局限于绝对的 true 和 false。所有存在的事物，即使它不是布尔类型，当它被“强行”放入需要判别真假的语境时，它都会自动显形为“真实相 (Truthy)”或“虚无相 (Falsy)”。

1. 五大 Falsy 护法法则

记住！在整个庞大的 JavaScript 世界里，只有五种值在被转换为布尔类型时，会死死地变成 false（除了 false 本身以外）。它们是虚无的代表：

  1. 0 —— 数字零
  2. "" —— 里面连个空格都没有的空字符串
  3. undefined —— 未定义的空物质
  4. null —— 刻意指派的空
  5. NaN —— 无效的数字错乱物

上面没点到名的任何东西（包括哪怕仅仅是写了空格的字符串），统统都是 Truthy（它会转换成 true）。

3. 致命的 0 之巨坑 (The Bug of Zero)

细心的人可能发现了一个恐怖的逻辑漏洞。
如果高度确实存在，且用户输入的就是极为合理的数值 0 米（例如海平面）呢？

🚨 系统误判预警

如果 height = 0; ，系统同样会把它当作 Falsy 值并跳转到 else: "Height 目前没有被定义"。这就是为什么一昧依赖 Truthy/Falsy 来检查一个值是否存在，在对方刚好合情合理地输入了数字 `0` 的时候，会成为一个坑爹的 Bug。

我们未来会用逻辑运算符（如 `??` Nullish Coalescing）来修补这种特殊情况！

字符串与模板字面量

📺 来源：014 Strings and Template Literals.en.srt 📂 章节：第 02 章

组装由文字和变量构成的信息，是前端开发中最繁重且频繁的任务之一。如何优雅地写出 "我是某某某，我今年几岁了" 的一句话呢？

1. 痛苦的传统拼接法 (The Old Way)

在过去，我们只能用加号 + 强行去缝合字符串和变量的每一寸关节，并且还要像扫雷一样处处小心空格是否加够了、引号是否冲突了。

🚨 单双引号冲突问题

当你想写 I'm 时，如果你最外层用的也是单引号 let sentence = 'I'm...';，程序在第二个单引号那里就会提早认为字符串结束了，瞬间报错！解决办法是：如果是英文中带有缩写单引号的句子，最外层必须包一层 双引号 "" 以避开冲突。

2. 救星降临：Template Literals（模板字面量）

从 ES6 (JavaScript 的一次大版本跳跃) 开始，我们得到了神级武器——模板字面量 (Template Literals)。它的做法非常简单：只用一组特殊的引号包围整句话，需要塞入变量或者运算的地方，我们用 ${} 挖个洞直接嵌进去！

这组特殊引号叫做 反引号 (Backticks : ` )，它通常在键盘左上角，Tab键上方。

❌ 传统加号拼接 (极易出错、可读性地狱)
const jonasOld = "I'm " + firstName + ", a " + 
(year - birthYear) + " years old " + job + "!";
✅ ES6 模板字面量拼接 (直白如白话文)
const jonasNew = `I'm ${firstName}, a ${year - birthYear} years old ${job}!`;

你会发现，在 ${} 的大括号内部不仅仅可以放原始的变量，还能够放诸如 year - birthYear 的数学运算。模板引擎会先计算减法，然后再将算出的年龄数字强制转为字符串塞进去。

3. 多行字符串革命

在写网页或者做文本换行的时候，老版代码想要换行，只能加入古老的编程特殊转义字符 \n\：

multiline.js

别小看这个多行字符串的功能。在后续章节中，当我们需要在 JavaScript 当中动态组态 HTML 的 DOM 元素并插入到网页中时，这个直接按回车换行而不用塞满恶心转义符的特性能节省你成倍的时间！以至于很多现代开发者养成了一个习惯：只要是写字符串，一律默认就用反引号。

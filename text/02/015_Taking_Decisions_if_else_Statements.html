1. 控制流的诞生：非此即彼的岔路口

假设你想检查一个叫做 Sarah 的女孩的年龄是否满 18 岁以够格考取驾照。如果够资格，就打印颁发驾照；如果不够资质，就替她算出还差几年。

flowchart TD A[判断: age >= 18] -->|True| B(条件成立! 执行 If 模块) A -->|False| C(条件落空! 越过 If, 执行 Else 模块) B --> D[继续执行下方代码] C --> D

If 语句后面的括号 () 中放入的是一组 评估为布尔值（true/false）的条件表达式。其后的花括号 {} 划定了当前执行逻辑的地盘范围。

ifelse.js

值得指出的是：else 模块完全是备用方案，你可以选择不写。 如果不写 else，一旦判断为 False 整个分支连同内部代码将会化为泡影，系统将无声无息地略过并继续向下执行。

🚨 范围禁锢规则 (Scope Rule)

JavaScript 里的花括号 { } 是一个封闭的结界隔离墙。任何你在墙壁内部使用 let 或 const 创建（宣告）的东西，都无法从墙外面被获取。因此，凡是需要供外部世界（比如控制台记录）所见的结果变量，必须在墙壁的外围（上方）优先布置下声明阵位，然后再在里面进行逻辑值的更新（覆盖）。

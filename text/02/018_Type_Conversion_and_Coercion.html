类型转换与强制转换

📺 来源：018 Type Conversion and Coercion.en.srt 📂 章节：第 02 章

在 JavaScript 中，数据处理常常会面临“类型不匹配”的尴尬局面（比如想把带有数字的文字拿去做数学计算）。这时候，我们就需要了解类型的显式转换 (Conversion) 和隐式强制转换 (Coercion)。

1. 手动明文转换 (Type Conversion)

当你明确知道想要把一个字符串转为数字（如处理网页表单输入的值时，它们默认总是字符串），你可以主动召唤官方的类型转换函数：Number() 和 String()。

⚠️ 注意：函数的首字母必须是大写！

conversion.js

2. 黑魔法：自动强制转换 (Type Coercion)

如果你一直手动转换那得多麻烦？作为一门灵活（也有些随性）的语言，JavaScript 会在幕后自动猜测你的意图，偷偷把类型进行转换。这就是强制隐式转换 (Type Coercion)。但这其中存在着一套诡异的加减法则！

运算符 偏好阵营 行为规律
+ (加号) ✨ 崇拜字符串 只要遇到字符串，立刻将旁边的数字统统同化成字符串，然后粗暴连接。
- * / (减乘除) ⚙️ 崇拜数学 遇到混合计算，会主动把伪装成字符串的数字剥掉引号，变成真正的数字进行计算。

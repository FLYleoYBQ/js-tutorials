数据类型 (Data Types)

📺 来源：007 Data Types.en.srt 📂 章节：第 02 章

🎯 概述

每个值都必须拥有一个“类型”，这样计算机才知道如何处理它（比如数字能相加，文字则不能进行数学相加）。在 JavaScript 中，所有的值被分为两派：对象 (Object) 和 原始值 (Primitive Value)。今天我们只探讨最核心的原始数据类型。

1. 七大基础数据类型

JavaScript 中有 7 种原始数据类型，这里我们重点掌握前 5 种：

  1. Number (数字)： 包含整数和浮点数（带小数点的数）。
    let age = 23;
  2. String (字符串)： 一串排成序列的文本字符，必须用单引号或双引号包裹。
    let firstName = "Jonas";
  3. Boolean (布尔值)： 只有两个永恒的状态：true (真) 或 false (假)。这在逻辑判断时极其重要。
    let isFullAge = true;
  4. Undefined (未定义)： 当你声明了一个变量，但却完全没往里面塞任何值时，它的状态和类型就是 undefined。
    let children;
  5. Null (空)： 同样意为“空”，但用于有意识地赋值代表“此地无银”。
  6. Symbol (符号，ES2015 引入)： 用于定义不可被改变、独一无二的标识。
  7. BigInt (大整数，ES2020 引入)： 当数字达到极大突破 Number 限制时使用。

🚨 致命新人错误：忘写引号的字符串

当你写出 let name = Jonas; 时，JavaScript 引擎会发疯！因为它认为你试图把一个名为 Jonas 的变量赋给 name，但你根本没定义过 Jonas 变量！
正确的写法永远是：let name = 'Jonas';

2. 动态类型 (Dynamic Typing)

JavaScript 是一门神奇的语言。拥有数据类型的，是值（包裹里的东西），而不是变量本身（箱子外壳）！这意味着你可以在运行中途，随意更换不同类型的内容进入同一个变量中，这被称为动态类型。

3. typeof 操作符与历史遗留 Bug

如果你想让程序告诉你当前变量里到底装的是什么类型，可以使用类似雷达一样的内部探针：typeof。

typeof.js

为什么 typeof null 会返回 "object"（对象）呢？难道 null 不是独立的数据类型吗？
实际上，这是一个存在于 JavaScript 核心引擎里的历史设计 Bug。由于为了维持地球上上千万依赖此设定的旧网站的正常运转，官方决定永不修复这个 Bug。这是所有 JS 工程师的冷知识共识。

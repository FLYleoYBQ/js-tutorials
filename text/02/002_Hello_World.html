🎯 概述

在接通正式武器编辑器之前，我们将直接借助**浏览器开发者工具（Developer Tools）**里的控制台（Console），写出你的第一行 JavaScript 语句。

1. 打开控制台大门

你可以直接通过浏览器和 JavaScript 交互，这常用于报错检查或临时代码测试：

  • Mac 捷径： Command + Option + J
  • Windows 捷径： Ctrl + Alt + J
  • 右键直达： 页面空白处右键选择“检查 (Inspect)”，然后切换到 Console 面板。

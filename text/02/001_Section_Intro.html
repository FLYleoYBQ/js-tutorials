🎯 概述

欢迎来到课程的第一大战役。在这一章，你将开始学习 JavaScript 语言的**最底层基础**。

我们将探索诸如变量（Variables）、数据类型（Data Types）、运算符（Operators）以及if-else 语句（if-else statements）等核心概念。在深入构建漂亮的网页用户界面之前，我们必须先打好语言逻辑的基础结构。

🏆 本章目标

本章的讲义专为您“夯实根基”而设计。这期间我们不会立刻去操纵 DOM（操作网页标签），而是聚焦于语言本身，也就是如何利用 JavaScript 表达逻辑和处理数据。

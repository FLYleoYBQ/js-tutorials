Working With Classes (使用类操纵样式)

📺 来源：013 Working With Classes.en.srt 📂 章节：第 07 章

其实在真正的 Web 开发中，我们极少直接去修改元素的 `.style` 内联属性 (比如 modal.style.display = 'none')。

因为一个组件可能需要同时修改十几条样式 (透明度、高度、动画时间等)，如果一条一条通过 JS 去写，简直是灾难。现代开发标准的做法是：把这些样式提前写进 CSS 的一个“类(Class)”中，然后用 JavaScript 像开关一样，控制这个类名的“挂载”与“移除”。

1. 样式操作的终极武器：classList

在项目中，我们有一条在 CSS 里写好的专门用于“隐身”的类名：

.hidden {
  display: none;
}

此时，无论是白色的弹窗面板 modal 还是黑色的暗色遮罩层 overlay，它们身上都默认携带着 .hidden，由于 display: none 的存在，它们统统被浏览器强制隐身了。

如果玩家点击了三个呼出按钮中的任何一个，我们要让它们“现形”，唯一的做法就是：剥夺它们身上的 .hidden 外衣！

for (let i = 0; i < btnsOpenModal.length; i++) {
  btnsOpenModal[i].addEventListener('click', function() {
    
    // 🔪 使用 API：classList.remove('类名') 强行扒掉隐身衣
    modal.classList.remove('hidden');
    overlay.classList.remove('hidden');
    
    // 🚨 注意：这里传入的是类名本身 'hidden'，绝对不要在前面加点号 '.hidden'！
    // 点号 '.hidden' 是你在查询选择器 (querySelector) 里为了区分标签和类的暗号。
  });
}

2. 隐藏弹窗机制

让弹窗消失的逻辑则完全相反：我们要把 .hidden 外衣重新给它们披上即可。也就是使用 classList.add('hidden')。

能够关闭弹窗的操作通常有两个：

  1. 点击右上角的叉叉关闭按钮。
  2. 点击弹窗外围的黑色半透明遮罩层 (Overlay)。
btnCloseModal.addEventListener('click', function() {
  modal.classList.add('hidden');
  overlay.classList.add('hidden');
});

overlay.addEventListener('click', function() {
  modal.classList.add('hidden');
  overlay.classList.add('hidden');
});

3. 重构：提炼核心函数以消除重复

上面的代码中，modal.classList.add('hidden') 配合遮罩层的相同代码被硬生生抄了两遍。

不仅如此，“打开弹窗”里面剥衣服的代码如果不提炼，也会变得臃肿。我们运用上一节学的 DRY (不要重复自己) 原则，将它们打包进单独的函数中：

const openModal = function() {
  modal.classList.remove('hidden');
  overlay.classList.remove('hidden');
};

const closeModal = function() {
  modal.classList.add('hidden');
  overlay.classList.add('hidden');
};

// 【极简版的事件监听绑定】
for (let i = 0; i < btnsOpenModal.length; i++) {
  btnsOpenModal[i].addEventListener('click', openModal);
}

btnCloseModal.addEventListener('click', closeModal);
overlay.addEventListener('click', closeModal);

🚨 致命提醒：函数作为回调的高级用法
观察上面最后三行的绑定事件代码，我们向 addEventListener 传递的是 closeModal 这个变量名，而绝对没有包含圆括号 closeModal()！
一旦你在后面加了对小括号，JavaScript 解析到这行的时候哪怕不点击也会立刻当场将函数爆炸执行。去掉括号，等同于：“喂！浏览器，帮我收好这份叫 closeModal 的图纸，有人点了你再给我照着执行！”

1. 下拉菜单、折叠面板、轮播图等交互在底层技术实现上，最主要/最标准依赖的 DOM API 是哪一个？
A) `element.style` 直接修改大量具体的宽高颜色背景。
B) `element.classList` 配合 add, remove, toggle 方法进行专门 CSS 类的切换挂载。
C) `element.textContent` 去修改元素中的文字促使网页重绘。
👍 正确！ 解析：专业级的大型网站无一例外都是采用 classList 进行类名的调度切换。CSS 负责表现，JS 仅负责逻辑开关。这样实现了样式与行为的完美结构解耦。

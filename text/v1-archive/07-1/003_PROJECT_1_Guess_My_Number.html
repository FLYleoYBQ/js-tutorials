🎯 项目概述与演示

这是我们将要构建的第一个复古感（Retro 80s）项目：猜数字游戏 (Guess My Number)。

游戏规则非常简单：系统会在后台随机生成一个 1 到 20 之间的秘密数字。玩家需要在输入框中输入猜测，点击“Check”按钮进行检验。

当你想再玩一局时，点击“Again”按钮将重置所有状态和分数，但是**保留你创下的历史最高分 (Highscore)**，借此激励玩家更快地猜出答案。现在，我们就来看看，要让这个逻辑跑起来，我们的 JS 首先需要学会什么绝技。

1. 如何在JS中“抓取”元素？

游戏中有一段负责显示提示状态的文字，例如一开始写着 "Start guessing..."，在 HTML 中它长这样：

<p class="message">Start guessing...</p>

想要通过 JavaScript 控制这行字，我们要做的第一件事就是在茫茫 HTML 文档中找到并选中它。我们使用 document.querySelector() 这个强悍的方法：

🧩 生活类比：document 就像是这本花名册的总司令，而 querySelector 就像是他手下的特工探测器。你给特工下达指令字符串：『去找那个胸牌带有类名 .message 的家伙』，特工就会把该元素活捉回来交给你。

// 使用和 CSS 选择器一模一样的语法！
document.querySelector('.message')

注意，由于它具有类名 (class)，我们在选择器字符串 '.message' 中使用了小数点。如果它是 ID，则需要用井号 '#'。

🧪 学习验证

1. 在 JavaScript 中，哪行代码可以正确捕获下面这个 HTML 的计分板文本？
<span class="score">20</span>
A) document.querySelector('.score').textContent
B) document.querySelector('score').text
C) document.querySelector('#score').textContent
👍 正确！ 解析：因为 HTML 中的属性配置是 `class="score"`，所以传递给 `querySelector` 的选择器字符串必须加上 CSS 的类选择符前缀也就是小数点 `.`，所以选 `.score`，获取纯文本属性名为 `textContent`。

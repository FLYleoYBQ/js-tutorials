1. 终极实战：Pig Game

欢迎来到本章最庞大、逻辑最复杂的终极项目：Pig Game (吃猪骰子游戏)！
在这个双人对战游戏中，我们将全方位运用迄今所学的 DOM 操作、事件监听、类名切换，并在一个真实完整的游戏循环中锤炼编程逻辑。

2. 架构先行：流程图设计

在编写像双人游戏这样复杂的应用时，严禁直接上手写代码！ 那会让你陷入死胡同。
专业的开发者在编码前，一定会先借助诸如 diagrams.net 等工具绘制一份 流程图 (Flowchart)。

对于 Pig Game，你需要弄清楚：起手条件是什么？掷骰子点数为 1 会发生什么？点击“Hold”(保留分数) 时又会触发哪些状态切换？只有脑中有图，代码才不会乱。

3. 另一把利器：getElementById

打开这个项目的 HTML，你会发现页面中很多核心数据的容器不再是仅仅使用 class，它们甚至拥有全世界独一无二的 id (比如玩家 1 的总分 ID 为 score--0)。

我们之前总是使用万能神油 document.querySelector('#score--0') 来抓取带有 ID 的元素。但当你在面对 ID 时，JavaScript 引擎底层其实为你准备了一把更为锋利、据称抓取速度更快的专用手术刀 —— getElementById。

万能用法：querySelector
// 需要用 # 前缀来宣告这是一个 ID
const score0El = document.querySelector('#score--0');
原生专用：getElementById
// 无需前缀！函数名已经明确了它只找 ID
const score0El = document.getElementById('score--0');

💡 老鸟建议：
虽然 getElementById 在极端情况 (同时抓取成千上万个元素) 时确实比 querySelector 稍快一丢丢，但在现代性能过剩的浏览器下感受并不明显。很多开发者为了保持心智统一，依然全盘使用 querySelector。不过作为合格的前端，你必须认识它！

4. 设定初始状态 (Init)

游戏刚打开时，页面上可不能有假数据。我们要把两边玩家的分数都归零，同时要把屏幕中间那颗巨大的骰子给“藏起来”。

// 1. 在文件顶部统一抓取元素兵马
const score0El = document.getElementById('score--0');
const score1El = document.getElementById('score--1');
const diceEl   = document.querySelector('.dice');

// 2. 设定游戏开局状态 (Initialization)
score0El.textContent = 0;
score1El.textContent = 0;
// (注：我们将数字 0 塞进去，JS引擎会在底层自动把它转换为字符串 "0" 并显示)

// 3. 隐藏骰子：复用上一节的 classList 大法
// 在 CSS 中已经写好了 .hidden { display: none; }
diceEl.classList.add('hidden');

现在，你的游戏大厅已经打扫得干干净净。在下一节，我们将正式写下掷出虚拟骰子的核心随机算法与 DOM 更新！

🧪 学习验证

1. 下面哪一句利用 `getElementById` 来选取 `
` 的语法是绝对正确的？
A) `document.getElementById('#player-status');` (因为是ID，所以必须要加 `#` 号)
B) `document.getElementById('player-status');` (不需要加 `#`，因为函数名本身就已经指明了找的是 ID)
👍 正确！ 解析：`getElementById` 是非常死板和专才的 API，它就是冲着 ID 去的，所以你只要给它原本的名字字符串即可；如果你在前面加上了 `#` ，它反而去网页里找有没有谁的名字叫 "#player-status"，那当然找不到啦。

连接外部 JavaScript 文件

📺 来源：004 Linking a JavaScript File.en.srt 📂 章节：第 02 章

🎯 概述

在企业级开发中，我们绝对不可能把成百上千行的 JavaScript 代码揉合在浏览器的隐秘控制台，或者强行写死在 HTML 页面中间。真正的做法是：实现展示层（HTML）与 逻辑层（JavaScript）文件的彻底物理分离，并通过桥梁连接它们。

1. 分离与桥梁连接

创建一个名为 script.js 的空白文件（后缀 .js 代表 JavaScript 文件）。这就是我们未来驰骋的战场。

然后回到前端大门 index.html 文件，在 <body> 结束前（通常是最底部），插入这个召唤仪式：

<body>
  <h1>JavaScript 奇妙之旅</h1>

  <!-- 通过 src 属性指引到外挂的 JS 文件位置 -->
  <script src="script.js"></script>
</body>

⚠️ 错误排查须知：如果连接后浏览器没动静：

  • 检查文件拼写是否是 script.js 以及 HTML 中 SRC (Source) 是否正确拼写。
  • 检查两个文件是否被你保存在了同一个电脑文件夹层级下。

2. console.log() 的力量

在控制台环境中，即使你只写 40 + 8 + 23 - 10 并回车，控制台由于其 REPL 本质会自动吐出结果。

但是！在外部 JS 文件中执行了算术或者其他逻辑，它默认是在“黑暗的幕后”运行的。如果你想在前台把结果打印到浏览器的控制台中，你必须强制召唤：console.log()。

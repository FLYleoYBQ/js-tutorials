基础运算符 (Basic Operators)

📺 来源：009 Basic Operators.en.srt 📂 章节：第 02 章

能够计算出数值或产生布尔结果的特殊记号被称为“运算符”。它们能帮助我们执行运算或合并数据。

1. 数学运算符 (Math Operators)

包括我们最熟悉的加减乘除 + - * /，以及 ES6 引入的强力指数运算符（计算几次方） **。

math.js

💡 提示：神奇的是 + 号还能用于字符串缝合。"Jonas" + " " + "Schmedtmann" 结果将会是 "Jonas Schmedtmann"。

2. 赋值运算符 (Assignment Operators)

等号 = 是最基底的赋值运算符（将右边的结果给予左边）。除此之外，还有用于简写的强力突变运算符。

assignment.js

3. 比较运算符 (Comparison Operators)

我们用它们来提问！最终的结果永远是 Boolean (true / false)：

  • > (大于) 和 < (小于)
  • >= (大于或等于) 比如测试某人是否满 18 岁（可涵盖18）
  • <= (小于或等于)
comparison.js

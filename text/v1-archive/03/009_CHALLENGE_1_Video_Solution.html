🏆 Coding Challenge：体操比赛裁决者

🤸‍♂️

背景介绍：
海豚队（Dolphins）和考拉队（Koalas）正在进行一项全新的体操比赛大奖赛。每次比赛共有3次试跳得分，通过计算全部三跳的平均分来决定整支队伍的分数。

📋 任务清单（Tasks）

  1. 写一个箭头函数 calcAverage，用来求出3个数字的平均值。
  2. 用上面的函数计算出海豚队和考拉队各自的平均分。
  3. 写一个普通函数 checkWinner。这个函数接受队伍两边的平均分为参数（avgDolphins, avgKoalas）。
  4. 在 checkWinner 内部执行胜负判定公式：只有当一队的平均分达到另一队平均分的 2 倍（或以上）时，该队才算获胜。 如果符合条件，使用 `console.log` 打印出 `Dolphins win the trophy (30 vs. 13)`，否则打印并没有队伍获胜。
  5. 在 Data 1 和 Data 2 的数据集上分别算出结果！提示：判定2倍的公式为 `A >= 2 * B`。

🧪 测试数据集（Test Data）

  • Data 1：海豚队得分 44, 23, 71。考拉队得分 65, 54, 49。
  • Data 2：海豚队得分 85, 54, 41。考拉队得分 23, 34, 27。

💡 Jonas 官方解法揭秘 (Spoilers! 先自己试哦)

如果你已经成功做出来了，或者卡在某一步无法动弹，别怕！下面是我本人（Jonas）的思维拆解：

第一步：创造能通用一切三连数的 calcAverage 箭头机器：我们不要把函数名限制死在算跳水成绩上，所以我们就使用 a, b, c 代替参数。

const calcAverage = (a, b, c) => (a + b + c) / 3;

第二步：应用算出的平均分。因为我们要算两次不同的数据，如果希望重复利用这两个变量赋值，那么我们要用 let 声明，而不是没法改写的 const。

let scoreDolphins = calcAverage(44, 23, 71);
let scoreKoalas = calcAverage(65, 54, 49);

第三步：写判定法则。这是非常优美的独立判定模块：

const checkWinner = function(avgDolphins, avgKoalas) {
    if (avgDolphins >= 2 * avgKoalas) {
        console.log(`Dolphins win the trophy 🏆 (${avgDolphins} vs. ${avgKoalas})`);
    } else if (avgKoalas >= 2 * avgDolphins) {
        console.log(`Koalas win the trophy 🏆 (${avgKoalas} vs. ${avgDolphins})`);
    } else {
        console.log('No team wins... 😢');
    }
}

最后：执行。并在第二组数据中直接覆盖变量执行！

checkWinner(scoreDolphins, scoreKoalas);
// 第一波数据测试完成。没有任何队伍获胜（因为都没有到达对面 2 倍）

// 开始更新数据注入
scoreDolphins = calcAverage(85, 54, 41);
scoreKoalas = calcAverage(23, 34, 27);
checkWinner(scoreDolphins, scoreKoalas);
// 神奇的事情发生了：Dolphins 的 60 刚好打败了 Koalas 的 28。海豚队胜利！

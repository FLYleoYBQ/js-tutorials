The while Loop (While 循环)

📺 来源：022 The while Loop.en.srt 📂 章节：第 03 章

🔬 解剖 While 循环体

我们已经知道 For loop 那非常整齐的组件阵列（起点、极限、递推）。但是有另一种循环极其奔放叛逆：while 循环。

While 循环内部被剥除到了极致，它只要求一样东西：循环条件(Condition)。至于起跑线放哪，怎么向前递推，全部由你在外面手动操刀控制！

let rep = 1;  // 起点：必须扔到外部独立定义

while (rep <= 10) {  // 宇宙真理：当括号内依然成立，它将至死方休。
    console.log(`Lifting weights repetition ${rep} 🏋️`);
    rep++; // 你必须在代码块的最末尾手动挂推挡齿轮。否则浏览器将卡死(死循环)！
}

⚔️ 哲学难题：何时拔出 While 之剑？

既然能用 For，为何还需要残废版的 While？

因为 While 循环其实具有比 For 极度广泛的适用性：当你不知道你要做多少次迭代才能完成任务的时候。

比如：你要不停地掷骰子，直到掷出极品数字 “6” 才会停下！因为都是随机概率，这一路可能走 1 步，也可能走 800 步。这种没有任何定长数量级的悬疑地带，正是 While 循环降维打击的地方。

💡 实战选择指南：
当你明确知道你要循环某个阵列，哪怕不知道具体长度但用 .length 已经获取到总额度数字了——永远果断使用 For 循环。
当你对何时停手一无所知，只能把希望寄托给运行时诞生的某种条件时，请点燃 While 循环 的火花。

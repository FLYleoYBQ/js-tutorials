Handling Click Events

📺 来源：006 Handling Click Events.en.srt 📂 章节：第 07 章

🎯 概述

让网页变“活”起来的灵魂，就在于响应用户的操作。在 "Guess My Number" 游戏中，我们需要在用户点击「Check!」按钮时，读取输入框的数字并作出反馈。要实现这一点，我们需要祭出 DOM 操作中最强大的武器：事件监听器 (Event Listener)。

1. 事件监听器 (addEventListener)

事件 (Event) 是页面上发生的动作，比如鼠标点击、键盘敲击、甚至是鼠标滑动。我们使用 addEventListener 方法在特定元素上“竖起耳朵”监听这些动作。

🛠️ 绑定点击事件的标准语法

document.querySelector('.check').addEventListener('click', function() {
    console.log(document.querySelector('.guess').value);
});

这段代码由两个关键参数组成：

  1. 事件的名称：第一个参数是一个字符串 'click'，指明我们在等什么事情发生。
  2. 事件处理函数 (Event Handler)：第二个参数是一个函数 (Function)。这个函数体内包含了当事件发生时，我们到底想要执行什么代码。

2. 核心概念：将函数作为“值”传递给另一个函数

🚨 千万不要在这儿把函数“调用”了！

初学者极易在这里犯错，写成类似 addEventListener('click', myFunction()) 的代码。请记住：在 JavaScript 中，函数也只是一种特殊的数值 (Value) 罢了。

就像我们可以把字符串当参数传给函数一样，我们也可以把一整个函数当参数，原封不动地传给 addEventListener 这台机器。这叫回调函数 (Callback Function)。我们仅仅是把这行代码“告诉”了 JavaScript 引擎，引擎会将其默默存起来。只有当按钮真正被点击的那一刻，JavaScript 引擎才会帮我们执行这个函数！

3. 游戏逻辑的起点：类型转换与空值检测

一旦按钮被点击，我们的处理函数就开始工作。通常第一件事是获取输入，并做两项非常重要的前置处理：

① 强制转换数据类型 (String -> Number)

不论用户在页面输入什么（哪怕是纯数字如 23），只要是通过 DOM 拿到的输入内容，它默认永远是 String 字符串类型！要拿去跟游戏底层的秘密数字比大小，第一步必须是将它转成数字。


const guess = Number(document.querySelector('.guess').value);
console.log(guess, typeof guess); // 输出: 23, "number"

② 首要逻辑防御：用户没输入时的提示

如果用户没填任何数字直接点了 Check 按钮，guess 变量会被 Number() 转换成 0。在 JavaScript 中，0 是 falsy (假值)。

我们用非运算符 ! 将这个 false 反转为 true，从而触发保护机制的 if 语句：


if (!guess) {
    // 操作 DOM 显示错误提示
    document.querySelector('.message').textContent = '⛔ No number!';
}

这就是实现任何带有输入框应用的第一准则：永远先假设用户没有给数据，然后针对这种情况做处理，再接着写后续成立后的游戏逻辑。

🧪 学习验证

1. 下面这段代码为什么会一加载页面就执行了，而不是等点击按钮时执行？ `document.querySelector('.btn').addEventListener('click', reactToClick());`
A) 因为 JavaScript 会把页面上所有见到的函数立刻执行一遍。
B) 因为末尾的括号 `()` 意味着“立刻调用该函数”。你应该移除括号，只传入函数的名称（即将函数本身作为值传递）。
正确答案：B。这大概是新手最容易犯的错误之一。一旦加了括号 `()`，函数就会在代码被初次解析时立即执行，然后把它的返回值（很可能是 undefined）交给了 addEventListener 当作第二个参数，这彻底破坏了事件监听的意图。

2. 用户在数字输入框填了 18，不经过 `Number()` 处理直接读取并执行 `guess === 18`，结果会是怎样？
A) 返回 false。因为直接读取的必定是字符串 `'18'`，严格相等 (`===`) 时类型不同。
B) 返回 true。JS 引擎知道这是一个数字输入框，会自动转换为数字类型 18。
正确答案：A。DOM 从 UI 接收到的一切交互内容（包括 number input），在 JS 侧统统都是纯字符串 (String)！如果不手动转成 Number，比较大小/做加法会导致可怕的 Bug。

Implementing Highscores

📺 来源：010 Implementing Highscores.en.srt 📂 章节：第 07 章

🎯 概述

上节课我们通过 "Play Again" 按钮完美实现了游戏的本轮重置，而没有刷新整个浏览器页面。这为我们引入 highscore (最高分) 系统打下了基础，因为如果我们刷新了网页，所有 JavaScript 内存中的数据都会瞬间被抹除。现在我们要让程序“记住”你跨局达成的最高分！

1. Highscore 的业务逻辑

在动手写代码前，我们必须先理清业务逻辑，弄明白**“在什么时候去检查并更新最高分？”**

显然，玩家还在苦苦挣扎猜数字的时候（数字太大/太小），最高分是毫无意义的。只有在一个时刻我们需要去检验成绩：那就是当玩家猜中数字（获胜）的那一瞬间。

在那一刻，如果玩家当前这局的得分 (score) 击败了历史保留的最高分 (highscore)，那就产生了一个新纪录！

2. 代码实现：状态驻留与判断

首先，我们需要一个新的全局“应用状态”变量来记录最高分：


// 全局状态定在最上方
let secretNumber = Math.trunc(Math.random() * 20) + 1;
let score = 20;

// 新增：高分状态，打底为 0。这样玩家第一次赢必定能破纪录。
let highscore = 0;

接着，我们去寻找代码中处理“玩家获胜” (guess === secretNumber) 的那个 if 分支块。在改变背景颜色和显示正确数字的背后，悄然加上比较分数的霸气逻辑：


} else if (guess === secretNumber) {
    document.querySelector('.message').textContent = '🎉 Correct Number!';
    document.querySelector('.number').textContent = secretNumber;

    document.querySelector('body').style.backgroundColor = '#60b347';
    document.querySelector('.number').style.width = '30rem';

    // 👇 处理最高分逻辑 👇
    if (score > highscore) {
        highscore = score; // 玩家破纪录，把当前分数赋给最高分变量
        
        // 别忘了通过 DOM 将破纪录的喜悦显示在屏幕上！
        document.querySelector('.highscore').textContent = highscore;
    }
}

💡 大功告成！ 由于我们在上节课 "Play Again" 的重置功能中，刻意没有重置 highscore 变量，所以当你点击重玩时，即使 score 变回了 20，你的 highscore 依然骄傲地留在内存和网页上。

🧪 学习验证

1. 为什么我们必须借助 "Play Again" 按钮来重置游戏，而不是简单地叫玩家按浏览器的 F5 刷新？
A) 浏览器刷新会导致 DOM 加载变慢。
B) 一旦刷新网页，JavaScript 引擎的内存空间会被彻底清空，所有的全局变量（包括 `highscore`）会被销毁并重新初始化为 0。所以必须通过代码软重置状态。
正确答案：B。Web 页面的本质是“无状态的”。每次完整的刷新都会重新读取并执行一遍 JS 文件，这意味着所有的变量声明 `let highscore = 0;` 会重新运行，你幸苦保留的分数就彻底凉凉了。（注：后续课程会有 LocalStorage 存到硬盘里的持久化方法）。

Rolling the Dice

📺 来源：016 Rolling the Dice.en.srt 📂 章节：第 07 章

🎯 概述

游戏初始化完成后，现在我们来实现核心交互：抛骰子 (Rolling the Dice)。

抛骰子的逻辑包含三大步骤：生成 1 到 6 的随机数、在页面上显示对应的骰子图片、检查是否掷出了 1（如果是 1 就惩罚并换人，否则把分数加到当前积分里）。本节主要实现“非 1”状态下的分数累加和图片切换。

1. 第一步：生成随机数与动态切换图片

我们依然使用老朋友 Math.trunc(Math.random() * 6) + 1 来生成随机数。最酷的是我们如何把这个数字和网页上的图片对应起来：

在 HTML 中，展示图片的标签是 <img src="dice-5.png">。我们可以通过 JavaScript 动态抢走它的 src 属性，把它偷换成我们甩出来的点数对应的图片！


// 当用户点击 "Roll dice" 按钮
btnRoll.addEventListener('click', function () {
    // 1. 生成 1 到 6 的随机数
    const dice = Math.trunc(Math.random() * 6) + 1;

    // 2. 移除 hidden 类，让被隐藏的骰子重新显示出来
    diceEl.classList.remove('hidden');

    // 3. ⭐️ 动态切换图片 
    // 图片文件名恰好叫做 dice-1.png, dice-2.png 等，我们利用模板字符串拼接！
    diceEl.src = `dice-${dice}.png`; 
});

2. 第二步：用状态变量 (State Variable) 记住当前得分

当玩家掷出点数后，我们需要将其累加。这里最大的陷阱是：你应该在哪里声明 currentScore（当前得分）变量？

🚨 错误示范：写在事件流内部
如果你在 btnRoll.addEventListener 内部写 let currentScore = 0;，每次点击按钮时，它都会把 0 重新赋值一次，你的分数永远只能记录最后一次抛掷的结果！

为了让分数能在多次点击中持久存活 (persist)，这个变量必须存放在大环境（外部），这就是游戏的基础状态 (State)：

🧪 学习验证

1. 我们需要用 JavaScript 替换 <img> 标签显示的图片，应该修改其哪个属性？
A) `element.image = '...'`
B) `element.src = '...'`
正确答案：B。DOM 对象的属性与你在 HTML 中写标签时的属性高度映射。在 HTML 中我们写 <img src="">，因此在 JS 里改变图片路径用的就是 .src。

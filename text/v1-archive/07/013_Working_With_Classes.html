Working With Classes

📺 来源：013 Working With Classes.en.srt 📂 章节：第 07 章

🎯 概述

上一个项目中，我们通过 element.style.property 的方式逐一修改 CSS 行内样式。但如果一个状态（比如“激活”、“隐藏”）包含十几个 CSS 属性，每次都用 JS 逐行去写简直是恶梦。现代前端开发中，我们更喜欢把样式打包进一个 CSS Class 里，然后通过 JavaScript 去“开关”这个 Class。

1. 神器：classList API

在这个项目中，模态框和黑色遮罩层默认都带有一个叫做 hidden 的类，这个类的 CSS 代码其实就是一句 display: none;。想要让它们显示出来，我们只需要移除这个类。


for (let i = 0; i < btnsOpenModal.length; i++) {
    btnsOpenModal[i].addEventListener('click', function() {
        // ❌ 以前的做法：(繁琐，且会覆盖内联样式)
        // modal.style.display = 'block';
        
        // ✅ 现在的做法：移除 'hidden' 类
        // 注意：传入的类名 string 前面绝对不要加点 (.)
        modal.classList.remove('hidden');
        overlay.classList.remove('hidden');
    });
}

同样地，当我们需要关闭模态框时，只需要把这个类添加回去即可：


// 当点击“关闭(X)”按钮时
btnCloseModal.addEventListener('click', function() {
    modal.classList.add('hidden');
    overlay.classList.add('hidden');
});

💡 最佳实践： CSS 负责管样式（把所有的属性写在新 Class 里），JavaScript 负责管逻辑（决定在什么时候给元素加上或移除这个 Class）。这种分离能让你的代码更干净、更易维护。

2. DRY 继续：复用事件处理函数

现代交互设计中，除了点右上角的 X 能关闭弹窗外，点击弹窗外部的黑色遮罩层 (overlay) 通常也能关闭弹窗。按照目前的学识，你可能会把上面的代码复制一份给 overlay：


// ❌ 糟糕的做法：重复写相同的回调函数逻辑
overlay.addEventListener('click', function() {
    modal.classList.add('hidden');
    overlay.classList.add('hidden');
});

为了遵守 DRY 原则，我们可以把这段关闭逻辑提取为一个有名字的函数，然后在两个 addEventListener 中把它当作参数传进去：


// 1. 声明一个带名字的函数表达式
const closeModal = function() {
    modal.classList.add('hidden');
    overlay.classList.add('hidden');
};

// 2. 把函数【扔给】addEventListener 老板，让它在合适的时候去执行
btnCloseModal.addEventListener('click', closeModal);
overlay.addEventListener('click', closeModal);

🚨 致命易错点提醒： 在传参时，写的是 closeModal，绝对不能写成 closeModal()！
一旦加上括号 ()，JavaScript 会在解析到这一行时立刻执行这个函数。我们不希望一刷新页面窗口就关了，我们希望的是当点击发生时，由浏览器代我们去执行它。

🧪 学习验证

1. 关于添加或移除 CSS 类的语法，以下哪项是正确的？
A) `modal.classList.remove('.hidden');`
B) `modal.classList.remove('hidden');`
正确答案：B。这是一个每天都能坑死无数新手的点。`querySelector` 里必须要传 `.` 因为它要区分标签和类；但在 `classList.add / remove` 方法里，明确规定只接受“纯类名”，所以前面的点 `.` 绝对不能加！

2. 为什么在绑定事件时写 `btnCloseModal.addEventListener('click', closeModal)` 而不是 `closeModal()`？
A) 因为加上圆括号意味着“立即调用并获取返回值”，我们不希望它马上执行。我们只想把函数体本身作为参数传给事件监听器，让监听器在检测到点击时再去调用它。
B) 因为 JavaScript 在事件监听器中不支持使用带括号的函数调用。
正确答案：A。把函数本身当作一个值传递（不加括号），而不是传递它的执行结果（加上括号），这是 JavaScript 【一等公民函数】的核心魅力之一。

📖 词汇速查表 (Cheat Sheet)

中文术语 代码 简明释义
移除 CSS 类 .classList.remove('类名') 将指定的类名从元素的 class 列表中移除（注意不带 .）
添加 CSS 类 .classList.add('类名') 将指定的类名添加到元素的 class 列表中（注意不带 .）

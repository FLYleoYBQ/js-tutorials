🐛 报错实验室

在严格模式 (`'use strict'`) 下，函数自身也是**块级作用域**的！如果你在一个 if 代码块内部声明了一个函数，一旦离开那个 if，在外部去调用该函数会立刻触发 ReferenceError: xxx is not defined。

exercise_1.js
💡 参考答案

由于 const 是块级作用域的，在 if 和 else 大括号内声明的 price 在外部已经被销毁了。在最外层找不到它们。

function calculateCart(hasDiscount) {
    // 正确的做法：在父级作用域中事先立好变量
    let price; 

    if (hasDiscount) {
        price = 50;
    } else {
        price = 100;
    }
    console.log(`Total price is ${price}`);
}
calculateCart(true);

function check() {

        var a = 1;
        const b = 2;
    }
    console.log(a);
    console.log(b);
}
check();
A) 打印 1 和 2
B) 第一行报错 ReferenceError: a is not defined
C) 第一行打印 1，第二行报错 ReferenceError: b is not defined

🔧 代码填空

要想在函数内改变外部全局中声明的 score 变量，同时**不要产生遮蔽 (Shadowing)** 现象，划线处不应该带有声明关键字：


let score = 10;
function updateScore() {
    // 补全下面的代码，使其修改外层的 score 而非创建局部变量
    _______ = 99;
}
updateScore();
console.log(score); // 期望得到 99
💡 答案 
score = 99; // 直接赋值，不要带 let 或 const

An High-Level Overview of JavaScript (JavaScript 高级定义概览)

📺 来源：003 An High-Level Overview of JavaScript.en.srt 📂 章节：第 08 章

🎯 概述

如果有人问你“什么是 JavaScript？”，除了回答它是一门在浏览器里跑的编程语言，你还能说出什么？本节课我们将剖析 JavaScript 的 9 大核心特征，从高级语言到底层单线程事件循环，带你重新认识老朋友 JS。

1) 🏢 高级语言 (High-Level)

在 C 语言这种**低级语言 (Low-level)** 中，开发者必须像仓库管理员一样，手动向计算机申请内存 (Allocate) 并手动释放。一旦忘记，程序就会崩溃 (内存泄漏)。

而在 JavaScript 或 Python 这种**高级语言 (High-level)** 中，有一套抽象层帮你代劳了这一切。这让语言变得极其容易学习，代价是它永远跑不出像 C 语言那样极致优化的速度。

2) 🗑️ 垃圾收集 (Garbage Collection)

🧩 生活类比：就像你住在一个自带隐形保洁阿姨的酒店里。你在房间里扔的垃圾（那些不再被引用的变量和对象），阿姨会在后台悄悄帮你清理掉，不让房间（内存）被塞满。

这是 JS 引擎内部的一个强大算法，它会自动找到内存中无用的旧对象，并将它们清除。

3) ⚡ 解释型或 JIT 编译 (Interpreted or Just-In-Time Compiled)

计算机 CPU 只认识 `010101` (机器码)。我们写的 JS 代码必须被翻译。过去 JS 被认为是纯解释型语言（边读边执行，速度慢），现今的现代 JS 引擎（如 V8）采用的是极其先进的 **JIT (即时编译)**，在代码执行前一瞬间将其编译为机器码，实现了性能的飞跃。

4) 🎭 多范式 (Multi-Paradigm)

范式（Paradigm）是指编写代码的思维方式和结构体系。很多语言只能单一使用一种，但 JS 是个多面手，它支持：

  • 过程式 (Procedural)：我们前几章写的线性的“记流水账”代码。
  • 面向对象 (Object-Oriented)：基于对象和类。
  • 函数式 (Functional)：近年来非常火爆的抽象思维，得益于 JS 的头等函数特性。

5) 🧬 基于原型的面向对象 (Prototype-based OOP)

在 JS 中，几乎一切皆为对象（除了基础原始值如 String、Number）。

比如，为什么我们可以对一个通过 `const arr = [1, 2]` 创建的数组直接调用 `.push()` 方法？那是因为由于**原型链继承 (Prototypal Inheritance)**，这个数组从底层的“数组蓝图 (Array Prototype)” 中直接继承了百宝箱里的所有方法。

6) 🥇 头等函数 (First-Class Functions)

这是 JS 最迷人的特性之一。在 JS 的世界里，函数并不高人一等，它就跟普通的变量一模一样！

正因如此，我们可以把一个函数当作包裹，塞进另一个函数里做参数（比如我们之前在弹窗项目里写的 btn.addEventListener('click', closeModal)，就把 closeModal 当作变量传进去了）。

7) 🔄 动态类型 (Dynamic Ttyped)

在 C 或 Java 中，声明变量前必须死板地发誓：“这个变量永远只能存整数 (int x = 10;)”。

而在 JS 中没有这规矩：let x = 10; x = "hello";。虽然方便，但这也是许多恶性 Bug 的根源，正因此业界诞生了 TypeScript (强类型 JS) 来弥补这一缺陷。

8 & 9) 🧵 单线程 (Single-Threaded) 与 ⏳ 非阻塞事件循环 (Non-blocking Event Loop)

单线程意味着：JS 在同一时刻，只能干一件事 (执行一条指令)。

这带来一个致命问题：如果有一项耗时巨长的任务（比如从网络下载一张 50MB 的图片），如果只能单排队，那整个网页不久卡死 (Blocking) 了吗？

为了做到非阻塞 (Non-blocking)，JS 引擎引入了牛逼的 事件循环 (Event Loop) 并发模型。它的核心思想是：把耗时的长任务一脚踢到“后台 (Background)”去慢慢熬，主线程继续飞速运行后续代码；等后台任务熬好了，再把它放回主线程里执行。这是这门课后期最难、最迷人的终极课题。

🎯 概述

上节课我们学习了“四步框架”，今天我们要用它来实战！假设你入职了一家生产智能温度计的公司，经理派给你一个任务：“给定一个包含一天中温度数据的数组，计算出当天的 温度振幅（Temperature Amplitude）。注意，传感器偶尔会报错。” 让我们看看如何用 Google 取长补短，破局解题。

1. 问题拆解：计算温度振幅

面对这个需求，我们首先按照四步法进行拆分（Divide and Conquer）：

  • 搞懂问题： 什么是“温度振幅”？答：最高温与最低温之间的差值。传感器报错长什么样？答：一个写着 'error' 的字符串，我们需要忽略它。
  • 打碎子任务清单：
    1. 如何遍历数组并跳过 'error'？
    2. 如何找出数组中的最大值？
    3. 如何找出数组中的最小值？
    4. 将最大值减去最小值，返回结果。

2. 借力 Stack Overflow：寻找最大/最小值

你可能不知道该怎么在 JavaScript 中找出数组里最大的数字。遇到这种常见的“轮子”，千万别觉得羞愧，直接在 Google 搜索：javascript get max value in array。通常第一个结果就会把你引向全球最著名的程序员问答社区 —— Stack Overflow。

❓ 理解检测

1. 在开发中，Stack Overflow 和 MDN 的主要区别侧重点是什么？
A) Stack Overflow 是官方教程，MDN 是网友吹水论坛。
B) Stack Overflow 是互助问答社区（主治疑难杂症，看大家怎么修轮子），MDN 则是官方词典规范（主查 API 参数、长啥样）。
C) 两者完全一样，没有区别。
B 是正确的选项。前者提供人们踩坑后的经验拼凑解决方案；后者提供精确、详实的原生函数运作机制说明。

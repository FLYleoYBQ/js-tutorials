Installing Node.js and Setting Up a Dev Environment

📺 来源：004 Installing Node.js and Setting Up a Dev Environment.en.srt 📂 章节：第 05 章
📌 知识脉络
  • 前置知识：基本的 HTML 和 JS 文件保存、终端基础概念
  • 后续扩展：真正像工程师一样脱离“手动刷新”的工作流

🎯 概述

在现实的商业开发中，没有哪个前端工程师会在改完代码后，一遍又一遍地手动点击浏览器刷新按钮。本节我们将彻底消灭这种低效的重复劳动！我们将设置“Live Server”（实时运行服务器），它能监听文件更改并瞬间自动刷新浏览器，让你感受到顺滑的丝滑开发体验。

1. Live Server 插件（极简首选途径）

最快捷配置自动刷新的方式直接内建在 VS Code 扩展商店中：

  • 打开 VS Code 扩展面板，搜索 Live Server。
  • 点击“安装”。完成后，在 VS Code 底部状态栏会出现 Go Live 的字样。
  • 当你点击 Go Live，它将开启一个本地端口（形如 http://127.0.0.1:5500），自动弹出浏览器并载入此项目的 index.html。

现在，让它挂在后台，你随意在 JavaScript 中输入 console.log('Test'); 并按下 Ctrl+S / Cmd+S，留意浏览器窗口 —— 半秒不到它就自动无感重载并打印出了最新结果。再也不需要去点浏览器的刷新圆圈了！

2. Node.js 与全局 Live Server（专业级前端工作流）

如果你追求更原生、更酷炫的工程师做派，或者想要为后续深度使用构建工具打基础，我们可以利用 Node.js 环境以及终端（Terminal）在全局启动 Live Server。

第一部分：安装 Node.js。前往 Node.js 官网，下载对应的 LTS（长期支持）版本安装包并安装。
Node.js 不仅赋予了 JavaScript 脱离浏览器而在底层系统运行的魔力，它还带来了一位老朋友 —— npm (Node Package Manager)，世界上最大的代码包仓库。

第二部分：通过终端安装。打开 VS Code 内置终端（Terminal -> New Terminal）。键入以下命令验证 Node 存在：

node -v

若输出了版本号，在终端执行以下命令将实时服务器全局打包安装进系统中心（Mac 用户需要在前面加上 sudo 提权）：

npm install live-server -g

注：-g 标志代表 Globally（全局），意味着以后随便在哪个文件夹下都能呼出它。

第三部分：一键运转。当你清干净屏幕（Ctrl/Cmd + K），进入开发目录后，仅需自信地敲入这个词：

live-server

回车！熟悉的浏览器自动开启了！这两种方法的内核完全一致：任何时候你的文件变动，这个服务端代理就会向浏览器发送重新渲染讯号。

❓ 理解检测

1. 什么是 npm？
A) Node Program Monitor，用于监控浏览器是否死机的内置应用。
B) Node Package Manager（Node包管理器），用于在互联网上下载并安装海量开发者生态工具的仓库。
C) 一种只有苹果电脑才能运行的系统变量。
B 是正确的。npm 随 Node.js 同捆安装，是全球开发者共享、发掘强大命令行工具及运行库的包管理器。

🎯 概述

跟真实世界迷路的地图不同，代码世界里的 Map 就是最顶级的字典密码锁保险柜。
相较于前一节像乞丐残缺的 Set 集合，Map 是在真实业务与引擎底层被疯狂频繁压榨调用的明星数据结构。它同样提供了存储与索引，但是具备了 任意跨数据维度作键名 (Any Datatype as Key) 这项惊人超能力！

2. 高能神操作法：利用布尔逻辑运算强娶门牌信息

基于 Map 可以安放纯粹的 true 和 false 两枚布尔逻辑当做柜门的指纹扫描仪这一强力设定。你可以不写一句啰嗦恶臭的 if 或三元表达式，直接借计算的力反馈砸开那只正确的门：

const time = 21; // 假装现在是晚上九点

// 核心杀招：我们比对当前时间是不是在开门期间之内。
// 这截逻辑链条会产出一枚布尔结晶 (true/false)。
// 直接把这枚结晶像钥匙一样塞进锁孔！太过于天才和可怕的设计。
console.log(
    rest.get(time > rest.get('open') && time < rest.get('close'))
);
// 输出：'太棒啦！店里现在是大门敞开的营业时间！'

(注：虽然这么炫技装逼很刺眼非常过瘾甚至可以卖弄，但太紧绷不利于后来接手你项目的新入行小弟维护代码。尽量不要滥用形成病态代码。😄)

3. 复杂巨兽对象挂靠及：内存堆积地址暴踩天坑

除了刚才玩的原生小元素。Map 的最高狂野法术是可以将 一个完全臃肿庞大的数组，甚至另一个对象，甚至屏幕上的 HTML 一个实体 DOM 标签化身成为一枚 Key 指纹扣！

const arr = [1, 2];

// 将数组当做钥匙放进去。
rest.set(arr, '被隐藏掩盖在数组底下的大绝密资料！');

// 💣 菜鸟死亡盲区：不要尝试这样做！！！
console.log(rest.get([1, 2])); // 将会爆出尴尬的 undefined 提取失败

// 🛡️ 正确破解方式：
console.log(rest.get(arr)); // 绝杀！顺利提取：'被隐藏掩盖在数组底下的大绝密资料！'
⚠️ 内存地址天堑！不要被长得一样的孪生假象蒙蔽：

为什么上面的 rest.get([1, 2]) 抽不出钥匙拔不出数据了？那是因为在堆区庞大的底层内存银河网格网段里面。一开始存放并拿去挂靠定形的 arr 指向了一栋叫 A 区别馆内存。你后来强塞去探路的 [1, 2] 在底层只是被引擎刚出场盖起了一栋看着完全重长相的孪生大楼 B 区罢了！去扫描指纹当然认证无法匹配通过。一定要死死攥着指向同一个唯一内存引用地皮的变量本身。这就是高维物种的对象内存机制。

连前端的 HTML 外壳按钮节点都能充当一枚大锁扣呢！
rest.set(document.querySelector('h1'), '这就是主标题本体');
(想象一下在非常巨大且复杂的 Web 系统里，你可以随时抽查 HTML 节点本身上面私下粘着挂靠的什么神仙数据流)

❓ 理解检测

1. Map 与长得跟它差不多老祖先 Object 的根本灵魂剥离性特点在于？
A) 在它内部设做 Key（钥匙、查询键名）的物质，完全不受到任何形态种族属性的设限。无论是数字 1、对象数组 [a]、乃至纯正的布尔体 false、甚至是 DOM 树页面元件，它都能精准挂载上数据。
B) Map 和 Object 本质全一样，只为多增加个好记且名字短的对象形式罢了。
C) Map 可以调用 sort 去让里面的东西疯狂排序打圈。
A 是正确的选项。打破字符串 String 死板当钥匙盘的百年结界，就是 Map 横空出世在这个武林里的最高存在意义！它让映射技术有了极强的可拓宽想象延展边界。

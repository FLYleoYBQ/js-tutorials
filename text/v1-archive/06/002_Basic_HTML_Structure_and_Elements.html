Basic HTML Structure and Elements (基础的 HTML 结构和元素)

🎯 概述

如果你已经准备好学习 HTML 的基础，那就和我们一起动手吧。这节课将带你熟悉 HTML 的核心概念：元素（Elements） 与 标签（Tags），并梳理一个标准 HTML 文件的基本结构模型。

1. HTML 极简基础框架

HTML 全称是 超文本标记语言（HyperText Markup Language）。我们主要用它来描绘网页的基本内容结构。HTML 文档由各种各样的元素（Elements）组合而成。

写一个元素，我们通常需要一个起始标签（Opening tag）和一个闭合标签（Closing tag）。

🧩 生活类比：在 HTML 中写作，就像把一个个物品放进专属的储物盒（即元素）。比如把一句话放入 `<h1>` 这个盒子，为了说明放完了，我们要用 `</h1>` 这个带斜杠的盖子把盒子盖上。

所有的 HTML 项目，都通常始于一个名叫 `index.html` 的核心文件。当我们打开这个文件，它的顶层建筑应该如下所示：

flowchart TD A["🌐 <html>\n(包裹着网页上所有的东西)"] --> B("⚙️ <head>\n(网页的设置参数区)") A --> C("🧱 <body>\n(网页的可见肉身区)") B --> D["🏷️ <title>\n(网页的浏览器页签名称)"] C --> E["📝 所有你写在页面上的元素...\n(标题、段落、图片等)"] style A fill:#2e0618,stroke:#f03c15 style B fill:#1a1005,stroke:#f78c25 style C fill:#0f1d10,stroke:#3bb44a

① 首先，<html> 标签告诉系统：“你好，这是一个 HTML 文档！”
② 在内部我们分化出 <head> 和 <body> 两部分。
③ <head> 区域存放的是“给浏览器看的”设置，比如页签上的标题 <title>，或将来要关联的样式和图标等。
④ <body> 区域存放的是“给读者看的”实质性内容，这是我们将来主要的工作舞台。

2. 标题和段落标签

现在，我们将视线聚焦在 <body> 内。我们可以给页面添加各种各样有特定功能的元素。

大标题（Heading）： HTML 提供 6 个等级的标题标签，从 <h1> 一直到 <h6>。数字越大，标题级别越低，在浏览器中的默认字号也越小。

段落（Paragraph）： 标记普通文本内容的，往往是 <p> 标签。

index.html
⚠️ 常见误区：新手容易忘记写闭合标签（比如只写了 <h1>，迟迟不写 </h1>），这会导致在那之后所有的文本都被当成了标题，使得排版彻底崩溃！不过在现代编辑器如 VS Code 中，有很多扩展（如 Auto Close Tag）能够自动帮你补全斜杠结束标签。

3. VS Code 快速生成模板工具

每一次都去手写 `<html>`, `<head>`, `<body>` 实在是太费体力了。在 VS Code（Visual Studio Code）编辑器中，我们有一个绝妙的技巧来自动生成一个带标准前缀的网页骨架：

💡 神奇快捷键：在一个完全空白的 HTML 文件中，输入英文感叹号 ! ，然后立刻按下 Tab 键。奇迹发生了——你会看到一整段标准的 HTML5 Boilerplate（样板代码）！

<!DOCTYPE html>  <!-- 此标记明确告诉浏览器，这是 HTML5 规范的文档 -->
<html lang="en">  <!-- 顺便标注了这个页面的主语言是英文 -->
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
  <!-- 我们的舞台 -->
</body>
</html>

🧪 学习验证

❓ 理解检测

1. 在 HTML 中，下列哪一项内容会直接显示在网页的纯白画布（主视觉区）上供读者阅读？
A) 放在 <head> 内部的 <title> 标签
B) 放在 <body> 内部的 <p> 标签
C) <html> 外围的所有声明
👍 正确！ 解析：<head> 里的内容主要是设置（如浏览器顶部页签名字），而肉眼真实可见的页面主体全部都要塞到 <body> 中。
2. HTML5 标题的大小顺序是如何排列的？
A) 从 <h1> (最大) 一直到 <h6> (最小)
B) 从 <h1> (最小) 一直到 <h6> (最大)
👍 正确！ 解析：数字标志了"重要性级别"。H1 是最重要的顶级大标题，字号最大；H6 则是层级最深的副副副标题，因此字号极小。

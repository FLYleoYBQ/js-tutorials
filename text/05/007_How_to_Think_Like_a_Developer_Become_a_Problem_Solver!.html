🎯 概述

编程本质上就是“解决问题”。面对复杂的业务需求（比如“从 GPS 数组中找出最近的两个坐标”），你如果直接凭一股冲动猛敲键盘，最终通常会被乱如线团的逻辑逼入死胡同。本节课程教你一套万能的开发者【4 步解题框架】。

  • 第一步：100% 彻底理解问题。 不要上来就写代码！主动提问，搞清楚输入是什么？输出是什么？发生异常情况怎么处理？
  • 第二步：分而治之 (Divide and Conquer)。 将复杂的大问题，大卸八块，变成一个个简单好上手的小任务清单。
  • 第三步：善用搜索研究。 当卡在某个小任务上不知道怎么实现时，不要死脑筋，果断使用 Google、Stack Overflow 开发社区或 MDN 官方文档寻找灵感。
  • 第四步：编写伪代码 (Pseudo-code)。 用人类看得懂的逻辑（即使不是有效 JS 代码）写下整个执行流程大纲，整理好后再动手写出真正的代码。

2. 案例实战拆解

需求假设：经理要求“写一个能反转输入任何数据的函数”。

❌ 失败的做法：马上新建文件，打下 function reverse() {}，然后脑子一片空白。

✅ 四步框架流的做法：

Step 1：提问理解

  • “任何数据” 指的是什么？数值、字符串、数组都可以反转，但对象 (Object) 没有固定顺序，怎么反转布尔值也不合规矩。
  • 输入的类型不对该怎么办？
  • 输出应该和输入类型保持一致吗？

Step 2：分而治之

  1. 检测输入的值属于哪种类型（数字、字符串抑或数组）。
  2. 分别实现：怎么反转数字？
  3. 怎么反转字符串？
  4. 怎么反转数组？
  5. 返回最终值。

Step 3：调研搜索

如果在实现中不知道如何“检测类型”，就可以直接去 Google 搜索："How to check type in JavaScript?" 或者 "How to reverse string MDN" 寻找兵器。

Step 4：编写伪代码

直接在代码编辑器里写人类能懂的英文/中文草稿：

pseudo_code.js

有了这个脚手架，你只需要把这 5 句中文翻译成等效的 JavaScript 语法，功能自然水到渠成！

🧪 学习验证

❓ 理解检测

1. 什么是伪代码 (Pseudo-code)？
A) 一种人类看得懂的逻辑草稿，不受限于严谨的编程语法规则。
B) 一种只有高级编译器才能运行的秘密机器码。
C) 从网络上复制粘贴来的未经测试的残缺代码。
A 是正确的。伪代码用于搭建系统思考的大纲桥梁。写代码不过是将其“翻译”为特定语言语法的最后一步而已。

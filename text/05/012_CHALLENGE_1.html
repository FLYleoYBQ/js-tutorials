📝 需求描述

给定一个表示预报最高气温的数据数组。我们正负责构建的“前端温度计面板”需要将这组庞大的数据输出渲染为一句特定格式的长字符串。

你需要创建一个名为 printForecast 的函数。
它接收一个数组 arr 作为输入，并将上述格式的长字符串直接打印 (console.log) 在控制台上。

🎯 输出格式示范：
如果输入数组是 [17, 21, 23]，预期的打印结构必须如下：
"... 17ºC in 1 days ... 21ºC in 2 days ... 23ºC in 3 days ..."

理解问题：

  • 核心挑战在于需要把整堆 Array 转换为一个一体的 String，它们由 ... 间隔符拼接。
  • X 天代表什么？就是我们常说的第 1 天、第 2 天。本质上就是数组当前索引 (index) 加上 1。

拆分为子任务：

  1. 遍历数组元素并将元素转为其等效的格式："XºC in Y days"。
  2. 需要有个外部大字符串把这些小零碎像吸尘器一样全部聚合到一块。
  3. 处理起始和接驳处的 "..." 逻辑。
🔥 进阶：如何拼接超级长字符串

回顾一下计算总和。那也是在循环外声明一个 `sum = 0` 做容器。我们现在依葫芦画瓢，只是这次容器是一个空皮囊 `""`。

const printForecast = function(arr) {
    // 蓄水池变量，初始极净为空白
    let str = '';

    for (let i = 0; i < arr.length; i++) {
        // 利用模板字符串魔幻拼接，每次都向旧蓄水池填充水
        str += `${arr[i]}ºC in ${i + 1} days ... `;
    }
    
    // 我们发现上面的结果首部还缺一个 `...` 
    // 于是在全局输出打印的时候人工补充一个领班
    console.log('... ' + str);
};

printForecast([17, 21, 23]);

巧妙利用空的 String str 并在执行内部打补丁式向后累加 +=！这是编程里非常经典的模式。

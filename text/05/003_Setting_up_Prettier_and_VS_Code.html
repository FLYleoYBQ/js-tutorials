Setting up Prettier and VS Code

🎯 概述

让编辑器更好地为我们服务，是提升编码效率的关键。本节课我们将安装并配置 Prettier —— 一款行业标准的强制代码格式化工具，同时学习如何使用 VS Code 代码片段（Snippets）极大减轻输入 console.log 的体力劳动。

1. 配置 Prettier 格式化工具

Prettier 是一款极具“主见”（Opinionated）的代码格式化插件。它会对一段代码应该长什么样做出强硬假设，并在保存时自动调整空格、空行及引号等，从而一举终结开发团队关于“代码风格”的争论。

第一步：安装。在 VS Code 扩展面板搜索 "Prettier"，安装排名第一的扩展并点击启用。

第二步：设置为默认格式化程序。进入 VS Code 的【首选项】 > 【设置】，搜索 Default Formatter，在茫茫列表中选中 esbenp.prettier-vscode。同时，确保勾选了 Format On Save（保存时自动格式化）。

配置完成后，当你随便写一些未对齐的丑陋代码，只要按下 Ctrl+S / Cmd+S，Prettier 便会自动帮你清理空格、转换双引号等。代码瞬间变身行业标准级外观！

2. 定制 Prettier 规则

虽然 Prettier 很强硬，但它也开放了部分规则让我们微调。比如我个人更青睐单引号，而不喜欢它默认强加的双引号；又或者我不喜欢只有一个参数的箭头函数外边套着圆括号。

实现这一点最简单的方法是：在项目根目录下创建一个名为 .prettierrc 的配置文件。

.prettierrc

加入这个配置后，Prettier 就会遵守这几条特例：将字符串保留为单引号（singleQuote: true），并对单参数的箭头函数省略圆括号（arrowParens: "avoid"）。

3. 配置 VS Code 自定义代码片段 (Snippets)

你有没有觉得，一整天疯狂敲打 console.log() 的工作枯燥无比？VS Code 内建了“用户代码片段”（User Snippets）功能，可以让我们定义简写指令，自动展开为长代码。

步骤如下：前往【首选项】 > 【用户代码片段】 > 【新建全局代码片段文件】（例如随意命名为 jonas），录入以下代码：

jonas.code-snippets

现在，只要你在 JavaScript 文件中输入 cl 并回车，VS Code 就会“嗖”地一下展开成完整的 console.log(); 并且光标会自动放置在括号内（由 $1 占位符控制）。这看似微小的一步，每年却能为你省下成百上千次敲打按键的时间！

> 💡 **专家提示 (TODO Highlight)**：我强烈推荐你安装名为 `TODO Highlight` 的扩展。当你用 `// BUG` 或 `// FIXME` 书写注释时，它能以醒目的高亮红色或黄色提醒你，非常好用。

❓ 理解检测

1. Prettier 被称为“Opinionated（有主见）”的工具，这意味着什么？
A) 它强制接管格式化决策，不论你喜不喜欢，它都会按既定标准重写样式（空格、换行）。
B) 它会自动帮你修复 JavaScript 逻辑错误。
C) 它可以随时被其他插件取代，没有任何独占性。
A 是正确的。Prettier 的哲学是不给开发者太多选项（尽管有几个可配），强制统一风格团队标准，消灭关于排版好坏的主观争论。

Solving CHALLENGE #2 With AI

📺 来源：014 Solving CHALLENGE #2 With AI.en.srt 📂 章节：第 05 章
⚠️ 章节说明

本章是一个特殊演示挑战。我们将彻底使用在上节课学会的基于 ChatGPT 的辅助重构技巧，兵不血刃地破解一道包含你也许还不会的高阶数组操作特性的考题。以此来展示真实环境中的破壳解闷之剑该如何拔出鞘。

📝 需求描述

假设你目前在为自由职业者制作一个工时计时器 APP。你需要一个统计处理函数，可以按周吞入七个每天打卡的工时数值。并经过脑洞大开地运算后，全自动返回以下五大结果（用 Object 对象包裹打包带走）：

  • 整个打工周的总小时数
  • 平均每个有效工时日的打卡均值
  • 肝胆相照的爆肝日子（哪天卷得最狠最高）
  • 有效上工了有产出的天数（剔除了摸大鱼休假的 0 小时日子）
  • 判定这是否算是一个满血超载周工作全职周（标准线 >=35小时，布尔值真伪返回）

你或许可以利用你仅有的所学大汗淋漓地拼凑出一套 for 循环版本，这完全是一项加分勇敢之举！不过本案例，我们将让 AI 为我们一码平川。

1. 书写完美的 Prompt 提示词

好的回复，永远奠基于精良、苛刻、无歧义的高密度约束 Prompt 指令。让我们打开 ChatGPT，输入这种工业级标准黑话：

“I'm building a time tracking application for freelancers. Write a function called analyzeWorkWeek that receives an array of daily work hours and returns an object with the following data: total hours, average daily hours, day with the most hours worked, the number of days working with more than 0 hours, and whether the week was full-time (>= 35 hours). Also, assume Monday is day 0 in the array and round daily hours to one decimal place.”

2. 多次要求 AI 迭代修改与修复盲区

ChatGPT 第一时间为我们吐出了夹杂有神乎其神高阶语法如 reduce()、Math.max() 的代码。我们将它拷贝到编辑器里运行测试时发现：

痛点一：不直观的爆肝日。当前 AI 返回的最卷工作日 maxDay 居然是干巴巴的数字比如 4，太不优雅了。于是我们要求它迭代修正：
“change maxDay to be an actual work day like Monday”
聪明如它，理解后帮你在内部挂载了一个硬汉打卡天字版数组 ['Monday', 'Tuesday', ... ] 中转映射，输出变回了悦目的 "Friday"。

痛点二：对意外故障参数没有封堵。如果我们向新函数传入了只有 5 条记录的残废 Array，AI 写的方法并不会拦截，且导致一些均值除法被拉扯变形。我们需要追加防御：
“The function should require the input array to have exactly 7 days. Update the function accordingly.”
AI 收得指令，便在方法进门顶端处写了个拦截过滤门神：如果 length !== 7，就让它无情报错被 throw new Error(...)。

3. 反向倒逼：用它当做私人百科导师

你在这几次代码生成交流期间，或许会产生恐慌。你看到了很多你一辈子都没听过的妖魔鬼怪方法比如 filter 甚至是 callback。
不要逃避自己的懦弱瞎拷贝带过，利用它的无情碾压反杀变成学习契机！继续在此会话窗口连追发问：

  • "What does the filter method do? Why is it useful? Give me a few examples."
  • "What is a callback? Explain the filter method in simple terms to a JavaScript beginner."

这就是你所能拥有的跨越时区、绝对体贴包容的 AI 助教力量的极致展现。当你有且仅有在具备底线基础和解决宏观方案逻辑时，请用这股力量，加速横扫那些你看不懂或者写得累的任务，这才是未来开发工程师应有的格局。
